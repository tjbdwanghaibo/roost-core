# 生成器逐字节比对（不声明 websocket 的工程）

生成器 A：git archive HEAD（44241b95 之后的 main HEAD）构建的 roost；生成器 B：HEAD + ws 组改动（只覆盖 ws 组的文件）构建的 roost。
同一组命令，两个生成器各跑一遍：
  roost project new wsp -module example.com/wsp -template game
  roost add access player --service game --root wsp
  roost add transport tcp --root wsp        # 快照 wsp-tcp：嵌入 TCP 工程（94 个文件）
  roost module add login --root wsp
  roost add gate --root wsp                 # 独立 Gate 工程（131 个文件）
