# 把生成工程的三份开发配置改成演练用的：隔离环境的 Redis / NATS（从环境变量读，不打印）、私有 etcd、
# 避开本机别人在用的端口。输出到 <工程>/.drill/configs/，不进仓库。
import os, re, sys

root = sys.argv[1]
out = os.path.join(root, ".drill", "configs")
os.makedirs(out, exist_ok=True)
redis = os.environ["ROOST_DATAENGINE_IT_REDIS_ADDR"]
nats = os.environ["ROOST_DATAENGINE_IT_NATS_URL"]
etcd = "127.0.0.1:23791"
subs = {
    "account": [("  addr: 127.0.0.1:9100", "  addr: 127.0.0.1:19300"), ("  addr: 127.0.0.1:8080", "  addr: 127.0.0.1:19380")],
    "lobby": [("  addr: 127.0.0.1:9101", "  addr: 127.0.0.1:19301"), ("  listen: 0.0.0.0:8081", "  listen: 127.0.0.1:19381")],
    "relay": [("  addr: 127.0.0.1:9102", "  addr: 127.0.0.1:19302"),
              ("  listen: 0.0.0.0:7102", "  listen: 127.0.0.1:19310"),
              ("  advertise_addr: 127.0.0.1:7102", "  advertise_addr: 127.0.0.1:19310"),
              ("  ws_listen: 0.0.0.0:7202", "  ws_listen: 127.0.0.1:19320"),
              ("  ws_advertise_addr: ws://127.0.0.1:7202/relay", "  ws_advertise_addr: ws://127.0.0.1:19320/relay")],
}
for name, pairs in subs.items():
    text = open(os.path.join(root, "configs/service/config.%s.yaml" % name), encoding="utf-8").read()
    for old, new in pairs:
        if old not in text:
            sys.exit("%s: %r not found" % (name, old))
        text = text.replace(old, new, 1)
    text = text.replace("  addr: 127.0.0.1:6379", "  addr: " + redis, 1)
    text = text.replace("  url: nats://127.0.0.1:4222", "  url: " + nats, 1)
    text = text.replace("  endpoints: [127.0.0.1:2379]", "  endpoints: [%s]" % etcd, 1)
    text = re.sub(r"(?m)^  dir: log$", "  dir: .drill/log/" + name, text)
    if name == "account":
        text = text.replace("  session_secret: CHANGE_ME", "  session_secret: lrportal-drill-session-secret-0123456789", 1)
    open(os.path.join(out, "config.%s.yaml" % name), "w", encoding="utf-8").write(text)
print("configs written to", out)
