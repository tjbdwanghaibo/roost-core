## 验证边界

- 05 的 Cluster 是单机上的三主节点，无副本和故障切换；06 的 Redis 是独立单节点。07 与 09 使用运行在本机的 Go relay 对端，未演练 NATS、多进程乱序或跨机网络。
- 浏览器 Origin 与 URL 的序列化对照使用 Node 的 WHATWG URL 实现；本轮没有启动 Unity Editor、浏览器 Player 或移动真机。C# 与 TS 的连接集成均通过回环网络。
- 业务模块、MOBA、SLG 的成功记录覆盖功能契约。Mongo / NATS、真实掉电与恢复、全部业务模块组合、全仓 pretag、容量和长稳本轮未验证。
