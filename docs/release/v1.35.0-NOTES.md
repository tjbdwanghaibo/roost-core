# v1.35.0：PB 客户端、Robot 与生成游戏验收

## 升级要求

CLI、runtime、玩法夹具和客户端生成物使用同一版本。生成工程最低 core 提升到 v1.35.0：公共 Robot 新增 `transport.PlayerTCPType`、`Session.CallChecked`、`session.ErrRejected` 及运行报告 API，默认 DAO 同步也依赖本版 PB 编码。用新生成的 idle-sim 工程实际依赖 v1.34.2 编译，以上前三个符号缺失；这是提高下限的实际 API 原因，不是仅按版本号限制。

默认 DAO 同步编码号由 BSON 的 1 改为 PB 的 2。重新生成服务端 DAO、业务 PB、客户端 `dao_sync.proto` 与 `dao_sync_apply.cs`，一起升级。字段补丁按存在性替换，空集合与零值不能忽略，不能用普通 PB MergeFrom 合并集合。不提供旧同步格式双读；持久化与回滚仍使用 BSON，本次不改变落库格式。详见 [DAO 同步契约](../framework/DAO-SYNC-PROTOBUF.md)。

## 能力与行为

- C# 标准 `GameClient` 提供 PB 请求/推送回调、超时与异常回调、心跳、业务可选重连和有界完成队列；EntitySync 管理对象、代际、版本及 Full/Delta/Remove 变化通知。回调在业务线程 Pump 中执行，业务回调异常不破坏同步基线。Unity 使用薄生命周期桥接。
- C++17 客户端提供有界网络工作线程、请求/心跳、PB DAO 字段补丁、EntitySync、C ABI 及 Unity/UE 接线。原生库与 C# 客户端共用协议；本版不移植 Lockstep 客户端状态机。
- Robot 的 player-tcp 适配收敛到公共库，生成业务 PB 同时产生协议注册表。请求超时释放线序列映射，迟到回复不会冒充推送。arrival-rate 有并发预算、丢拍/容量拒绝统计；停止等待调度器和清理完成。
- Robot 报告按运行隔离，区分协议成功与业务拒绝，记录逐消息计数、延迟分位数、最慢样本、实际 socket 字节、CPU/RSS/Go 运行指标。小数毫秒参与门禁，历史报告深拷贝，调用者不能改写保留结果。参见 [Robot](../framework/ROBOT.md)。
- 13 类游戏 skill 与生成矩阵使用公共 Robot。新增回合 PvP、合作 Roguelike、异步社交经营；合作样板覆盖双客户端三关、领奖/重试/重连及授权视图，MOBA 覆盖 KCP 丢包追帧直到终局、Nest 幂等结算与客户端资产核对。生成器仍提供骨架，玩法源码来自仓内夹具。
- Nest 增加按 owner 去重的 AfterRollback 通知；State 在全部 DAO 成功恢复后通知变化，重新对齐状态门控。逆操作失败不宣称恢复成功，外部副作用与已取消动作不自动补偿。

真实账号联合验收的上游身份签发使用测试 HMAC verifier，不代表 Steam/Apple 登录已集成。在线实体 getter 由测试宿主提供；恢复检查是对象/驱动/WAL 重开与 DAO 冷水合，不是生产 Repository 启动、进程 SIGKILL 或断电恢复。通用 game-demo 的真实存储结果不扩张为所有玩法的真实存储证明。

本轮没有生产容量、跨机、Linux 实跑、Unity Editor/IL2CPP、UE 实机、Windows/Android/iOS 设备结果，不把多平台源码和接线描述为这些平台已经验收。现行开放边界仍以 [KNOWN-LIMITS](../maintenance/KNOWN-LIMITS.md) 为准。
