## 升级动作

维护者已明确“线上尚未部署，格式变更不做旧数据兼容”。本轮按该边界实施：

- 一仓一模块，同一个 core tag 包含 kit、codegen、skill。minimum及release清单已准备v1.23.1；发布前只能用source-head本地replace验证，不能将旧已发布生成器用于新清单。
- Runtime checkpoint=10；chat持久状态、global route、session run相关记录升级到各自v2。先停旧进程，按本地数据用途清理或离线重建旧格式，再起新进程。旧格式明确拒绝，不做新旧混跑承诺。
- ReplicaSyncer 需换用 ReplicaStore：值与删除版本原子更新。ReplicaLocalStore有总键数上限（含墓碑），不会为腾空间丢版本水位；持久副本由业务实现同事务持久水位。
- 新TCP的鉴权后心跳为MsgID0/flags0/空payload/递增非0序号，回同序号空ACK；心跳也计入请求额度。业务请求不能占用MsgID0。客户端须在idle_timeout内发送请求或心跳，只有服务器下行不能保活。
- `bus_rpc_pending_total` Gauge 已更名 `bus_rpc_pending_requests`，面板改名，不用rate计算Gauge。其余新增指标与单位见根 [OBSERVABILITY](../../OBSERVABILITY.md)。
- 默认生产拒绝dev管理令牌，admin关闭时允许空令牌；启用必须填写。审计operator/source为调用方声明，框架没有自动审批、隐藏或dry-run执行器。
