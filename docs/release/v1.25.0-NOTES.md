# v1.25.0：目录分类、Gate 与 Block AOI

本版交付Framework/Infra/Gameplay/Service/Wiring目录分类、正式独立Gate/Game（Core NATS + MessagePack）、广播、Sync/Lockstep接线与Block AOI。Nest快池共享等待容量默认65536；空间组件手写接入，setter仍只标脏，handler完成后经提交门统一发布。

## 升级

运行时与codegen同一tag；最低core为v1.25.0。旧kit及扁平路径不保留alias，业务需要更新导入，用同版本工具重新生成并编译。Gate绑定需要业务提供身份解析与player绑定，不能把连接ID当账户/玩家身份。详细接口见[Gate](../framework/GATEWAY.md)和[Block AOI](../framework/INTEREST-BLOCK-AOI.md)。本版不自动清库、转换WAL或迁移DAO schema；需要保留的数据仍按维护手册排空与落库。

## 已接受的发布限制

维护者在2026-10-09明确要求先发布，再分析重档问题。1000玩家、10000实体、每玩家10msg/s、1Hz heartbeat、1%变化的15分钟负载通过：业务/HB各900万，零拒绝，DAO/AOI一致，Sync提交→客户端P99=20.06ms，最大148.643ms、>50ms共4096条。

同规模10Hz heartbeat、5%变化的15分钟负载失败：802.919秒先Gate准入容量耗尽（Nest队列约7050），805.465秒Nest队列达65536，随后EOF及最终值不一致。不能宣称此重档容量稳定或用常规结果替代重档结果；首错根因仍待分析。原始证据和复跑参数见[性能验收](../maintenance/DIRECTORY-GATE-VALIDATION.md)。

测试为macOS本机、Gate/Game/客户端同进程，broker独立；未证明跨机、Linux实机、额外observedBlocks高扇出或全部生产故障矩阵。发布不包含部署，也不移动已有tag。
