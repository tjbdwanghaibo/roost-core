# v1.37.0：网络体验与事务边界修复

## 升级要求

服务端、客户端头文件、native 动态库和 Unity 托管绑定从同一版本重新构建。本版新增 `roost_clock_probe` 导出，网络 ABI 布局仍为 2；不能用旧动态库搭配调用新导出的绑定。业务 PB、DAO 同步载荷、WAL 与 BSON 持久化格式没有变化。默认生成工程的最低 core 仍为 v1.35.0；使用本版新接口应固定 v1.37.0。

Gate 的 RCN1 校时使用鉴权后的 ID=0 控制帧，沿用心跳开关及请求限速。时钟样本来自 Gate UTC，不自动等同于另一个主机的 Game/场景时间；Sync tick 也不能按 50ms 换算服务器时间。默认不自动发探针。

## 行为变化

- 修复 RV-20261101-01：失败创建改动已登记 DAO 时，整个 Nest 事务失败并回滚；业务吞掉创建错误也不能提交这些外部副作用。
- 修复 RV-20261101-02：`WaitTerminal` 绑定首次权威查询发现的 Lifecycle，并补查登记间隙。尚不存在时等待首次可见记录；登记期间换轮返回 `ErrLifecycleChanged`，已绑定记录消失返回 `ErrNotFound`。不自动接续另一轮，不采用旧生命周期的高 Version 终态。
- 修复 RV-20261101-03：native 心跳选包与取号跟请求准入同锁，避免序号倒序被 Gate 断开；取消和响应关联语义不变。
- 新增可选逐会话状态发送软预算和发送优先级。默认关闭，按完整 subject 选取，删除放行，延后的增量恢复当前 Full；不是跨多个 Manager/PB/Lockstep 的全 TCP 带宽上限。
- C# / C++ 新增有界校时、表现插值、输入预测历史及诊断；物理 viewer 接入正式插值与预测，保留最新输入邮箱语义。插值播放头不超过最后可显示样本，长暂停恢复后仍能继续插值。
- Sync、Gate 实际 socket 写出与客户端应用/展示可按阶段关联。写出成功不代表客户端收到；跨机时间未经校准不能直接相减。

接入、配置和验证边界见[网络体验](../framework/NETWORK-EXPERIENCE.md)。只在需要的状态流启用预算和表现插值，不延迟资产或删除的权威回调；20Hz 周期兜底和 handler 级 on_change 保持原语义。

## 验证口径

专项证据包含 Nest/Saga/wiring 的 race、C# SDK 回环与物理 viewer、native 七组 CTest。新增固定 20Hz 抖动输入、60Hz 展示的 600 帧轨迹验证，以及独立线程 500 个业务请求与 1ms 心跳的线上序号回归。三项缺陷的修前红文本和修后入口分别保留在 Nest/Saga 实现篇和 native README。

发布脚本执行 pretag：全仓 build/vet/test、生成物漂移、C# SDK 和生成玩法门禁；随后核对 main/tag，再用 GOPROXY=direct 生成 game-demo 并 build/vet。实际发布日志保留在 artifacts/release/v1.37.0。

本版不宣称 Unity 渲染 FPS 提升、生产容量提升或跨机时钟误差保证。Linux、移动设备、UE、真实 WAN 与生产故障矩阵未作为本轮实跑证据；历史 Unity Player 测量不能冒充本版重新验收。发布不等于部署。
