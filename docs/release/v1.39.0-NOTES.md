# v1.39.0：DAO 递归增量持久化

## 行为变化

普通 Mongo DAO 在 setter 中记录字段、map key、list index 路径，Nest 事务提交时读取最终值并冻结 BSON `$set` / `$unset`，不再因修改嵌套叶子而编码整个容器。父节点替换覆盖子操作；空容器、列表结构替换、不安全 key、密集变化与 4096 节点预算超限回退完整字段。

持久变化树独立于 Sync 确认，不改变事务回滚、WAL fsync 策略、Mongo 版本校验或幂等投影。Remote 权威信封仍使用完整 payload。详见[实现说明](../framework/DATAENGINE-INCREMENTAL-PERSISTENCE.md)。

压测夹具 RV-20261102-02 的初始版本期望已统一为创建与初始化后的版本 2，保留修前失败；没有变更生产持久版本语义。

同时修复 RV-20261102-01：Patch 在 WAL 准入前拒绝重复及父子重叠路径。手写 DAO 应在提交前合并覆盖关系，不能把冲突路径交给 Mongo 处理。

## 升级要求

- 生成器与 core 一起升级到 v1.39.0，并重新生成 DAO/嵌套类型。生成物使用新增的 `nest.MarkPersistPath`、`PersistChange.Paths` 与 `SyncChange.ReplacementCount`；v1.38.0 实编确认缺少 API，不能混配。
- BSON 文档 schema、WAL codec 与客户端 PB 同步格式未改变，无需清库或更换 WAL 目录。客户端 Sync 格式仍为 3，本轮不要求客户端额外升级。
- 业务继续使用生成 setter，无新增 tag 或启用开关。绕过 setter 修改内部容器不属于支持路径。

全 nopersist DAO 的空持久路径生成已通过心跳和双模式 Sync 消费工程编译及 race；修复发布前门禁发现的 RV-20261102-03，不使用无效变量读取规避编译错误。

## 验证范围

功能验证包含事务回滚、冻结值不变、嵌套增删与整体替换、真实隔离 Mongo、文件 WAL 关闭重开和重复投影。全仓 build/vet/test、受影响包 race、生成 game-demo 的 build/vet/test 与无漂移检查已通过；发布脚本另执行 pretag 与 tag 下载消费验证。

实测结果、参数和限制见[持久化性能报告](../performance/DATAENGINE-PERSIST-PATHS.md)。本次为 macOS 本机验证，不代表 Linux、生产跨机或长期容量验收。发布不等于部署。
