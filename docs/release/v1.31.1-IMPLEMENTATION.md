- `codegen/ci/framework-release.yaml` `release: v1.31.1`（`scripts/pretag.sh` 第 4 步比对）。
- **最低 core 不动**（`codegen/internal/roost/manifest.go:36` `minimumVersions.Core = "v1.31.0"`、`.github/workflows/framework-compat.yml:50` minimum lane 仍为 v1.31.0）。依据：`git diff v1.31.0..665db4fe -- codegen demo` 为空；`GOWORK=off go list -deps ./codegen/cmd/roost` 不含本版改过的任何包（chunksync、gameplay/physics、nats/driver、base/index、physicsroom、saga）；生成物不引用 physics / chunksync，新增 API 都在生成物用不到的包里。实测见[验收 V1](v1.31.1-VALIDATION.md)。与补丁先例 v1.26.1 一致（它也保持 v1.26.0）。
