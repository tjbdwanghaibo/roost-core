## <a id="perf15"></a>5. 15 分钟性能

本版之前最近一次 15 分钟重档通过（`stackfix-heavy-15m-20261012`，见 [REVIEW-20261012](../performance/REVIEW-20261012.md)）对应的是可读性整理、热路径六项优化与池改名**之前**的代码。v1.26.0 发布后已补测并**通过**（2026-10-13 23:35～23:50，[复测报告](../performance/V1260-HEAVY-20261013.md)）。长尾明显收窄，但两次样本之间叠加多项改动、单次样本受宿主后台负载影响，不归因到某一项。
