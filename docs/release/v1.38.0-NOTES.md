# v1.38.0 发布说明

本版完善生成代码的业务接入，并将默认 EntitySync 改为 setter 记录的递归 PB 增量。最低 core 提升到 v1.38.0；新生成 DAO 对 v1.37.1 源码实编已确认缺少 `dataengine.SyncPath` / `SyncChange`；服务端生成器、运行时和客户端须配套更新。

## 升级要求

1. 更新 core 与 roost 生成器到 v1.38.0，执行 `roost generate`，重新编译服务端。
2. 使用新 `db/dao_sync.proto` 生成客户端消息；C# 同时更新 `dao_sync_apply.cs`，C++ 更新原生 SDK。DAO 同步载荷使用 `sync_format=3`，不兼容旧格式；关闭旧连接后重新获取全量。
3. 持久 BSON、WAL 及 EntitySync 外层编码不变，不需要清理数据库或 WAL。`.Values()` 返回 map 和 error，原始递归补丁必须先 Apply。
4. 自定义 Subject packer 继续使用字段替换；要使用变化追踪，按 [DAO 同步协议](../framework/DAO-SYNC-PROTOBUF.md)接入捕获版本与确认接口。默认 self_sync 已自动接入。
5. Remote View 的 schema 不兼容时明确拒绝，发布与读取两端须一起重新生成，不做旧快照转换。

## 行为与接入变化

- **递归同步**：支持嵌套 struct、map、list 的子字段变化，以及列表按索引赋值。setter 只记录，handler 提交后统一同步；失败回滚、冻结内容和版本确认仍受正式事务边界保护。元数据超限或密集变化回退完整替换。
- **Remote View**：DAO 字段可声明 `remoteview`，生成只读 Snapshot、深拷贝投影与 codec；请求 DTO 可放在共用请求包，统一生成预取声明和访问器。I/O 池预取、业务池读取，不自动扩大权限。见 [Remote 指南](../framework/guide/05-remote-mirror.md#6-普通-entity-写入--remote-view-读取)。
- **Controller 接线**：标准 endpoint 分为手写入口和生成转交文件，`//roost:endpoint nest=<Handler>` 为对应关系声明；可直接转交 PB 请求、返回 PB 响应，手写校验与授权仍由业务负责。见 [命令参考](../../codegen/docs/CODEGEN_REFERENCE.zh-CN.md)。
- **标记说明**：新增 [tag 手册](../../codegen/docs/TAGS.zh-CN.md)，SLG/MMORPG skill 同步说明 Remote View 接入方式。

## 已执行验证与边界

功能阶段已执行相关核心/生成器 race、生成 DAO 运行回归、真实 TCP → Nest → DAO → Sync（含回滚与重连），以及 Go/C#/C++ 同一 PB 金样和 native managed interop。Remote View / endpoint 另有跨包生成消费工程、schema 拒绝和授权回归，存储/解析器替身不代表真实跨机验证。

1000 项 map/list 各改一项，编码微基准中位数从 106.716µs / 9760B 降为 0.547µs / 30B；包括 setter、隔离事务及确认的对照为 145.290µs → 34.095µs。该结果不是网络端到端容量承诺；原始样本与限制见[性能报告](../performance/DAO-COLLECTION-SYNC.md)。

发版使用 `scripts/release.sh v1.38.0 --min-core`：pretag 验证后推送 main/tag，再使用发布 tag 生成 game-demo，以 `GOPROXY=direct` 下载并 build/vet。Linux、Unity Editor/IL2CPP、移动设备和生产网络长稳不在本次验证范围。
