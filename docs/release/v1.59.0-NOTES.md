# v1.59.0：普通图成员与停机排空、换服落点、Saga 分段观测

这是相对 v1.58.0 的升级说明。是否已发布以正式 tag 为准；合入 `main` 不代表已经上线。完整变更见 [CHANGELOG](../../CHANGELOG.md)。

## 对玩家和运维的影响

- **普通图容量数的是在图玩家，不是连接数或可见对象数。** `scene.player_capacity: 0` 是默认值，不限人数。设置正数后，满员答 `scene_full`；断线不腾位，同服重连不重复占位，正式离场或卸载才释放。正常停机拒绝新落位和迟到的会话加入；逐个保存在线及断线驻留玩家的最后位置，空图才能确认关闭；某名玩家离场失败时，其余玩家照常保存，失败汇总上报、地图不确认关闭。写入被 Nest 围栏或停机超时不算排空成功。没有在线维护关图、动态开图或多图切换入口。
- **换服只改首次进入目标普通图的落点。** 目标服用自己的出生点；不能站立时由原有地形规则找可用点。目标坐标与玩家换服标记 `PlacedID` 同事务提交，再做到账。满员不消费意图，到账前重连不再次回出生点。同服重连仍用当前位置或保存位置。CellWorld 的路由、所有权、落位和快照恢复不变。
- **Saga 诊断不改变业务结果。** `delivery_age` 保留原口径，新增按步骤主题、首投／重投拆分的 `append_to_callback` 和 `callback_to_worker`。前者不是纯 broker 排队，后者不含业务执行。机器人失败时记录 `saga_record`，供计时结束后只读查终态；客户端超时不等于未提交。`AddExp` 的 Player + World 原子性、WAL 和全局并发默认值未改。[指标定义](../framework/OBSERVABILITY.md) · [百人档结果与未解问题](../performance/DEMO-WORLD-SAGA.md)。
- **沿用本版 main 的修复。** 已批量投影的 async WAL 在丢尾后只剩单条时，按事务 ID 与摘要核对既有结果；不是放宽版本冲突检查。新生成配置区分前 40 字节相同的超长工程名。TS Gate 的一个完成回调抛错，不再阻断其他请求的关闭通知。

## 升级与回退

1. **生成器和框架分开看。** 普通图迁移属于 game-demo 模板；仅更新已有工程的 Go 依赖，不会替换手写接线。已有工程在独立目录生成并对比 DAO、处理器、同步桥和配置后再迁入，不要覆盖定制文件。最小 `core` 仍是 v1.58.0：合并候选生成的完整 demo 不加 `replace`，用缓存的已发布 v1.58.0 做过 ID 检查、build、vet 和普通图专项。要采集新增的框架指标，运行服务也须使用含新观测的 core；这项最低版本验证不等于任意新旧实例可混跑。
2. **保留现网 Mongo 库名、前缀与 WAL 映射。** 不因重新生成配置就更换 `mongo.database_prefix`。确需迁库时先停写、排空 WAL、备份并核对新旧库；新版不会自动拆开历史撞库数据。[前缀与 WAL 的升级边界](v1.58.0-NOTES.md)。
3. **换服在途先收敛，再切换或回退。** 普通图的容量账本、关图标志不落库；`PlacedID` 则随玩家换服状态持久化。建议维护窗口暂停新换服，核对在途意图、绑定及已保存的位置，再升级参与换服的 game 实例。回退也先收敛在途换服；不要把旧程序能否正确处理“新版已落位、尚未到账”的中间状态当作已验证。遇到结果未知时查绑定、意图和记录，不盲目重放。
4. **上线前再验最终候选。** 在目标环境验证普通图满员／重连、换服到账前重试、正常停服保存和重启登录；发布仍走仓库 CI、升级兼容矩阵及 `pretag`。本机百人同秒与分批通过不是生产容量承诺，历史失败的 8 笔终态仍未知，200 人档未因本版关闭。[已知限制](../maintenance/KNOWN-LIMITS.md)。
