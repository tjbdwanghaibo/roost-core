## 强制边界与review重点

- Nest只有快池执行业务并持Entity local锁；慢阶段不执行业务。setter仅标脏，Guard锁内冻结Sync，全部锁释放且提交确认后外发；pipelined Enqueue后的不可回滚不等于已持久。
- ReplicaStore必须原子保存删除水位，旧更新不能复活墓碑。默认有界且拒绝新键；不能用LRU淘汰水位伪装成无限防复活。
- 管理审计不记录payload/token/Data，命令标签有界；stat采集只读，文件窗口随成功写入推进。DataEngine Gauge沿既有准入/确认/后台采样更新，没有额外poller。
- 项目模板全在stage构建，rename是唯一发布点；失败清stage。生成文件分类与Roost覆盖权限分开，标准生成头不能扩大到别的生成器。
- RR-39不改生产：保留已持久但发布待补发的判定，真实Mongo验证后续事务继续、outbox仍保留、重启后补发。第一轮失败日志原样保留，不能只看最终绿。
