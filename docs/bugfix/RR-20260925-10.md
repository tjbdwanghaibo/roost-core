# RR-20260925-10 修复：Flush 校验订阅所属的会话生命周期

对应[问题](../bug/RR-20260925-10.md)。日期：2026-09-25；已修复并通过并发回归，未发布。

Flush 捕获前同时核对会话存在及 lifetime 一致；已经重开的 ID 所残留的旧订阅立即清理，不进入新会话编码。清理复用 `removeSubscriptionLocked`，同步删除旧 lifetime 反向索引，不影响新会话。该改动不新增授权规则，只阻止旧连接意图跨生命周期复用。

回归测试通过 channel 确定性冻结 SessionClosed，覆盖 Close/重开/Flush 顺序；修前红、修后绿。另覆盖全部订阅删除路径、1000/10000 实体恢复、Subscribe/Unsubscribe/Hold/Ready/Close 并发。`go test -race` 的 Sync、policy、Remote、kit/remoteentity、Nest、DataEngine engine、kit/dataengine 七包通过。新增用例重复 race 验证与性能结果见[本批方案和验收](../feature/REFACTOR-2026-09-25-resource-budgets-and-session-recovery.md)。

传输回调的外部连接身份管理仍由 Transport 负责；本修复保证 Manager 不将旧订阅编码给新 lifetime，不能撤回已经交付给旧连接的帧。
