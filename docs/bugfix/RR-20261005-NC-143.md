# NC-143 修复：BlockRect 的右 / 下边界饱和计算

[问题](../bug/RR-20261005-NC-143.md) · [证据](evidence/noncore-bugfix-20261005-revn11/README.md) · [本轮](../review/REVIEW-2026-10-05-n11.md)。已修复、声明场景验证，未发版。

## 根因与修法

`spatial/block_index.go` `BlockRect` 原来 `Min + (x+1)*blockSize` 在 int64 上界溢出。改为先算 `Min + x*blockSize`（小于跨度，不溢出），右 / 下边界 `SaturatingAdd(…, blockSize)` 后截到 bounds。块划分、BlockIndex 编号不变。

同文件给 `QueryBlocks` 补中文注释：每块独立读锁，多块查询不是快照（观察 O1），需要一致视图的调用方自己串行化。

## 兼容

只有原来会溢出的边界配置返回值改变；AOI 只用 `BlockRects` 的键。

`TestBlockRectsStayInsideBoundsAtTheInt64Edge` 修前两叶红（[原文](evidence/noncore-bugfix-20261005-revn11/red-nc143-spatial.txt)），修后 `go test -race -count=3 ./spatial` 与 `./sync/entitysync/policy` 通过。
