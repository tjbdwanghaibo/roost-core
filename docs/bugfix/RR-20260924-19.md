# RR-20260924-19 修复记录

问题见 [RR-19](../bug/RR-20260924-19.md)。已修复并验证，未发布。

Assembly 内串行持有启停操作，竞争等待遵守 context。已运行时 Start 幂等，失败重试复用首次绑定的 replicator。Stop 取得所有权后进入终止状态，超时保留复制依赖，后续 Stop 完成排空再回收。finalizer 原本就是 sync.Once 单次生命周期，因此停止后 Start 明确返回新增 ErrAssemblyStopped；重新运行需要重新 Assemble。

六个生命周期场景 race 通过：重复启动、初始化失败重试、先停后启、取消启动、并发启停等待取消、停机超时保留订阅再重试完成。修前四个原始场景失败，日志见问题记录。

首次 bus 在 Assembly 生命周期内固定，替换须重新 Assemble。ISyncBus 的 Subscribe/unsubscribe 没有 context，本次不能为外部阻塞实现增加硬截止保证。持久化格式和业务提交顺序不变。完整命令、日志与十包回归见 [第二轮实施](../feature/REFACTOR-2026-09-24-remote.md#第二轮启停与锁代际)。
