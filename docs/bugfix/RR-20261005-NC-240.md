# NC-240 修复：结果确定即停止本次 Tick（`decided`），再 Reset 全部子节点

问题：[RR-20261005-NC-240](../bug/RR-20261005-NC-240.md)。分支 `revn10b`，基线 `81d7cb16`，[本轮](../review/REVIEW-2026-10-06-noncore-n10b.md)，[证据](evidence/noncore-bugfix-20261006-n10b/README.md)。

## 修复

`Parallel.Tick` 每处理完一个子节点就用 `decided(successes, failures)` 判断结果是否已定，已定即跳出循环，之后照旧 Reset 全部子节点。注释写明。

文件：`ai/nodes.go`、`ai/parallel_decision_promises_test.go`。

## 兼容

结果确定那一拍，排在决定者之后的子节点不再被 Tick（此前被 Tick 后立刻 Reset）。结果未定时行为不变；已在运行的子节点照旧经 Reset 收到 OnInterrupt（控制用例 `TestParallelStillInterruptsRunningChildrenWhenItCompletes`）。
