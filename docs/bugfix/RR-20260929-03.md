# RR-20260929-03：account 建角补偿误删已有名字

状态：已实施并通过本轮定向回归，未发版。源码基线 `f46db3e7d504bbd73581aa4119baa71171352519`。

根因：名字 owner 只使用 accountID，跨服同账号复用已提交名字，失败后释放他人角色的名字。

实现：新建角 nameOwner 使用现有 account/server slotKey；任何已提交的同 owner claim 都拒绝复用，不 Commit/Release。失败只清理自身暂占 slot。

改动：kit/service/account/service.go。

回归：`TestReviewCrossServerRoleRollbackKeepsExistingName；TestCommittedLegacyNameOwnerIsNeverCompensated`。修前证据保留在 [第一轮](../bug/REPRO-2026-09-29-services.md) / [第二轮](../bug/REPRO-2026-09-29-services-02.md)；RR-09 修前是源码接线缺口，其他项有动态 FAIL。正式行为回归位于对应包，含 race；排行及 session ABA 使用隔离真实 Redis。统一命令、实际计数与未测边界见 [本轮总记录](SERVICE-BUGFIX-2026-09-29.md)。
