# NC-269 修复：lifeMu + shut 取代 closeOnce：Shutdown 关闭全部 worker（含未启动的），之后 Start 无效

问题：[RR-20261005-NC-269](../bug/RR-20261005-NC-269.md)。分支 `revleft`，基线 `dc877c04`，[本轮](../review/REVIEW-2026-10-06-revleft.md)，[证据](evidence/noncore-bugfix-20261006-revleft/README.md)。

## 修复

`lifeMu` 串行化 Start / Shutdown 的状态转换；Shutdown 第一次调用置 `shut`、`running=false` 并关闭全部 worker 的 channel（从未启动的也关）；Start 见 `shut` 直接返回。等待部分不变（超时后重试仍会再等，G4 的既有承诺）。

文件：`goroutine/task_pool.go`、`goroutine/task_pool_restart_promises_test.go`。

## 兼容

Shutdown 之后 Start 不再把池标成 running（之前标成 running 但不可用）。
