# RR-20260927-29 修复：共享加载的领头方以任何方式离开都登记离开，迟到的 `RunLocal` 不再永久阻塞

问题：[RR-20260927-29](../bug/RR-20260927-29.md)（第六轮审计 N1 → OPEN-ITEMS 批次 13 追加）。日期 2026-09-27。基线 `a136c98`，分支 `fix-r8-b13`。
状态：已修复，本地验证通过，本地提交，未推送 / 发布。codebase-memory 图谱过期（09-26），未使用；以当前源码为准。

## 根因（基线行号）

`entity/manager_access.go` `loadEntityShared` 的等待循环只在 `case <-ctx.Done()`（`:330-335`）调用 `flight.leaderLeft()`；从 `case <-flight.done`（`:325`）
正常返回或把加载 panic 重新抛出时都不登记离开。于是：

- RR-27 的持锁非 Nest 领头方：`leaderAway` 永不关闭。loader 在 `LoadEntity` 返回后另起 goroutine、仍用加载 ctx 调 `RunLocal` 时，`runOnLeader`（`:434-446`）
  向已无人接收的 `leaderSteps` 发送、等不到 `leaderAway`，调用方永久阻塞（goroutine 泄漏）。
- Nest 慢阶段领头方（有执行器）同源：`leaderGone` 不置位，迟到步骤仍经 `flight.leaderRun`（`:417`）交给那条**已经返回**的消息的快续行，而那条 Msg 在返回后会被回收。
  这一半不在主记录里，是同一行代码的另一面，一并修正。

## 决策

- `loadEntityShared` 的领头方在进入等待循环前 `defer flight.leaderLeft()`，覆盖 ctx 离开、加载完成、加载 panic 重新抛出三种返回方式；ctx 分支不再单独调用。
- `leaderLeft` 用 `sync.Once`（`leaveOnce`）保证只生效一次（关闭 `leaderAway` 只能一次）。离开后的迟到步骤走既有的“领头方离开后”路径：绑定的 `NestMgr.RunLocal`，未绑定时就地执行。
- 加载完成路径上 `leaderLeft` 取 `leaderMu`：正常的本地步骤都在 `LoadEntity` 返回（`done` 关闭）之前结束，所以这里只可能等一个迟到的、正在用领头方执行器的续行——
  与 ctx 离开分支已有的“离开要等在途续行结束”相同（续行仍在使用领头方的 Msg）。`leaderSteps` 路径的步骤不持 `leaderMu`，不受影响。
- 未采用：在 `runOnLeader` 里再加 `flight.done` 分支——`done` 关闭时领头方可能还在循环里接收步骤，也可能已经返回，单看 `done` 分不清；以“领头方离开”为唯一事实更直接。

RR-27（交回领头方执行、领头方按 ctx 离开不被发布阻塞）、RR-54（解耦加载、各等待方按自己的 ctx 离开）、B20 的行为不变。

## 文件与行为

- `entity/manager_access.go`：`entityLoadFlight.leaveOnce`；`loadEntityShared` 领头方 `defer flight.leaderLeft()`；`leaderLeft` 幂等与注释。
- `entity/load_flight_late_local_step_promises_test.go`：`TestLateRunLocalAfterNonNestLeaderLoadCompletedDoesNotBlock`（审计探针 `TestAud8LateRunLocalAfterFlightDone` 收正：
  迟到步骤用 channel 在领头方 `Get` 返回后才放开，不靠 sleep；子用例 `unbound` 断言就地执行，`bound_executor` 断言经绑定执行器执行一次）。
- `docs/USER_GUIDE.md`：共享冷加载执行器交接一段补“离开包括加载完成后返回”。

## 兼容性

无 API / 配置变化。之前会永久阻塞的契约外用法现在返回；Nest 领头方完成后的迟到步骤改经 `NestMgr.RunLocal` 执行（此前交给已返回消息的快续行）。

## 未验证项 / 风险

- Nest 领头方“完成后迟到步骤”那一半没有单独的回归（需要 loader 在 Nest 慢阶段加载返回后再调 `RunLocal`，与本用例同一行代码）；由整包 nest / kit/nest 共享加载用例覆盖不回退。
