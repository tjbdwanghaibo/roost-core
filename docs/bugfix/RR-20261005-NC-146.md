# NC-146 修复：OrderedIndex 内嵌 Index，零值可用、nil 为空

[问题](../bug/RR-20261005-NC-146.md) · [证据](evidence/noncore-bugfix-20261005-revn11/README.md) · [本轮](../review/REVIEW-2026-10-05-n11.md)。已修复、声明场景验证，未发版。

## 根因与修法

`OrderedIndex` 的数据从 `*Index` 改为按值内嵌 `Index`（Index 零值本来可用）；方法经 `inner()` 取内嵌索引，接收者为 nil 时返回 nil `*Index`（其方法是空操作）。`NewOrderedIndex` 不再单独分配内层。

## 兼容

字段未导出，API 不变。`OrderedIndex` 现在直接含锁，不应按值复制（`go vet` copylocks 会提示），与 `Index` 相同。

## 验证

`TestZeroOrderedIndexIsUsable` 修前红（零值写入丢失），修后通过（零值读写 / 排序 / 清空，nil 指针各方法不 panic 且为空）。
