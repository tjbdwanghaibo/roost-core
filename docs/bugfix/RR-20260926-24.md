### 残留 (2)：改写保留路径时包名变化未补别名

根因：`codegen/internal/roost/consolidate.go`（基线）`:305-306` 计算 kit 保留路径时丢弃了 layout 阶段的包名，`:352-362` 的“只用 Mod glue / 混用”两支只改路径；
而“全部搬走”一支（`:348-350`）会在包名变化时补别名。手写 `import "github.com/tjbdwanghaibo/roost-kit/room"` + `room.NewRoomMod` 升级为
不带别名的 `kit/syncbus`（包名 `syncbus`），代码仍写 `room.NewSyncBusMod` → `undefined: room`。

修复：保留路径同时记下新包名（layout 的 `package`，否则路径末段），两支统一走 `keptImportEdits`：改路径，未带别名且新包名与文件在用的名字不同时补别名。

回归：`TestConsolidationKeepsTheFilesNameForARenamedKitPackage`（由 REPRO-2026-09-26-03 §10 探针改写，三种形状；`assertPackageQualifiersResolve` 检查每个包限定符都有 import 声明）。修前红：

### 残留 (1)：无法自动映射的符号静默成功

根因：迁移表 layout 阶段只改包路径，设计上把改名 / 删除的符号“留给编译器”（旧 yaml 注释、T-175）。v1.16.1 → 当前在同步块删除 / 换包了数百个导出符号
（M-13 room 广播器、M-15 statesync 复制器、M-16 传输契约换包、M-17 spatial → policy、M-18 datagram 分片），upgrade 改完 import 退出码 0，
编译器只报每个包的首批 `undefined`，且不给替代 API。

修复：

- `codegen/internal/roost/migration/consolidation_imports.yaml` 新增 `layout.removed`：按**改写后的** import 路径分组登记符号与指引（替代 API、CHANGELOG 条目、`docs/bugfix/M-1x` 记录）。
  清单由 v1.16.1 源码（tag 归档）与当前源码逐包比较顶层导出标识符得到（room 60、statesync 123、entitysync 28、nettransport 10、spatial 18、kit/room 2、kit/mods 1），
  再按去向分 12 组：同包改名（EncodeFrame → Encode 等）、换包同名（statesync.SessionID → nettransport.SessionID；spatial.InterestEvent → policy.InterestEvent）、
  换包改名（spatial.InterestManager → policy.AOI，InterestConfig → policy.AOIConfig）、线格式函数（room.DecodeRoomWireFrame → entitysync.DecodeFrame）、已删除无替代（Reassembler 等）。
- `consolidate.go`：`consolidateFile` 拆成纯计算的 `rewriteImports` 与扫描 / 写盘；`findRemovedUses` 在**最终内容**上按文件自己的 import（别名或路径末段）解析限定符，
  局部同名标识符不算；`ConsolidateProject` 先写完可机械完成的改写并打印，再返回错误：逐条 `文件:行: 限定符.符号 [组号]`，末尾每组指引各列一次。dry-run 同样报错。
  用户改完重跑，扫描为空即继续 go.mod / roost.yaml / 重生成。
- 未采用：自动改写同包改名（EncodeFrame → Encode）。前两阶段按 T-45 不维护符号改名表；layout 阶段本轮只做报告，不在已验证的 RoomMod 改名逻辑之外再引入符号级改写，
  清单与指引一起给出，改动面可控。

回归：`TestConsolidationReportsRemovedSymbolsInsteadOfSucceeding`（v1.16 形状：spatial.InterestEvent、corestate.NewReassembler / SessionID、room.DecodeRoomWireFrame；
断言错误、行号、指引关键词，仍存在的 `spatial.Vec2` 不误报，按指引修改后重跑成功）；`TestConsolidationRemovedSymbolsAreReallyGone`（表中每个符号在其登记路径的当前源码里确实不存在、每组有指引）。
