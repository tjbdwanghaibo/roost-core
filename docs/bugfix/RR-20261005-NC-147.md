# NC-147 修复：只有最外层 Tick 收尾

[问题](../bug/RR-20261005-NC-147.md) · [证据](evidence/noncore-bugfix-20261005-revn11/README.md) · [本轮](../review/REVIEW-2026-10-05-n11.md)。已修复、声明场景验证，未发版。

## 根因与修法

`Tick` 原来无条件置 / 清 `running` 并执行推迟操作。改为只有进入时 `running` 为 false 的最外层 Tick 设置 running、在 defer 里清除并按登记顺序执行推迟操作；重入的内层 Tick 照常触发到期节点，不做收尾。推迟操作执行完用 `clear` 释放闭包引用。

## 验证

`TestReentrantTickKeepsTheOuterTickSemantics` 修前红（[原文](evidence/noncore-bugfix-20261005-revn11/red-nc141-nc147-timer.txt)），修后通过；既有 panic 收尾由 `TestPostponedTimerDuringTickComposesWithLaterOperations` 的 panic 子例覆盖。
