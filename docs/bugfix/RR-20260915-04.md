# RR-20260915-04:已剔除连接的通知在剩余批次失败后丢失

**仓库 / 位置**:roost-core `room/room_transport_sink.go`,`admitWithSlowConsumerPolicy` 的普通错误出口与 `AdmitRoomFrames` 的错误提前返回。
**修复单元**:U-0207(C8)。**定位文档**:TROUBLESHOOTING T-101。

## 问题

一个 room 同主体有 session 1、2。整批可靠快照准入遇到 session 1 的 `ErrReliableBackpressure`,默认 `SlowConsumerEvict`
删掉它的传输基线、标记 `deadSessions`、`RemoveSession`,并累积一条剔除通知;筛掉 session 1 后重试剩余路由,这时
transport 返回另一个错误(临时失败 / `context.Canceled`)。函数 `return nil, err` 把已累积的通知丢了;调用方也只在
整体成功时 `dispatchSlowConsumers`。之后正常重试对 deadSessions 路由直接跳过,原通知再也生成不出来——room 保留
失效订阅和名额(实测 `sink.DeadSessions=1 EvictedRoomSessions=1 CallbackPending=0`,room `ActiveSubscribers=2`),
继续为送不到的连接做 profile / 信封工作。

## 根因

剔除是**不可撤销的副作用**(基线已删、session 已从 transport 移除),它的通知却绑在**批次结果**上——成功出口派发,
失败出口丢弃(C8:同一件已经发生的事在两条出口上待遇不同)。

## 方案选择

- **失败时回滚剔除。** 回不了:`RemoveSession` 已经调过,transport 侧的状态已变。
- **让重试时对 deadSessions 路由重新生成通知。** 重试批次未必还包含那条路由(订阅可能已变),而且把"通知"
  变成依赖后续流量的偶然事件。
- **副作用与批次结果分别交接(采用)。** `admitWithSlowConsumerPolicy` 的普通错误出口 `return events, err`,把已累积
  的通知随错误一起带回;`AdmitRoomFrames` 只在 `err == nil` 时提交 plans(失败批次的 plans / dirty 仍不提交),
  但**两条出口都**在释放 room 锁之后 `dispatchSlowConsumers(events)`。复用已有的 `pendingCallbacks` / worker:
  按 (room, session) 合并重复事件、Close 期间丢弃,不新增通知系统。

## 改动

`room/room_transport_sink.go`:两处,如上。

## 证明

`room/eviction_notice_promises_test.go` 的 `TestEvictionNoticePromiseSurvivesRemainingBatchFailure`:真实
`RoomBroadcaster → RoomEnvelopeSink → RoomTransportSink`,只替换末端 `AtomicBatchTransport` 为两阶段注入
(第一次 backpressure 剔除 session 1,第二次 `remaining route rejected` / `context.Canceled`)。失败后断言状态仍 dirty,
重试成功后 300ms 内 session 1 的订阅必须被 room 清掉;剔除后剩余批次立即成功为对照。

修前红:`evicted session remains subscribed after retry: sink={… SlowConsumerEvictions:1 EvictedRoomSessions:1
DeadSessions:1 CallbackPending:0 …} room={… ActiveSubscribers:2 …}`(两个失败子例)。修后 room 含 `-race` 全绿,
core 全仓 `-race` 全绿。

## 未做 / 边界

- 只替换了末端 transport,没有真实 QUIC / KCP / UDP。
- 事件去重仍是 `pendingCallbacks` 的按 (room, session) 合并;Close 期间的事件按既有策略丢弃。
- 审查同轮的"分片锁等待不可取消"(entitysync 观察项)未登记 RR,本轮不动。
