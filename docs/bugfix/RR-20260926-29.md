# RR-20260926-29 修复：外部夹具使用正式的手动回放 Projector

问题：[RR-20260926-29](../bug/RR-20260926-29.md)。日期 2026-09-26。实施基线：main `87d9499`（问题基线 `985d5ba`）。
状态：已修复、已在本地真实 Mongo 集成环境验证，已本地提交，未推送/发布。

## 根因

RR-17 让 `Projector.ReplayPass` / `Flush` 先 `operations.Begin()`（`dataengine/engine/projector_replay.go:17`、`projector.go:307`），
Close 之后返回 `ErrRuntimeStopped`。`kit/dataengine` 的 6 个真实 Mongo 集成测试用“先 `Close()` 停后台循环、再手动 `ReplayPass`”
的办法取得可逐步驱动的 Projector（`multi_batch_integration_test.go:33-43` 的 `manualRealProjector`，以及
`real_integration_test.go` 三处同样写法），RR-17 之后第一次 `ReplayPass` 就被拒绝。engine 包单测用未导出的
`projector.cancel()` 停循环，所以不受影响；外部包拿不到这个入口。

## 决策

- 保留 RR-17 语义（Close 后拒绝新的 Flush / ReplayPass，关闭等待已准入调用）。不回退。
- 新增 `ProjectorOptions.ManualReplay bool`：`NewProjector` 不启动后台回放循环，`done` 在构造时即关闭；
  回放只由调用方显式 `Flush` / `ReplayPass` 驱动，Close 行为不变（仍拒绝之后的调用）。
  用途写在字段注释上：供需要逐步控制回放与 ack 的外部夹具（配合既有的 `OverrideAck` 注入“投影成功、checkpoint 丢失”）；
  生产装配（`kit/dataengine`、`OpenRuntime`）不设置。
- 未采用：
  - 导出 `Projector.StopLoop()` 之类的方法——在已运行的实例上“停循环但不关闭”会引入第三种生命周期状态，
    还要回答它与 Close/Shutdown 的交错；构造选项只有两种状态，更简单。
  - 改用 `Runtime`——这 6 个测试要在 WAL 与 Projector 之间注入故障（丢 checkpoint、同 WAL 重开、改 Store 包装），
    Runtime 会先做启动恢复 Flush 并持有 WAL，所以测试无法再逐步驱动中间状态。
  - 在测试里用 `IdlePoll: time.Hour` 代替停循环——后台循环启动时会立即跑一轮，并且 `TransactionReleased` / `Commit`
    会 kick 它，与测试的手动 ReplayPass 竞争，结果依赖调度。

## 改动

- `dataengine/engine/projector.go`：`ProjectorOptions.ManualReplay`；`NewProjector` 在该选项下不起 `run`。
- `kit/dataengine/multi_batch_integration_test.go`：`manualRealProjector` 改用 `ManualReplay: true`，不再先 Close，并在 Cleanup 中 Close。
- `kit/dataengine/real_integration_test.go`：TestRealMixedProjectionSegmentsPreserveOrder、
  TestRealProjectionOnlyMongoAckFailureRestartPreservesSameEntityOrder（第一个 Projector）、TestRealMongoMixedRatioWALReplayAckThroughput
  改为手动回放 Projector；重启后的 Projector 仍用后台循环（该测试断言的正是重启循环会尝试回放）。
- `dataengine/engine/projection_lifetime_test.go`：新增 TestManualReplayProjectorRunsOnlyExplicitPasses（无后台循环、
  只有显式 ReplayPass 投影、Close 后 ReplayPass/Flush 仍返回 `ErrRuntimeStopped`）。
- `docs/USER_GUIDE.md`：生命周期兼容说明补一条。

## 兼容性

- 新增导出字段 `ProjectorOptions.ManualReplay`，零值保持原行为；无持久格式、配置键或协议变化。
- RR-17 引入的导出行为变化“Close 后 `Flush` / `ReplayPass` 返回 `ErrRuntimeStopped`”保持不变，已写入 USER_GUIDE。
  按本轮任务约束没有修改 CHANGELOG（问题记录要求 CHANGELOG 记录该变化，留给维护者统一处理）。
