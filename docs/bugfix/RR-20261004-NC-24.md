# RR-20261004-NC-24：Mongo替身精确数值比较

2026-10-04，P3，起点 `ce90e90d`；**已修复、声明场景验证，未发版**。[原问题](../bug/REVIEW-2026-10-04-noncore-14.md#rr-20261004-nc-24) · [运行](../review/REVIEW-2026-10-04-noncore-15.md) · [红绿/完整矩阵](evidence/noncore-bugfix-20261004-08/README.md)。

## 根因与决定

valuesEqual/compareValues把int64转换float64，2^53以上相邻版本合并。

标准库精确表示更易核对极值与混合float规则；不放宽容差、不改业务数据为浮点、不靠测试规避大数。只用于测试替身，不改生产数值协议。

## 改动与兼容

mongo/mongotest/mongotest.go复用math/big.Rat/Int表达整数及有限二进制浮点的精确值；signed/unsigned避免越界强转；非有限浮点显式ErrUnsupported，不静默等值。

替身非有限float从不可靠结果收紧为unsupported；整数宽度与有限float按精确值比较。标准库任意精度比较增加分配，无benchmark，不宣称加速。

## 先红后绿

修前当前源码正式测试实际失败：

> distinct BSON int64 compared equal: have=9007199254740992 query=9007199254740993

原12叶子6fail/6控制、旧实现overlay复跑仍6fail/6控制；本项根因修后转绿。原大数失败/小数控制通过；int64极值与2^53的$gt/$gte/$in、相邻大数排序、六混合数值及反向比较、非有限拒绝共11边界叶子通过。

最终十包race/vet：7测试包292叶子pass、317 test pass事件、0fail/skip，3包无测试；40新增正式叶子通过。扩展消费者14测试包674叶子pass、17环境skip另列，不以skip计通过；生成CLI独立module两个消费者race/vet通过。命令与原始事件见证据README；不是整仓或生产验收。
