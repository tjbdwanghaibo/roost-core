# RR-20261006-54 修复：proc 施放自己的事件 ID 低 32 位为 0

问题：[RR-20261006-54](../bug/RR-20261006-54.md)（F08-R R4）。基线 `47abe511`，分支 `skspawn`，与 RR-20261006-51～55 同批；验证见 [RR-20261006-51 修复](RR-20261006-51.md)。

## 根因与决策

proc 施放的事件 ID 用 `castID<<32 | 1`（基线 `skill/runtime.go:457`），与第 0 号效果 `castID<<32 | (0+1)` 相同。改为 `castID<<32`：效果编号从 1 起，低 32 位为 0 的值只属于施法自己（编号空间见 `skill/ir_event.go`）。

## 文件与行为

`skill/runtime.go` `startLocked`；用例 `TestProcCastSpawnCallbacksKeepDepthAndRoot`（第 0 号效果事件的父事件不是它自己）。

## 兼容性

线上未部署。proc 施放的 `EventID` 数值变化（仓内没有依赖具体数值的调用方）。
