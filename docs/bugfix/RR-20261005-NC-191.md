# RR-20261005-NC-191：Mongo Mod 连接日志去掉 URI 里的口令

2026-10-05，基线 `f6245613`（审查 `efe219c1`）。**已修复、声明场景验证，未发版。** [问题](../bug/RR-20261005-NC-191.md) · [本轮](../review/REVIEW-2026-10-05-n14.md) · [证据](evidence/noncore-bugfix-20261005-n14/README.md)。

## 根因

`kit/mongo/mongo_mod.go:100` 原样记录 `m.cfg.URI`；凭据只能写在 URI 的 userinfo 里（`fmongo.Config` 无独立字段）。

## 修法

`redactedURI` 把 userinfo 的口令换成 `***`，保留用户名、主机、库名与选项；userinfo 取到 `?` 之前的最后一个 `@` 为止——口令里没转义的 `/` 也盖得住，选项里的 `@` 不被误当成 userinfo 结尾。只有日志用它，连接仍用原 URI。

没采用：`net/url` 解析——多主机 `h1:1,h2:2` 与 `mongodb+srv` 的解析边界不稳定，解析失败时还得回退原样输出。

## 验证

- 修前红见 [nc191-red.txt](../review/evidence/noncore-review-20261005-n14/nc191-red.txt)；修后 `TestStartDoesNotLogTheMongoPassword`（多主机、srv、无选项）与 `TestRedactedURIKeepsEverythingButThePassword`（7 种形状）通过，`kit/mongo` `-race -count=3` 通过。

## 未验证

mongo-driver 自身的错误信息（例如 URI 解析失败）是否带口令没有查；真实 Mongo 未连接（Start 的部署校验分支不受影响）。
