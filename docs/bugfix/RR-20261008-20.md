# RR-20261008-20 修复：缺省业务时钟和系统时钟混用及偏移精度不一致

业务 Config.Now 默认 clock.Now；mail Redis 以同一业务钟计算剩余 TTL duration；account/chat SystemNow 默认 time.Now，与偏移独立。测试夹具显式注入两钟。进程偏移保留纳秒 Duration，与 Registry 一致。

方案：[B4 边界方案](../feature/REFACTOR-2026-10-08-config-time-boundaries.md)。修前日志 `roost-remaining-b4-service-clocks-red.log`（session/match/rank/activity 默认业务钟）、`roost-remaining-b4-service-clocks-red2.log`（account/chat/mail 两钟分离）、`roost-remaining-b4-boundary-red.log`（进程偏移精度）；首次日志中的编译错误不作为行为失败证据；13 个目标包 race 通过，tablegen 真实生成 loader/converter 运行通过，开关回滚在同一生成工程由红翻绿，timer 最终事务边界 race 通过。最终全仓与完整生成工程状态见交接 B4 节，未通过前不计完成。

兼容：不改已有持久格式；配置拒绝非法输入，异步消息改为每次准入固定最新运行时代际；自定义 timer 宿主须在正常事务中推进 NeedsCleanup。原始日志持久保存 `artifacts/perf/remaining-fixes-20261007/`。未发布。
