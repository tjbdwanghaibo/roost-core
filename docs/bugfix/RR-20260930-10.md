# RR-20260930-10 · Errcode 只提取真实调用

来源：[第三轮问题](../bug/REVIEW-2026-09-30-codegen-03.md#rr-20260930-10--errcode-注释中的-define-被当成真实错误码)。修前注释中 `errcode.Define(500999, ...)` 会进入 CSV。基线 Core `da56c998`。

`codegen/internal/errcode/main.go` 先按字符串快速跳过无候选文件，再用 Go AST 只提取实际 `errcode.Define` 调用，继续接受原有十进制整数和双引号字符串字面量；注释、块注释和字符串内的示例不再入表。重复 code 检查和排序保持原语义。包含候选文本但 Go 语法错误的文件会明确报解析错误。

正式 `TestExtractDefinitionsIgnoresCommentAndStringLiterals`、已有重复码测试、定向 race 与包回归通过。未发版。
