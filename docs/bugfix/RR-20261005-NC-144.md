# NC-144 修复：不等于自身的值只进主表

[问题](../bug/RR-20261005-NC-144.md) · [证据](evidence/noncore-bugfix-20261005-revn11/README.md) · [本轮](../review/REVIEW-2026-10-05-n11.md)。已修复、声明场景验证，未发版。

## 根因与修法

`index/index.go` `Upsert` 原来按同一个值建桶再取回写入，NaN 取不回 → panic。改为：`value != value` 时只写主表、不建反查桶（Go map 本来就无法按 NaN 命中，`Query(NaN)` 返回空）；其余值用局部变量持有新桶，不再二次查找。`Get` / `Delete` / `Len` 照常；从 NaN 改到正常值、再改回、删除都不留孤儿桶。

## 验证

`TestUpsertAcceptsAValueThatIsNotEqualToItself` 修前 panic（[原文](evidence/noncore-bugfix-20261005-revn11/red-nc144-146-index.txt)），修后 `go test -race -count=3 ./index` 通过。
