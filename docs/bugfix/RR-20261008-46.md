# RR-20261008-46：销毁准入前可取消，准入后完成收尾

[问题](../bug/RR-20261008-46.md)。`lock.LockContext`复用内建信号量和可重入所有权，不启动等待goroutine；Mutex接口不增加必选方法，旧实现通过其10ms有界取锁等待适配。内建锁直接select取消。

Destroy使用可取消锁入口，失败归还Touch；取锁后和删除准入前复查ctx。准入成功/未知仍完成隔离、索引删除、生命周期与锁资源释放；不通过取消回滚已接受删除。Deferred仍由原事务收尾，OnDestroy用户回调不承诺强制中断。

普通目标包lock/entity/nestwal/frame测试通过，含修前两反例转绿、准入后取消不丢收尾和可重入外层锁不误释放。lock/entity/nestwal/frame等目标race三轮通过；最终全仓结果在本轮验收记录追加；未发版。未改WAL/持久协议，不需要迁移。
