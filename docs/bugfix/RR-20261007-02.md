# RR-20261007-02：服务 Mod 可以与共享 Mod 重名

[问题与修前证据](../bug/RR-20261007-02.md)；对应 F01-9。

## 根因与修法

`app/app.go:911`：sortMods 仅对本段 byName 查重；external 仅用于满足依赖，没有参与重名判断。

注册本段 Mod 时同时检查 external；同名明确报错，其他 Mod 对共享 Mod 的正常依赖继续允许。

选择在原入口修正既有契约，不新增包、运行时 worker 或旁路机制。

## 兼容与边界

原来允许的共享/专属重名装配现在被拒绝。检查仍在既有服务专属排序阶段，共享 Mod 可能已启动；未改变启动编排和清理路径。
