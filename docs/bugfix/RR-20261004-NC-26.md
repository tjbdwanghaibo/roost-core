# RR-20261004-NC-26：BSON.D 嵌套路径

2026-10-04，P3，基线 `3d3b22c9`；**已修复、声明场景验证，未发版**。[原问题](../bug/REVIEW-2026-10-04-noncore-16.md#rr-20261004-nc-26) · [本轮运行](../review/REVIEW-2026-10-04-noncore-17.md) · [红绿证据](evidence/noncore-bugfix-20261004-09/README.md)。仅公开 Mongo 替身。

真实 BSON codec 会把嵌套文档解为 D，原 lookup/set/unset 只认 M。修前查询 count=0、set 丢 keep、unset 后 n 仍为 1，三个平面控制通过。现在 lookup 直接读取 D；修改沿路 D 转成 M 时保留同级字段，未访问的数组及文档仍保持 codec 形状。不把全部库存储转换为 M。

原三项失败转绿，并验证三级 D、兄弟字段和未访问数组。查询、排序和唯一字段检查复用同一 lookup；没有宣称所有 Mongo 路径语法通过差分认证。数组下标、位置操作符、重复 BSON 键、向非容器写路径的完整服务端错误语义仍未支持或未核定。

修改所经 D 的输出形状可能变成 M，字段内容保留；多一份沿路容器分配，无 benchmark。28 个新增正式回归及受影响消费者结果见证据，不能外推真实 Mongo。
