# RR-20260925-09 修复：回滚本地锁异常释放

[问题](../bug/RR-20260925-09.md) · [双池复核](../review/NEST-FAST-SLOW-2026-09-25.md)

`remoteentity/transaction_manager.go` 给每个实体回滚设置独立函数作用域，在 Lock 后立即 defer Unlock。保持一实体一锁的释放范围，不把全部锁累积到循环结束；仍由现有调用者处理 panic。

`remoteentity/batch_test.go` 新增跨 goroutine TryLock 回归。旧实现 overlay 失败，当前实现通过；七包 race/vet 和定向 race ×20 通过。此修复保证锁释放，不声称自定义钩子 panic 后业务回滚一定成功，也不新增忽略异常继续提交的语义。

慢 worker 仍通过 `entity.RunLocal` 委派本地回滚到快池。没有修改 WAL、事务确认或网络协议。本轮未部署、未重复真实存储性能压测；实际验证范围见复核记录。
