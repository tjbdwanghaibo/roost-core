# RR-20260927-18 修复：game-demo 场景在自建的 entitysync Manager 上接卸载后重载

问题：[RR-20260927-18](../bug/RR-20260927-18.md)（来源 [OPEN-ITEMS-2026-09-27 B25](../review/OPEN-ITEMS-2026-09-27.md)）。
日期 2026-09-27。实施基线：main `d4234c9`，分支 `fix-r7-sync`。状态：已修复，本地验证通过，已本地提交，未推送 / 未发布。
图谱说明：codebase-memory 图谱已过期（09-26），以下行号与结论全部来自当前源码与生成工程实跑。

## 根因（基线行号）

- `demo/internal/service/game/scene.go.tmpl:212` 自建 `entitysync.Manager`；game-demo 不用 kit 的 `NewModWithEntitySync`，框架只在
  `kit/nest/nest_mod.go:175` 给 kit 自己的 Manager 调 `ConfigureUnloadResync`。
- `entity/manager_access.go:598-601`：`Unload` 关闭实例的同步状态后只通知接上的重载器；场景的 Manager 没接，所以没有重载、也没有 `Rebind`，
  重新加载出来的新实例也不会被绑回场景的 subject。

## 修复（按清单推荐：照 kit 的做法接线，处理停机顺序）

`demo/internal/service/game/scene.go.tmpl`：

- `Scene` 增加 `unloads`（`unloadResyncer`：`entity.ManagerAccess` 的 `ConfigureUnloadResync` 一个方法的接口，测试可以不建运行时）与 `stopUnloads`。
- `NewScene` 从注册表取 `mods.ModEntityRuntime` 的 `*entity.ManagerAccess`，取不到直接返回错误（生产装配一定有，服务 Init 稍后也要求它；
  缺了就等于没有重载，不做静默降级）。
- `Scene.Start` 在启动复制循环**之前** `ConfigureUnloadResync(bridge.manager, entity.UnloadResyncConfig{})`（默认配置，与 kit 相同；发布经 Nest 构造时
  绑定给 `ManagerAccess` 的 `NestMgr.RunLocal` 回快池，不另传执行器）；复制循环启动失败时一并停掉重载。
- `Scene.Close`：先 `stopUnloads`（在途重载离开、不发 remove、之后的卸载不再登记），再关 Interest 与 Manager，错误用 `errors.Join` 合并；停重载超时也
  继续关 Manager。服务 `Shutdown` 里 scene 最后关，但整个服务 Shutdown 先于 Mod 停止（`app/app.go` 先等 `svc.Shutdown` 再逆序停 Mod），所以重载
  先于 Nest 停止，与 kit “先停重载再停 Nest”的顺序一致。
- 一个 `ManagerAccess` 同时只能接一个重载器：工程若同时用 `NewModWithEntitySync`，scene 启动会返回“already configured”而不是静默不接。

执行位置：`schedule` 仍在 `Unload` 的调用位置（快池）只登记；重载 I/O 在框架的重载 worker 上；发布与 `Rebind` 走既有正式路径，scene 没有新增等待。

未采用：给场景另挂 `OnEntityLoaded → Rebind`——清单推荐只要求接 `ConfigureUnloadResync`，重载 worker 自己会对重载出来的状态调 `Rebind`
（`entity/unload_resync.go` `reloadOnce`），覆盖“卸载时仍有人看着”的全部情形；剩余边界见下文。

## 未验证项 / 风险

- 真实 Mongo + lease fence 下的端到端（投影积压超过租约、礼物扣除被跳过、场景观察者收到 Mongo 全量）没有跑，属于集成环境（批次 7）。
- 剩余边界：卸载时**没有**非 leaving 的订阅者（例如玩家自己的会话已丢、重开也放弃，且此刻没人看它）时框架不重载（RR-59 约束），场景也没有
  `OnEntityLoaded → Rebind`；之后业务把玩家重新加载出来，场景的 subject 仍绑在关闭的状态上，稍后进入视野的观察者收不到它，直到它离场重进。
  USER_GUIDE（“自建 entitysync 的装配需要自己在 `OnEntityLoaded` 里调用 `Rebind`”）要求的这半条接线本次未做，交主会话决定是否另立条目。
- Player 不是 Remote 实体，RR-39 路径在 demo 中不可达；接线对它同样生效。
