# NC-162 修复：capture 标记记住注册时的会话，重连后再次安装在新会话上注册

问题：[RR-20261005-NC-162](../bug/RR-20261005-NC-162.md)。2026-10-05，分支 `revn12`，基线 `45d4bc1c`。

## 决策

- 黑板标记 `capture:<key>` 的值从 `true` 改为注册时的 `*session.Session`；标记指向当前会话才是空操作，否则在当前会话上注册并更新标记。Close hook 只删除仍指向自己那次注册的标记。
- 新增 `captureMu` 串行化“查标记→注册→写标记”，同 key 并发安装不重复注册。
- 未采用：`SetSession` 自动把所有 capture 搬到新会话。那是新的隐式行为（剧本重连后通常重建自己的 watcher，自动搬迁会把推送喂给旧 watcher）；当前语义是“重连后剧本再执行一次安装步骤”，写进注释。

## 文件与行为

`robot/robot.go`；回归 `robot/capture_reconnect_promises_test.go`（重连后安装生效；同会话重复安装一条推送只投递一次，用哨兵推送确定前一条已分发，不靠 sleep）。无 API 变化；黑板 `capture:*` 键的值类型变了（仓内无读取方）。
