# RR-20260923-07 修复：不同政策相互撤销订阅，Group 关闭误退役共享实体

[问题与修前证据](../bug/RR-20260923-07.md) · [收尾验收](../feature/SYNC-COMPLETION-2026-09-23.md)

状态：已修复并验证，未发布。

## 修复

新增 SubscriptionSource：每个政策实例单独持有，重复订阅幂等替换自身 profile；生效视图按 LOD、Key、SchemaVersion 升序确定，回落发全量，最后来源释放才 remove。Group/Interest 关闭只释放自身来源，实体销毁由 Manager.Unregister 表达。

改动位于 `sync/entitysync/` 下的 subscriptions.go、subject.go、policy/direct.go、policy/group.go、policy/interest.go。不改变实体帧线格式，不新增包。

## 验证

`go test ./sync/entitysync/policy -run 'TestPoliciesReleaseOnlyTheirOwnSubscriptions' -count=1` 定向回归已通过。整块 race、调用方与构建结果统一记录在[收尾验收](../feature/SYNC-COMPLETION-2026-09-23.md#验收记录)，避免将定向通过等同全场景验证。

## 契约与限制

Group RemoveSubject/Close 不再自动退役实体，应用需显式 Unregister；Manager 原 API 只操作默认来源。不同权限视图是否允许同时持有仍由业务授权。真实游戏客户端、生产集群和多进程故障注入未在本轮运行。
