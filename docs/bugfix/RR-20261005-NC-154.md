# NC-154 修复：空 / 重复 candidate source 带诊断

[问题](../bug/RR-20261005-NC-154.md) · [本轮](../review/REVIEW-2026-10-05-n09-batch3.md)。已修复、声明场景验证，未发版。

## 根因与决策

`skill/skillcompose/validator.go` 的 source 循环在空 / 重复条目上只置 `Valid=false`，其余拒绝分支都追加诊断。补一条 `PROVENANCE_MISMATCH`（“candidate source is blank or duplicated”）。不改判定本身。

## 回归

`skill/skillcompose/validator_provenance_promises_test.go`：`TestValidateCandidateExplainsBlankOrDuplicateSources` 三个子用例（重复、空 id、空 digest）修前：

```
validator_provenance_promises_test.go:39: invalid report without PROVENANCE_MISMATCH: []skillcompose.Diagnostic(nil)
```

修后 ok；同一用例里合法 candidate 仍 `Valid=true`、无诊断。

## 未验证

skillcompose 仓内无正式调用方；O14（因果图与来源校验的设计局限）未改。
