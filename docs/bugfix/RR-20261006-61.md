# RR-20261006-61 修复：lockstep 指标名恢复 `lockstep.` 前缀并钉住

问题：[RR-20261006-61](../bug/RR-20261006-61.md)（F04-5）。基线 `a7285da6`，分支 `lockstep`，提交 `4ce70763`（与 RR-20261006-62～65 同一提交）。

## 根因

合仓提交 `c8249526` 改包路径时把指标名里的 `lockstep.` 一并删掉；指标名是散落在 `room.go` 里的字符串字面量，没有测试把它和 `OBSERVABILITY.md` 对上。

## 修复

- `sync/lockstep/room.go`：新增导出常量 `MetricFrames` / `MetricInputLate` / `MetricInputRejected` / `MetricCatchupFrames` / `MetricDesync`（`lockstep.frame.total` 等），7 处调用改用常量。房间标签未加（序列数随房间增长，不在本次范围）。
- 守卫 `TestRoomPromiseMetricNamesArePinned`（`sync/lockstep/room_risk_promises_test.go`）：换一个干净的 registry，走遍 Room 的每条计量路径，要求实际发出的名字集合恰好等于钉住的 5 个；常量值等于钉住集合；包内非测试源码里不许出现 `metrics.X("…")` 内联名字；5 个名字都必须出现在 `OBSERVABILITY.md`。
- `OBSERVABILITY.md` 小节标题改为 `sync/lockstep`，注明名字由守卫钉住；`lockstep.desync.total` 说明补上 NoMajority（RR-20261006-64）。

## 兼容性

指标名从裸名改回 `lockstep.*`。按裸名临时配过告警或仪表盘的，改回 `OBSERVABILITY.md` 里的名字。未部署。
