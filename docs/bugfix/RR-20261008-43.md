# RR-20261008-43 修复：outbox 游标跨页

问题见 [RR-43](../bug/RR-20261008-43.md)。正式 MongoCommitter/Backend 实现 `IRemoteCommitOutboxPager`，以 `(created_at, _id)` 严格排序、游标查询；同一时间写入也有稳定次序。恢复在本轮跨过失败项继续下一页，返回汇总错误；下一轮仍从头重试，游标不替代持久发布确认。

坏记录逐条交给发布验证，不能在加载一页时提前丢弃整页；无效内容不会标记 Committed。cursor 不前进明确报错，扫描受调用方 ctx 限制。旧自定义 storage 未提供新分页接口时保留旧页内语义；要承诺大量失败项后的进度，接入方必须实现该接口。公开旧方法保留，未修改 WAL/Mongo 文档格式。

回归覆盖同时间戳 257 条、失败页后的正常提交、坏记录留存；race ×3 通过。真实资源、吞吐和全仓结果见本轮唯一发布入口方案的验收段。
