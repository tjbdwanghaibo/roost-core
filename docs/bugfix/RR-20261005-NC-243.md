# NC-243 修复：旧动作 Cancel 失败只报告，新动作照常启动

问题：[RR-20261005-NC-243](../bug/RR-20261005-NC-243.md)。分支 `revn10b`，基线 `81d7cb16`，[本轮](../review/REVIEW-2026-10-06-noncore-n10b.md)，[证据](evidence/noncore-bugfix-20261006-n10b/README.md)。

## 修复

`applyStart` 里 finish 的错误改经 OnError 报告（`taskflow: replaced action <id>: ...`），继续启动新动作。旧动作照样被替换（已结束一次），新动作照常 Start。

文件：`actionflow/action_runner.go`、`actionflow/update_and_replace_promises_test.go`。

## 兼容

直接 Start 替换一个 Cancel panic 的动作时，返回 (ID, nil)，旧动作的 panic 经 OnError 报告（之前返回 (0, err)、新动作未启动）。B7 方案 §4.3 把 O-A4 记为“panic 处理选择、未改”；在延后语义下它违反了 B7 自己的 ID 承诺，所以按缺陷修。
