# RR-20261008-24 修复：缓存复制删除忽略版本，旧更新复活删除值

ReplicaSyncer 启动强制身份提取器与 ReplicaStore 原子能力；ReplicaLocalStore 以一条记录保存值/删除水位，同版本删除优先。默认 10000 键，满时拒绝新键，不淘汰水位。

真实 Replicator 经总线乱序发布、缺配置、容量、并发更新/删除与冲突测试，cache race 通过。泛型持久 Store 必须自行实现同事务持久水位，普通 LocalStore 不再可直接作为副本接收 Store。原信封已有 Version，无新线格式。

方案：[B6 生命周期](../feature/REFACTOR-2026-10-08-sync-lifecycle.md)。全仓和生成工程最终验收见交接 B6 节。修前/修后日志保存在 `artifacts/perf/remaining-fixes-20261007/roost-remaining-b6-*.log`。未推送、未发布。
