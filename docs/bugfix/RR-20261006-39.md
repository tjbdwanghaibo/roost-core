# RR-20261006-39 修复：能力表并入 Host 接口，删掉“未实现则跳过”的准入分支

问题：[RR-20261006-39](../bug/RR-20261006-39.md)。方案见 [B3 ③ §12](../feature/B3-3-HOST-CAPABILITY-TABLE-2026-10-07.md)。

## 决策

把 `HostCapabilityProvider` 并进 `skill.Host`，而不是保留可选接口、在 Runtime 入口处对没实现的 Host 返回错误：改动更小（Runtime 不再需要任何
“没实现怎么办”的分支，非测试代码只有 `RecordingHost` / `ReplayHost` 要补），业务漏写在编译期就报。空表是合法声明（什么都不支持）。

## 文件与行为

| 文件 | 改动 |
| --- | --- |
| `skill/host.go` | `Host` 嵌入 `HostCapabilityProvider`，契约注释补一条 |
| `skill/runtime_host_capability.go` | `hostCoversProgram` 直接 `host.HostCapabilities()`，删掉类型断言与跳过分支 |
| `skill/host_capability_check.go` | `CheckHostCapabilities` 直接取表 |
| `skill/replay.go` | `RecordingHost.HostCapabilities` 转发并记录（`host_capabilities`），`ReplayHost.HostCapabilities` 回放 |
| `skill/host_capability.go` | `HostCapabilityProvider` 注释 |
| `skill/owned_entity_test.go` | `TestOwnedEntityRuntimeFailsClosedWithoutOwnedHostContract` 按新语义改写（下节）；`hostWithoutOwnedContract` 如实声明没有召唤物 |
| `skill/host_capability_promises_test.go` | 删 `noSummonHost`（声明并入 `hostWithoutOwnedContract`） |
| `skill/host_capability_required_promises_test.go`（新） | 回归与守卫 |

**改写的既有用例**：`TestOwnedEntityRuntimeFailsClosedWithoutOwnedHostContract` 依赖的正是被删掉的跳过分支（它的 Host 不声明能力表，准入被跳过，
summon 到施法中途才被类型断言拒绝）。改成两层：如实声明没有召唤物的 Host 在准入处被拒（`ErrHostCapabilityMissing`，也是 `ErrHostContractViolation`）；
谎报 summon 的 Host 准入放行，施法中途的类型断言仍然兜底拒绝——原断言（`err == ErrHostContractViolation`、召唤物没有到达 Host）原样保留在这一层。

## 兼容

破坏性（线上未部署，不做兼容）：业务的 `skill.Host` 实现必须有 `HostCapabilities()`，否则编译不过；嵌入 `*skill.MemoryHost` 的自动得到。
旧的 `HostRecord` 录制回放会在第一次准入处报 `ErrReplayMismatch`（多了一条 `host_capabilities`），重录即可。digest、编译结果不变。
