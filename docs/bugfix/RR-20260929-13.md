# RR-20260929-13：global 迁移后旧路由 lease 可续期

状态：已实施并通过本轮定向回归，未发版。源码基线 `f46db3e7d504bbd73581aa4119baa71171352519`。

根因：续期只检查 incarnation，不核对当前 route 的 epoch/global/group。

实现：Acquire/Renew 依据 route 快照 CAS 并写后再核验；Lease/LiveGames 同样核验当前绑定。物理保留的旧 lease 不再是有效持有权，新 route 可重新 acquire。

改动：kit/service/global/service.go。

回归：`TestReviewLeaseCannotRenewAgainstChangedRoute`。修前证据保留在 [第一轮](../bug/REPRO-2026-09-29-services.md) / [第二轮](../bug/REPRO-2026-09-29-services-02.md)；RR-09 修前是源码接线缺口，其他项有动态 FAIL。正式行为回归位于对应包，含 race；排行及 session ABA 使用隔离真实 Redis。统一命令、实际计数与未测边界见 [本轮总记录](SERVICE-BUGFIX-2026-09-29.md)。

兼容与边界：没有让两个 store 变成事务；每次操作以核验时路由为准，核验之后仍可能迁移。跨模块消息必须继续携带 epoch fencing。
