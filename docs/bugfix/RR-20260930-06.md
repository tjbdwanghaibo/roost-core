# RR-20260930-06 · Attribute 生成文件退役

来源：[第三轮问题](../bug/REVIEW-2026-09-30-codegen-03.md#rr-20260930-06--attribute-删最后一个-profile-后旧实现仍留存)。修前隔离 CLI 删除唯一 `//roost:attribute` 后仍保留 `gen_player_profile_attribute.go`。基线 Core `da56c998`。

`codegen/internal/attribute/main.go` 现在按当前 profile 计算默认输出名，生成成功后扫描同目录 `gen_*_attribute.go`，只删除带 `tool/attribute` 生成头且不在当前集合内的文件。零输入与改名均适用；手写同名文件保留。显式 `-output` 仅处理该文件；多个 profile 共用单一 `-output` 现在报错，避免此前后写覆盖。

正式 `TestRunRetiresOnlyOwnedProfileAfterLastMarkerIsRemoved`、定向 race 与 Codegen 包回归通过。源码删除后若业务代码仍调用该 profile 的生成 API，需要业务方迁移；此修复未发布。
