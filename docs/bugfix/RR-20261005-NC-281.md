# NC-281 修复：持久状态默认值只能用在任何读写处都求得出的引用（state_default 列）

[问题](../bug/RR-20261005-NC-281.md) · [本轮](../review/REVIEW-2026-10-06-n09-batch6.md) · [求值上下文表方案](../feature/SKILL-EVAL-CONTEXT-TABLE-2026-10-06.md)。已修复、声明场景验证，未发版。

## 根因与决策

状态默认值在读 / 写处求值，读写处可能是施法流程、进程每一步或进程回调；编译期按施法作用域检查。

- **采用**：state_default 列只放在所有上下文里都求得出的引用：`$caster` / `$caster.position`（进程里是 owner，即同一施法者）与 `$cast.mode`；`$primary_target`、`$ability.self`、其余 `$cast.*` 求得出但值随读写处漂移，标 ~ 保持现状（O33 同类）；`$input` / `$memory` / `$local` / 进程专属引用不可用。position 状态没有字面量，默认值必须是引用，所以不能只允许字面量。
- 未采用：按“这条状态在哪些上下文被读写”逐条推导。要跨效果做可达分析，且默认值的语义仍随读写处变化。

## 文件与行为

`compile_typecheck.go`（`scopeFor(evalStateDefault)`）；`runtime_state.go` `evalStateDefault` 在 state_default 上下文里求默认值。

## 回归

`TestCompileRejectsStateDefaultsThatCannotBeEvaluatedEverywhere`（修前：`state default "$input.target" compiled; casting it: skill: immutable program invariant failed`；memory 子用例修前是 `LOWER_UNRESOLVED`）→ 修后 ok；控制 `TestStateDefaultOfTheCasterRunsInCallbacks`。性质测试新种子 `seed.state_default_context` 在 state_default 列临时放开 `$input.*` 时当场报 `… default=$input.target: … immutable program invariant failed`。验证：`GOWORK=off`，`go test -race -count=3 ./skill/...`、`SKILL_MUTATION_FULL=1` 性质测试、根包、`go build ./... && go vet ./...`，见 [N09 第六批 §5](../review/REVIEW-2026-10-06-n09-batch6.md#5-修复与验证)。

## 兼容性

行为收紧：状态默认值读 `$input` / `$memory` 的定义被拒（前者此前在回调里读写即失败，后者此前已因 lower 失败）。仓内状态默认值只有字面量。
