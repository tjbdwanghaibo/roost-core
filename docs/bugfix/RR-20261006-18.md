# RR-20261006-18 修复：派发器排空停止后删除自己的 dispatcher 序列

问题：[RR-20261006-18](../bug/RR-20261006-18.md)。分支 `oa`，基线 `ac913a60`，未发版。只碰派发器指标的生命周期，不改调度、准入或停机顺序。

代码阅读：codebase-memory generation 09-30，`nest/dispatcher.go`、`dispatch_queue.go` metadata_match；本轮以当前源码为准。

## 决策

- **拥有者是“以这个名字运行的派发器”，按名字计数**：`OnInit` 登记（`holdSeries`），`OnDestroyWithContext` 里 `queue.stop(ctx)` 返回 nil 之后撤销（`releaseSeries`），
  同名的最后一个撤销时对 5 个带 `dispatcher` 标签的指标名逐个 `metrics.DeleteSeries(name, {dispatcher: <名字>})`。不按“谁销毁谁删”：生产里 NestMgr 的派发器都叫
  `"nest"`，同一进程两个同名派发器写同一组序列（测试里常见），先销毁的不能删掉另一个还在报的。
- **停机超时不删**：`queue.stop` 返回 ctx 错误时 worker 仍在跑、还会写 `slow_reroute`，保留；重试排空后再删（停止入口三步：排空之后才释放）。
- **上报与删除互斥**：`observeStats` 在包级锁下确认本派发器仍持有序列再写，所以与撤销并发的一次上报不会在删除之后把序列建回来。上报每 1024 次投递一次，锁不在热路径。
  `slow_reroute` 只在 worker 里写，排空后不会再写。
- 指标名列表 `dispatcherSeriesNames` 写在 `nest/dispatcher_series.go`，新增带 `dispatcher` 标签的指标要加进去（注释写明）。没有用“任意名字 + 标签匹配”删除：
  标签键 `dispatcher` 不归 nest 独占。

## 改动

- `nest/dispatcher_series.go`（新）：登记表、`holdSeries` / `releaseSeries` / `reportSeries`。
- `nest/dispatcher.go`：`seriesName` 字段；`OnInit` 登记；`OnDestroyWithContext` 排空后撤销；`observeStats` 经 `reportSeries` 上报（`observePoolStats` 改为包级函数）。
- `nest/dispatcher_series_lifecycle_promises_test.go`（新）。

## 兼容

已销毁派发器的序列从 `/metrics` 消失（修前停在最后的值）。生产单个 NestMgr 的 `nest_dispatch_*{dispatcher="nest"}` 在进程运行期间不变，停机排空后才删除。

## 补测：`slow_reroute.total` 的删除（2026-10-06，分支 `tail`，未发版）

上面“未验证”一项已补：`nest/dispatcher_series_lifecycle_promises_test.go` 的 `TestTheSlowRerouteSeriesGoesWithItsDispatcher`。

- 触发：真实 `NestMgr`（1 个快 worker、2 个慢 worker，派发器改用本测试独有的名字 `rr18-series-reroute`，避免其他用例的同名 "nest" 派发器持有序列），
  blocker 占住快 worker，期间对已加载目标发一条请求（准入走快池），再驱逐目标；快池首跑发现声明目标变冷，作业原位转慢池（与
  `TestDeclaredTargetEvictedAfterAdmissionMovesToSlowKeepingOrder` 的 “before lookup” 窗口相同）。断言请求成功、`nest.dispatch.slow_reroute.total{dispatcher=rr18-series-reroute}` 存在且为 1。
- 销毁：`mgr.Shutdown(ctx)` 返回 nil 后，断言这条序列不在 `metrics.Snapshot()` 里，`/metrics` 文本里也没有这个派发器名。
- 变异证明能红（不提交）：临时从 `dispatcherSeriesNames` 删掉 `"nest.dispatch.slow_reroute.total"`：

  ```text
  --- FAIL: TestTheSlowRerouteSeriesGoesWithItsDispatcher (0.00s)
      dispatcher_series_lifecycle_promises_test.go:214: the dispatcher rr18-series-reroute is shut down and nest.dispatch.slow_reroute.total still reports 1
  ```

  恢复后通过。`nest/dispatcher_series.go` 未改动，只加测试。
- 验证：`GOWORK=off go test -race -count=3 ./nest` ok，`go vet ./nest`，glsvet 退出 0。
