# RR-20261008-28 修复：玩家推送连接缺少心跳和每连接限流

鉴权后 MsgID0+空载荷+flags0 的递增序号帧为心跳，返回同序号空 ACK；默认 heartbeat_enabled=true。令牌桶默认100次/秒、burst200，心跳也扣令牌，request_rate=0显式关闭。

真实 TCP 连接连续心跳跨越 idle_timeout 仍在线，停止心跳后断开；每连接独立限流，超额断开，关闭限流正常。正式生成 TCP race 通过。

方案：[B6 生命周期](../feature/REFACTOR-2026-10-08-sync-lifecycle.md)。全仓和生成工程最终验收见交接 B6 节。修前/修后日志保存在 `artifacts/perf/remaining-fixes-20261007/roost-remaining-b6-*.log`。未推送、未发布。
