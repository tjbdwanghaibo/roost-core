# NC-247 修复：同签名不同命名时转换；无法转换时回落并计入 ResolveMismatches

问题：[RR-20261005-NC-247](../bug/RR-20261005-NC-247.md)。分支 `revn10b`，基线 `81d7cb16`，[本轮](../review/REVIEW-2026-10-06-noncore-n10b.md)，[证据](evidence/noncore-bugfix-20261006-n10b/README.md)。

## 修复

`Resolve[T]` 先做类型断言（快路径不变）；失败时若 T 是函数类型且注册的值可转换（底层签名相同），`reflect.Value.Convert` 后返回；无法转换时回落 fallback 并给该点的 `mismatches` 计数，`PointInfo.ResolveMismatches` 在 `hotcode.list` 里可见。

文件：`hotcode/registry.go`、`hotcode/patch_visibility_promises_test.go`。

## 兼容

新增 `PointInfo.ResolveMismatches` 字段（只增）。同签名不同命名的调用方现在拿到补丁（每次调用一次反射转换，只在类型不一致时发生）。签名确实不同时行为不变（回落），只多一个计数。
