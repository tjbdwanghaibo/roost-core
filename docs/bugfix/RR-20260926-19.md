# RR-20260926-19：租约跳过必须有确定结论

实施基线：main `381efc9` 加上一轮 RR-03～09 的未提交修复；原报告基线 `aaada47` 保留。
状态：代码已修复，适用本地验证通过，尚未提交/发布。完整证据和限制见[本轮汇总](../review/REVIEW-2026-09-26-release-fixes.md)。

## 修复与依据

新的 Remote mutation + lease-fence receipt 组合在 Projector reserve、写 WAL 前返回 ErrRemoteLeaseFenceUnsupported，让 Nest 在 Guard 内完整回滚。历史 WAL 的 skipped 记录仍可回放：同一 Mongo 事务内写入 digest 绑定的 Remote Rejected 记录，投影后通知 tracker；Admitted/Indeterminate 状态可回源查询，finalizer 能终止等待。

涉及：`dataengine/engine/projector.go`、`mongo_projection.go`、`remoteentity/backend.go`、`mongo_committer.go`、`transaction_tracking.go`。

## 验证

TestRemoteLeaseFenceRejectedBeforeWALAdmission（三种入口）；TestMongoStoreSkippedLeaseFenceNeverPublishesRemoteCommit；TestMongoRejectedTransactionIsDurableAndDigestChecked；TestDurableLeaseRejectionReleasesDeferredWriteGate；TestAdmittedTransactionStatusRefreshesDurableRejection。命令、负对照范围与环境见汇总；没有把全部测试绿色当成生产故障已穷尽。

## 兼容与边界

采用原问题允许的“准入时禁止组合”。生成 Entity 的 RollbackRemoteCommit 不保存完整跨实体前像，不能宣称支持投影阶段事后撤销内存事务。自定义 remoteStore 回放历史混合记录必须实现 RejectRemoteCommitsInTransaction，否则明确报错且不 ack。

实施基线：main `87d9499`。状态：回归与文档已补，已本地提交，未推送/发布。实现（`projector.go` 的 `reserve` 准入检查）未改动。

### 残留

(1) `TestRemoteLeaseFenceRejectedBeforeWALAdmission`（`dataengine/engine/projection_lifetime_test.go`）用空 `RemoteCommit` 与只有 Namespace 的 receipt：
修前记录在 WAL 规范化阶段就因 invalid identity / invalid receipt 被拒，“没有写进 WAL”这一承诺对该夹具修前就成立，构不成负对照。
(2) SAGA.md 没写原生步骤不能写 Remote 实体，以及被拒后的实际表现（重投得到 Duplicate 并等到 deadline，而非立即业务拒绝）。

### 修改

- 回归改用 WAL 会接受的夹具：`remoteProjectionRecord`（合法 RemoteCommit：身份、版本、ownership epoch、数据 mutation 齐全）+
  `coredata.NewLeaseFenceReceipt` 生成的合法 lease-fence receipt；先用 `coredata.ValidateCommitRecord` 证明夹具合法。三个入口（Commit / Enqueue / CommitSystem）
  各用独立事务、逐个 `t.Errorf`，最后断言 WAL 回放 0 条、WALUnacked 与 ticket 无泄漏。
- `SAGA.md` 在 native step 一节补“原生步骤不能修改 Remote 实体”：准入时拒绝（`engine.ErrRemoteLeaseFenceUnsupported`）、原因（lease 失效跳过整笔记录，
  而生成 Entity 无法在投影阶段撤销跨实体内存修改）、被拒后的消息重投表现，以及当前只能把 Remote 修改放在 Saga 之外的幂等 Remote 事务里。
