# RR-20261004-NC-03：JSON schema 容器所有权

2026-10-04，修前 `7e0d6ee2`。[原问题](../bug/REVIEW-2026-10-04-noncore-02.md#rr-20261004-nc-03)。已修复、声明场景验证，未发版。

根因在原 admin/admin.go:255–280：空 map 未复制，[]any 只复制槽位。cloneMeta 现在统一复制非 nil map（保留 nil），复用 cloneMap 并增加一个同包递归 JSON value helper，map、嵌套 []any、[]string 都隔离，nil/空容器保持原语义。TargetScope 同时用标准库 slices.Clone 保持其复制与 nilness。

没有引入反射序列化、第二套 registry 或把所有非 JSON 对象当作可复制值。PayloadSchema 注释明确：非 JSON 扩展值须不可变，循环对象不属于 JSON；caller 也不能在 Register 尚未完成时并发改输入。普通 Risk/Approval 值字段及审批策略不变，此修复不是新增鉴权。

六个正式修前反例在 Register 输入、Get/List 输出修改后读到 injected；修后同断言保持 string/空 map。追加 8 个 nil/空容器对照、嵌套数组/字符串、16 个消费者各 20 次 Get/List 后修改自身副本的 race 场景，通过。[证据](evidence/noncore-bugfix-20261004-02/README.md)。正式回归 admin/schema_ownership_promises_test.go，T-189。

公开签名、存储格式不变，不迁移数据。递归复制成本随 schema 大小增加，本批未 benchmark 大 schema；超深/循环输入和自定义可变对象未验证/不承诺自动复制。
