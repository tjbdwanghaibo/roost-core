# RR-20261008-42 修复：有界 Layered 准入元数据

问题见 [RR-42](../bug/RR-20261008-42.md)。沿用一个锁和 map，增加准入顺序链表：覆盖更新原节点，插入时回收队首过期项并按容量淘汰最旧项，删除同步撤销两处索引。无后台 goroutine、无全表定时扫描。

`NewLayeredStore` 增加可选 `LayeredOptions{MaxExpiryEntries: n}`，缺省 65536；既有调用不变。到达 TTL 截止时间即过期。没有远端的纯本地装配不保留这份无用元数据。

淘汰只撤销直接服务 L1 的资格，不删除权威值或 L1 值；下一次访问重新回源。容量过小可能增加回源次数，不改变数据准入规则。冷键在完全空闲期间最多保留容量上限，下一次准入回收已过期队首，不宣称 idle 时自动清零。

修前 70000 条元数据的失败已保留。修后 cache 全包 race ×3 通过（4.070s），覆盖高基数冷键、覆盖写不积累旧节点、冷过期回收、删除和淘汰后读到远端新版本。全仓验收及长稳在本轮总报告记录。
