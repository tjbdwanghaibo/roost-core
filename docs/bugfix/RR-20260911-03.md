# RR-20260911-03:finalizer 停止后晚到的 Close 遗留资源

**仓库 / 位置**:roost-core `remoteentity/transaction_manager.go`,`deferRemoteClose`。
**修复单元**:U-0173(C8)。**定位文档**:TROUBLESHOOTING T-67。

## 问题

停止前取得的 `RemoteWriteBatch` 进入 Indeterminate,`StopFinalizer` 成功返回**之后**才执行
`Close`。`deferRemoteClose` 的 select 同时面对一个还写得进去的缓冲队列和一个已经关闭的
`finalizeCtx.Done()` —— 两个都就绪时 Go 随机选,于是它仍然可能选择入队并返回 nil。

`batch.Close` 据此认为交接成功、不再自己清理。而最终 drain 只等 finalizer workers 与 retryWG,
**外部发送者不在这道屏障里**。结果是 entries、writeGate、ownership 读锁与 finalize slot 都留在
那儿,`finalizeOnce` 又不让重启来收拾。

## 根因

停止与外部发送者之间没有共用的准入屏障。重试路径已经有一道:它在 `retryMu` 下读 `stopping`,
并由 `retryWG` 让 drain 等到它发完。`deferRemoteClose` 没有参与,只靠一个 select 分支"碰运气"
地退出 —— 而 select 的随机性正好让这件事变成概率问题:64 次调用里实测有 33 次被接受。

## 方案选择

- **select 之前先查一次 ctx。** 消除不了窗口:查完到入队之间仍可能发生停止,而且 select 本身
  的随机性也还在。
- **让 drain 也等外部发送者,但不设准入。** 停止会被无限期拖住 —— 外部 Close 可以在任何时候来。
- **接入同一道准入屏障(采用)**:在 `retryMu` 下读 `stopping`,未停止就 `retryWG.Add(1)` 再放锁
  发送。`StopFinalizer` 在同一把锁下置 `stopping`,所以此后没有新发送者被接纳;而
  `runRemoteFinalizers` 在最终 drain 之前 `retryWG.Wait()`,所以已被接纳的发送者一定被排空。
  每份 entries 与 slot 恰好一个清理者:被接纳的归 drain,被拒绝的由 `batch.Close` 同步清理。

不会死锁:即便队列已满、workers 已退出,select 的 `finalizeCtx.Done()` 分支仍会放行,而那个
分支在 `StopFinalizer` 取消 ctx 时就已就绪。

## 改动

`remoteentity/transaction_manager.go`:`deferRemoteClose` 前置准入检查与 `retryWG` 注册,
注释写明为什么必须在锁下判定而不是靠 select 分支。

## 证明

`remoteentity/finalizer_stop_handoff_promises_test.go` 两条:

- `TestDeferredCloseIsRefusedOnceTheFinalizerHasStopped`:停止完成后连做 64 次交接,必须**全部**
  被拒(一次可能靠运气选中 Done 分支,64 次不可能),并断言队列里没有残留。
- `TestDeferredCloseAcceptedBeforeTheStopIsStillDrained`:停止之前的交接必须被接受,并在停止
  返回后已被排空 —— 拒绝它和接受得太晚一样错,因为调用方已经交出了 entries 的所有权。

修前红:

```text
33 of 64 deferred closes were handed to a queue nobody drains; their entries and finalize slots leak
```

修后 `go test ./remoteentity -race` 绿,core 全仓绿。

## 未做 / 边界

- 测试在 `deferRemoteClose` 这一层证明交接契约,没有构造 64 个真实 batch 走完
  prepare / finalize / Close。审查附录里那条是更强的端到端证据。
- 分布式锁的遗漏解锁在审查里是源码推断,本轮同样没有连真实 Redis 验证;修复消除的是交接窗口
  本身,所以那条推断的路径一并消失。
- `finalizeOnce` 不允许重启的设计没有改。
