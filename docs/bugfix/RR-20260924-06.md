# RR-20260924-06 修复：串行化 Ticker 生命周期转换

[问题与修前证据](../bug/RR-20260924-06.md)。已修复，未提交、未发布。

[ticker.go](../../nest/ticker.go) 使用一个 lifecycleMu 保护 started/stopped 和 stopChan 的关闭。Start 的检查与启动登记、Stop 的停止登记与关闭属于同一临界区；done 等待在锁外。多个 Stop 都等待同一个 run 结束，Stop 先到则后续 Start 不启动。

保留一次性启动、重复 Stop 和 tick 计数原有语义，不增加包或公开 API。周期回调快照的注册时复制优化是独立的分配改进，不参与生命周期正确性。

20,000 次竞争回归及 Nest race 已通过，相关包、编译和性能结果见 [收尾验收](../feature/NEST-COMPLETION-2026-09-24.md)。生命周期测试用显式通道/WaitGroup 排序，不依赖 sleep 猜测循环是否启动。
