# NC-64 修复：开关热更说明改成 reload 真正读取的文件

问题：[RR-20261005-NC-64](../bug/RR-20261005-NC-64.md)。2026-10-05，分支 `revn07b`，基线 `3d4fe9f3`。

## 根因

`gm.config.reload` / `gm.flag.set` 的说明与 flags 两处包注释把运维步骤写成“改 `configs/table/featureflag.csv` 再 reload”。reload 只读 `config_data.dir` 下的 JSON（`configdata/configdata.go:781` → `build`），CSV 只在 `roost generate` 时转成 JSON；文件名也写错。

## 决策

只改说明，不改行为：

- 让 reload 也读 CSV：会把 cfggen/tablegen 的转换与 required / unique 校验搬进运行时，发布物也不带 CSV，属于设计变化，未采用。
- 说明里写两条路径：线上直接改 `configs/data/feature_flag.json`；在源码树里改 CSV 的，先 `roost generate` 再 reload，并明确“reload 从不读 CSV”。

## 文件与行为

- `demo/internal/service/game/gm.go.tmpl`：`gm.config.reload`、`gm.flag.set` 的 Description；在 reload 定义处加注释说明为什么这样写（RR 编号；模板注释沿用英文）。
- `demo/internal/service/game/flags.go.tmpl`、`demo/game/flags/flags.go.tmpl`：包注释改成运行时读的是 JSON、CSV 经 generate 生效。
- `docs/feature/GAME_DEMO_TEMPLATE.md` §9.9.1 补一句。

没有行为、API、生成形状变化（只是字符串与注释）。
