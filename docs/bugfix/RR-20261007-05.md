# RR-20261007-05 修复：统一校验事务标记保留期

[问题与原始失败](../bug/RR-20261007-05.md) · [方案](../feature/REFACTOR-2026-10-07-remaining-core.md)

AssemblyConfig.ValidateReceiptRetention 共用校验：Kit 的配置加载与直接 Assemble 均执行。按 Mongo 整秒精度，事务标记 TTL 必须严格大于 WAL MaxUnackedAge；默认分别为 720h、24h。默认值与 MongoStore 共用，避免装配和 Store 各自推算不同默认值。

旧配置低于或等于窗口时启动拒绝，不改变 Mongo 写入、去重与 WAL 回放。长停机或积压超过标记保留期时仍须人工核对持久状态，不能盲目重放；健康阈值不是恢复期限保证。

Kit 与 engine 整包测试已通过；新增直接装配边界与组合 race 正在验证。尚未执行的全仓、真实 Mongo 索引检查不计入通过。本次未改持久格式、未发布。
