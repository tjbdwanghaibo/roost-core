# NC-262 修复：seq 非 0 且没有等待者的包丢弃，计 robot.session.late_response

## 修复

`dispatch`：seq 非 0 而 pending 里没有这个 seq，计 `robot.session.late_response{msg}` 并返回，不进入推送分发。seq 0 的包行为不变。

文件：`robot/session/session.go`、`robot/session/session_promises_test.go`、`OBSERVABILITY.md`。
