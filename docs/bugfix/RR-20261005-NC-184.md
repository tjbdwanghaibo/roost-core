# NC-184 修复：拓扑排序按参与排序的全部节点判环

[问题](../bug/RR-20261005-NC-184.md) · [证据](evidence/noncore-bugfix-20261005-revn13/README.md) · [本轮](../review/REVIEW-2026-10-05-n13.md)。已修复、声明场景验证，未发版。

## 根因与修法

`container/topologic_sort.go` 判环用 `len(sorted) != len(allComponents)`，而 `sorted` 里还有只作为依赖出现的未注册节点。改为与 `len(inDegree)`（参与排序的全部节点）比较：未注册的依赖按叶子排在依赖它的节点之前；有环时至少一个节点入度不归零，返回 nil。

同序节点顺序不确定、返回内部切片等（本轮 O4）不在本条范围，未改。

## 兼容

依赖了未注册节点的调用方，之前得到 nil，现在得到包含该节点的排序结果。仓内零调用方。

## 验证

- 修前：`TestTopologicalSortHandlesUnregisteredDependencies` `got [], want [B A]`（[原文](evidence/noncore-bugfix-20261005-revn13/red.txt)）；掩盖环的一支探针返回 `[Y X C]`。
- 修后：两支均通过；既有 `TestTopologicalSort` 通过；`go test -race -count=3 ./container` 通过。
