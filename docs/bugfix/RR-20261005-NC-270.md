# NC-270 修复：terrain 指针 Init 后不再改；Stop 只置 atomic stopped

问题：[RR-20261005-NC-270](../bug/RR-20261005-NC-270.md)。分支 `revleft`，基线 `dc877c04`，[本轮](../review/REVIEW-2026-10-06-revleft.md)，[证据](evidence/noncore-bugfix-20261006-revleft/README.md)。

## 修复

`PathFindSystem` 加 `stopped atomic.Bool`，`Stop` 只置它；`Path` / `Place` 先看 `stopped`。terrain 指针 Init 后不再改，地形停止后由 TerrainSystem 自己回答 “stopped”（它自带读写锁）。停止后的寻路仍返回错误（既有 `TestStoppedSystemsAnswerInsteadOfPanicking` 不变）。

文件：`demo/game/scene/runtime/pathfind.go.tmpl`、`demo/game/scene/runtime/runtime_test.go.tmpl`。

## 兼容

生成形状变化只在这两个模板；新生成 / 升级的 game-demo 得到修复，已生成的工程需重新生成或手工同步。
