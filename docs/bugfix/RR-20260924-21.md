# RR-20260924-21 修复记录

问题见 [RR-21](../bug/RR-20260924-21.md)。已修复并验证，未发布。

脚本执行 INCR 后 GET 精确十进制 fence，版本直接返回 HGET 字符串。Go 沿用已有 strconv.ParseInt，不经过 Lua 浮点数；Redis 存储格式不变。

真实 Redis 的 2^53+1 和 MaxInt64 均 race 通过，普通版本读回、到期后 fence 增长、交接和旧 owner 拒绝同时通过。日志 `/tmp/roost-remote-ownership-real.log`；命令与关联包回归见 [第二轮实施](../feature/REFACTOR-2026-09-24-remote.md#第二轮启停与锁代际)。

计数仍受 Redis 有符号 int64 的 INCR 上限限制，没有扩为 uint64 或自动重置。耗尽后的资源状态修复见 [RR-22](RR-20260924-22.md)。
