# RR-20261006-31 修复：tick 驱动的停止被宿主拒绝时转为待停止，Runtime 继续前进

问题：[RR-20261006-31](../bug/RR-20261006-31.md)。基线 `90c92caf`，分支 `skretry`（与 RR-20261006-21 后续同一提交），未发版。
读代码：codebase-memory 共享 generation 停在 09-30，以当前源码为准；停止入口用 `rg 'terminateProcess\(|terminateOwnedProcess\(|stopOwnedProcess\(' skill/` 穷举。

## 根因

tick 驱动的停止失败后进程仍是 running、仍到期，`Advance` 的循环每次先重做它（`ownedDue <= currentTick` 分支），失败即返回，`advanceHost` 走不到。错误语义是“这次失败了”，实际效果是“之后永远卡在这里”。

## 方案取舍

| 方案 | 结论 |
| --- | --- |
| ① 宿主拒绝停止时转为待停止（复用 RR-20261006-21 后续的 `stop_pending` 与退避重试），从 owned 表摘掉；错误照常返回这一次（采用） | 与维护者 2026-10-06 的决定（技能自己启动的东西由技能自己收尾）一致；只多一个入口 `deferRefusedStopLocked`，重试、上限、告警、内存上限、checkpoint 全部共用 |
| ② 吞掉错误、下个 tick 原样再试 | 未采用：每 tick 打宿主，无上限 |
| ③ `Advance` 遇到停止失败也先推进 host tick | 未采用：进程仍到期，下一 tick 照样重做，只是从“卡住”变成“每 tick 失败一次” |

`terminateProcess` 出错不一定是宿主拒绝（回调、区域信号、carry 解除也会出错）；只有出错后进程仍是 running 才说明 `StopProcess` 失败，`deferRefusedStopLocked` 以此为判据。`Shutdown` / `RemoveProgram` 是调用方驱动、由调用方重试（`TestOwnedProcessStopFailureRemainsTrackedForRetry`），不改。

## 文件与行为

| 位置 | 改动 |
| --- | --- |
| `skill/runtime_process_stop_retry.go` `deferRefusedStopLocked`、`markStopPendingLocked`（新） | 标成待停止、从 owned 表摘掉、发一条 stop_pending 的 process_update |
| `skill/process_owned.go` `terminateOwnedProcess`、`reapUnhandedEntityProcesses` | 停止出错后调 `deferRefusedStopLocked` |
| `skill/runtime_process_stop_retry_promises_test.go` | `TestHandedOffProcessStopFailureDoesNotFreezeTheRuntime` |

## 兼容性

`Advance` 在宿主拒绝停止的那一 tick 仍返回错误；之后不再返回同一个错误、tick 照常前进。待停止的移交进程不再出现在 `OwnedProcesses`（Runtime 不再推进它），在 `StateSnapshot().Processes`（`status: stop_pending`）与 `RetentionStats()` 里可见。

## 回归（`GOWORK=off`）

- 红：修前探针文本见问题记录（`Advance(4..6)` 全部失败、tick 停在 4、宿主同一 tick 被打四次）。
- 绿：`TestHandedOffProcessStopFailureDoesNotFreezeTheRuntime`——宿主前两次拒绝；只有 `Advance(4)` 返回错误，tick 走到 20，`StopProcess` 在 4、8、16 调用，第三次成功，end 回调一次，`OwnedProcesses` 为空。`TestOwnedProcessStopFailureRemainsTrackedForRetry`（RemoveProgram 由调用方重试）不变通过。
- 整体验证见 [RR-20261006-21 修复的后续一节](RR-20261006-21.md#后续runtime-负责重试停止维护者-2026-10-06)。

## 未验证 / 风险

无外部依赖。到期进程的 end / cancel 回调在第一次停止时跑过，重试只重发宿主停止，不再跑回调。
