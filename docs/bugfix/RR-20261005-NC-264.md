# NC-264 修复：标签值只转义反斜杠、双引号、换行，非法 UTF-8 换成 U+FFFD

问题：[RR-20261005-NC-264](../bug/RR-20261005-NC-264.md)。分支 `revleft`，基线 `dc877c04`，[本轮](../review/REVIEW-2026-10-06-revleft.md)，[证据](evidence/noncore-bugfix-20261006-revleft/README.md)。

## 修复

`prometheusLabelValue` = `strings.ToValidUTF8(v, "\uFFFD")` 后经 `strings.NewReplacer` 转义 `\`、`"`、换行。普通 ASCII 值输出与之前逐字节相同（`strconv.Quote` 对它们的转义与格式一致）。`# TYPE` 行仍不输出（O4 前半，未定类型的序列抓取器按 untyped 处理，不是缺陷）。

文件：`metrics/prometheus.go`、`metrics/prometheus_escape_promises_test.go`。

## 兼容

含制表符、非 ASCII 不可打印字符或非法字节的标签值，导出文本变了（现在合乎格式）；普通值不变。
