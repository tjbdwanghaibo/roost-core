# RR-20261001-03 · schema 已写、`configs/table` 还没有 CSV 的工程 `roost generate` 失败（v1.17.2 → v1.18.0 回归）

来源：[RR-20261001-03](../bug/RR-20261001-03.md)（独立复审 §4-D1）。基线 main `2308e37f`。P2。

## 根因

`153cac3d`（[RR-20260930-09](RR-20260930-09.md)）把 `codegen/internal/roost/generate.go:107-116` 的 config-data 步骤从"`configs/table` 没有数据文件就跳过"改成"没有数据文件但 `configs/data/_manifest.json` 存在就运行 tablegen"，目的是让零 meta 的 JSON 退役进入暂存树。但脚手架（`render.go:146`）总会写出 `_manifest.json`，`project sync` 也会写回，所以旧的跳过分支实际已死；`tablegen.convertCSVToJSON`（`tablegen/main.go:365`）对每个 meta 无条件 `readCSVRecords(csvDir/meta.File)`，第一个 meta 的 CSV 不存在即 `open configs/table/<file>.csv: no such file or directory`。标准脚手架 + 写好 schema + 还没放 CSV 这一 v1.17.2 容忍的状态，HEAD 的 `generate` / `generate --check` / `project sync` 全部失败。

## 决策与未采用方案

采用 (a)：CSV 目录为空时，只有 manifest `tables` 非空（确有登记过的 JSON 可退役）才运行 tablegen，否则仍跳过。理由：保持 v1.17.2 的"还没有 CSV 就跳过"语义，RR-09 的退役能力完整保留（schema 和 CSV 一起删掉时 manifest 仍登记文件，tablegen 照常运行并退役），v1 manifest（`tables` 恒空）与脚手架的空 v2 manifest 都回到跳过。manifest 的解析放在 tablegen 包的 `ManifestOwnsJSON`，roost 不复制 manifest 形状。

未采用 (b)"缺 CSV 改成点名 meta 的明确错误并登记为行为收紧"：它把已发布 v1.18.0 的静默回归正式化，让每个还没写 CSV 的新工程都过不了 `make generate` / CI `--check`，而这种状态没有数据风险，没有理由收紧。

(a) 留下的边界：**保留 schema 但删掉它的 CSV、而上一轮 JSON 仍登记在 manifest 里**，tablegen 会运行并报 `open configs/table/<file>.csv: no such file`（v1.17.2 在此静默跳过、留下过期 JSON）。这个状态要么补回 CSV，要么把 schema 一起删掉让 JSON 退役，已写进参考文档 §9.1；没有再把它改成点名 meta 的错误，以免越过本 RR 范围。

## 文件与行为

- `codegen/internal/roost/generate.go`：config-data 步骤在 `configs/table` 无数据文件时调用 `tablegen.ManifestOwnsJSON("./configs/data")`，`false` 跳过，`true` 运行 tablegen；注释写明为什么 manifest 存在不能当触发条件。
- `codegen/internal/tablegen/main.go`：新增导出 `ManifestOwnsJSON(jsonDir) (bool, error)`——manifest 不存在 → false；无法解析 → `read table manifest: …`（与 `convertCSVToJSON` 同一文本）；否则 `len(tables) > 0`。
- `codegen/internal/roost/table_without_csv_promises_test.go`：`TestGenerateSkipsConfigDataWhenSchemaHasNoCSVYet`——脚手架 + schema + 空 `configs/table`，`Generate` 通过、不写 `monster.json`、`checkGenerated` 通过。
- `codegen/docs/CODEGEN_REFERENCE.zh-CN.md` §9.1：config-data 何时运行 / 跳过与上述边界。
- `docs/bugfix/RR-20260930-09.md`：末尾追加后续。

## 兼容性

恢复 v1.17.2 的跳过语义，不改生成物形状、manifest 格式或 tablegen CLI 行为；直接调用 `tablegen -csv -json` 的用户不受影响。RR-09 退役路径（schema + CSV 一起删）不变。
