# RR-20260923-04 修复：在途交付覆盖新的会话或订阅意图

[问题与修前证据](../bug/RR-20260923-04.md) · [收尾验收](../feature/SYNC-COMPLETION-2026-09-23.md)

状态：已修复并验证，未发布。

## 修复

保存捕获时的会话状态引用，逐帧比较并采纳；错误清理只针对原状态。订阅记录 lifetime、revision 与 inFlight，旧结算不覆盖新意图，在途 create 的退出保留为 leaving。Ready 对已 ready 会话保持幂等。

改动位于 `sync/entitysync/` 下的 session.go、subscriptions.go、subject.go、flush.go。不改变实体帧线格式，不新增包。

## 验证

`go test ./sync/entitysync -run 'TestInFlightDeliveryCannotOverwriteNewIntent' -count=1` 定向回归已通过。整块 race、调用方与构建结果统一记录在[收尾验收](../feature/SYNC-COMPLETION-2026-09-23.md#验收记录)，避免将定向通过等同全场景验证。

## 契约与限制

会话重置或关闭不能撤回 Transport 已准入的字节；传输必须把在途请求固定到原连接。真实游戏客户端、生产集群和多进程故障注入未在本轮运行。
