# RR-20260929-22：Account Profile 返回所有权

状态：已实施，Memory/真实 Redis 对照通过；未发版。[原问题](../bug/REVIEW-2026-09-29-services-03.md#rr-20260929-22) · [本批验证](SERVICE-BUGFIX-2026-09-29-03.md)。

UpdateProfile 仅复制输入，返回值与 MemoryStore 保存的切片仍别名；ValidateSession 直接返回持久 Role。返回值修改可改变存储数据而不递增版本。

Role 增加私有 clone；UpdateProfile 保存与返回分离，ValidateSession 返回私有 Profile。新的 CreateRole 恢复/完成重放入口也返回 clone。没有对通用 Store 做反射深拷贝，没有更换 Redis 格式来掩盖 Memory 问题。

正式回归在 update、validate、create_retry 三个公开输出入口修改 Profile，检查存储保持 "safe" 且版本不变；Memory/Redis 均通过。原输入隔离、角色权限/范围检查与正常版本更新测试仍通过。P3 原问题的影响仍以 Memory 为界，Redis 修前对照已经安全，本轮保持该结论。
