# RR-20261006-60 修复：`HandlerMeta.Durability` 增加“未声明”状态，注册时强制

问题：[RR-20261006-60](../bug/RR-20261006-60.md)（F02-8）。基线 `b3ff8fcc`，分支 `hmeta`，提交 `2a8b2e64`。

## 根因

`nest.DurabilityPolicy` 是 `dataengine.Durability` 的别名，零值即 memory；handler 的声明与事务记录共用一个类型，“没写”与“写了 memory”无法区分，注册校验只能放行。

## 决策

二选一里选“增加未设置状态”（另一条“`Rollback != none` 且零值就拒”会拒掉显式写的 `DurabilityMemory` 和生成器产出的 `rollback=undo durability=memory`）：

- `nest.DurabilityPolicy` 改为 nest 自己的类型（不再是 `dataengine.Durability` 的别名），零值 `durabilityUnset`（不导出）表示未声明，`DurabilityMemory` / `Async` / `Strict` / `Pipelined` 依次为 1～4。导出常量名不变，`HandlerMeta{Rollback: …, Durability: nest.DurabilityX}` 写法照旧编译。
- 事务记录、WAL、投影、远端 outcome 上的级别仍是 `dataengine.Durability`（0～3，**wire / WAL 字节不变**）；`dataengine` 新增 `DurabilityMemory` / `Async` / `Strict` / `Pipelined` 常量。nest 在建记录（`rollback.go` `CommitRecord.Durability`）和发远端 outcome（`msg.go`）时用 `DurabilityPolicy.Record()` 换算。
- `validateHandlerMeta` 改为校验并归一：未声明且 `Rollback != none` → `ErrDurabilityUnset`（新哨兵），错误点名 handler、rollback，并列出 `nest.DurabilityMemory | nest.DurabilityAsync | nest.DurabilityStrict | nest.DurabilityPipelined`；未声明且 `Rollback == none` → 归一为 memory。注册表里存的是归一后的 meta，包级与实例级注册同一入口。
- `runTransaction` 入口兜住包内直接传 meta 的调用（只有测试）：未声明 + none 归一为 memory，未声明 + 可回滚返回 `ErrDurabilityUnset`。注册过的 meta 永远不会走进这个分支，`rollback=none` 快路径只多一次字节比较。
- `NewRollbackTx` 显式把 `tx.durability` 设为 memory（之前靠零值）。

未采用：把 `dataengine.Durability` 整体后移一位让 0 表示未设置——会改 WAL 字节与远端 outcome 的数值含义（remoteentity 按 0/1/≥2 判断），零值记录的语义也跟着变，影响面在三大块里且是静默的。

## 兼容性

**行为收紧**：手写 `HandlerMeta{Rollback: state|undo}` 不写 `Durability` 的，v1.23.1 起注册即失败（`MustRegister*` panic），按原语义补 `Durability: nest.DurabilityMemory`，或按需要选 async / strict / pipelined。

API：`nest.DurabilityPolicy` 不再是 `dataengine.Durability` 的别名。把 nest 常量当 `dataengine.Durability` 用的代码（直接给 `CommitRecord.Durability` 赋值、与记录字段比较）编译失败，改用 `dataengine.DurabilityX` 或 `nest.DurabilityX.Record()`；`uint8(nest.DurabilityX)` 能编译但数值多 1，须改为 `uint8(nest.DurabilityX.Record())`。WAL 字节、远端 outcome 数值、`String()` 输出（memory / async / strict / pipelined）不变；未声明的 `String()` 为 `unset`。未部署，不涉旧数据。
