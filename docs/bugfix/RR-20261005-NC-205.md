# RR-20261005-NC-205 修复：pretag 区分“远端没有该 tag”与“无法核对远端”

日期 2026-10-05。基线 `8597046c`（审查提交 `345488e4`）。状态：已修复、声明场景验证，未发版。问题：[RR-20261005-NC-205](../bug/RR-20261005-NC-205.md)。

## 决策

`scripts/pretag.sh` 记录 `git ls-remote --exit-code` 的退出码：0 → 已存在，失败；2 → 远端没有，继续；其他 → 打印 git 的错误并失败（“cannot check origin … fix the remote or the network and rerun”）。

## 验证

- 红：origin 指向不存在的仓库，修前 `ready to tag`、exit 0（[脚本](../review/evidence/noncore-review-20261005-n15/pretag_red.sh) · [输出](../review/evidence/noncore-review-20261005-n15/nc205-red.txt)）。
- 绿：`git ls-remote exit 128`，pretag exit 1（[输出](evidence/noncore-bugfix-20261005-n15/nc205-green.txt)）。
- 控制：本地 bare origin 无该 tag → ready、exit 0；origin 已有该 tag → `already exists on origin`、exit 1（[脚本](evidence/noncore-bugfix-20261005-n15/pretag_control.sh) · [输出](evidence/noncore-bugfix-20261005-n15/nc205-control.txt)）。
