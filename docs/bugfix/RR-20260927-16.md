# RR-20260927-16：Reserve 里 claim 标记 completed 失败记 Warn 与计数

问题：[RR-20260927-16](../bug/RR-20260927-16.md)（OPEN-ITEMS C25）。日期 2026-09-27。基线 `d4234c9`，分支 `fix-r7-de`。
状态：已修复，本地验证通过，本地提交，未推送 / 发布。codebase-memory 图谱过期（09-26），定位以当前源码为准。

## 决策与实现

`saga/dataengine_step_inbox.go` `reserveInTransaction`：`markCompleted` 返回错误时累加 `saga.step_inbox.mark_completed_error_total`（无标签）并
`slog.Warn("saga dataengine inbox: mark claim completed failed; the receipt stays authoritative", "command_id", …, "err", …)`；返回值不变
（仍返回 `Duplicate` + receipt 里的 completion 与读 receipt 的错误）。注释写明为什么不改返回值：receipt 是权威、claim 只是协调行，
真实服务端对事务内写错误会中止事务并由驱动重跑。

- 指标不带标签：只有这一个吞错位置；`command_id` 只进日志，不进标签（高基数）。
- `Replay` 路径的 `markCompleted` 错误本就返回给调用方，不在本条范围。
- 未采用：改成返回错误（清单 C25 推荐明确“不改返回值”）。

文档：`SAGA.md` 在 receipt 权威一段补这条 Warn / 计数与排查方向。

## 兼容性

返回值与持久格式不变；新增日志与计数 `saga.step_inbox.mark_completed_error_total`（供 CHANGELOG）。
