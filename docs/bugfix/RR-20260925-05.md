# RR-20260925-05 修复：Remote 独立实体有界并行投影

> 后续实现变更（2026-09-26）：下文描述当时按 worker 数分批的版本。当前窗口由 ReplayBatchRecords / ReplayBatchBytes 限制，RemoteProjectionWorkers 仅控制在途并发，空闲 worker 滑动补位、观察失败后停止；见[九项实施](../feature/REFACTOR-2026-09-26-core-nine-items.md)及[复审核实](../review/REVIEW-2026-09-26-followup.md)。

问题与修前数据：[RR-20260925-05](../bug/RR-20260925-05.md)。

## 实现

- `dataengine/engine/projector_remote.go` 在现有包内规划相邻纯 Remote 事务窗口，检查完整 RemoteCommit 契约，按 EntityID 和事务身份排除交叠，受 worker/记录/字节上限约束。
- `projector_replay.go` 并行执行窗口，每笔仍独立执行 Mongo 原子事务和完整 Remote 发布；返回前等待全部 worker。checkpoint 只确认连续成功前缀；失败后已成功后缀保留 WAL，通过持久事务身份重放。混合 DAO、effect、receipt、迁移和 held 边界保持原序。
- `ProjectorOptions.RemoteProjectionWorkers` 默认 8，1 为串行，最大 64；Kit 配置 `dataengine.projection.remote_workers`。只有 Store 显式声明能力才启用，MongoStore 还要求持久化和发布适配器都声明并发安全；自定义旧适配器不自动并发。
- 生成夹具增加可选 Nest 阶段计量、最多 32 个请求错误详情和汇总 metrics；原失败后跳过最终一致性校验的规则保持不变。性能脚本增加 DataEngine 源码 hash。

Nest 的 5 秒等待不变；WAL、DAO、Remote 协议及 strict 持久确认语义不变。不新增包、不执行部署。

## 回归

- 独立实体不被前一笔阻塞；相同实体、相同事务、非法/混合/特殊记录不跨窗口；字节/worker 上限。
- 失败仅确认前缀并重放成功后缀；checkpoint 丢失保留整窗；取消等待所有 worker；未知 Store 保持串行；Kit 配置范围。
- 负对照只禁用并行调用，独立实体测试在 5 秒内失败；实际实现通过。
- `go test -race ./dataengine/engine ./kit/dataengine ./remoteentity ./nest ./kit/remoteentity` 与同范围 `go vet` 通过。

真实验收已完成：21/21 故障矩阵一次性通过；60 TPS 短测 7200 笔全成功；30 分钟 60 TPS 实跑 108000 成功、0 错误/丢弃，完成 TPS=59.997，p50/p95/p99=124/262/845ms，最大延迟 2518ms。末次 WAL 积压 0，后续 Flush、Mongo/NATS 全量校验、回滚和 outbox 校验全部通过。原场景的至少 50 TPS 目标达成；未测最大容量，24 小时未执行，未部署。完整数据见 [实施报告](../feature/REFACTOR-2026-09-25-remote-throughput.md)。
