# RR-20261005-NC-207 修复：故障矩阵把没跑用例的格记 FAIL

日期 2026-10-05。基线 `8597046c`（审查提交 `345488e4`）。状态：已修复、声明场景验证，未发版。问题：[RR-20261005-NC-207](../bug/RR-20261005-NC-207.md)。

## 决策

`scripts/test-remote-matrix.sh` `run_case`：退出 0 但日志含 `no tests to run` 或 `[no test files]` 时记 `FAIL(no tests ran)` 并置失败。其余判定不变（`--- SKIP:` 仍记 FAIL）。

未采用：要求每格至少一行 `--- PASS:`——`final-health` 格是 `dataengine-env.sh status`，不是 go test；另加根包静态门禁（每个 `-run` 正则在对应包里至少匹配一个用例）可以作为后续补充，当前 21 个正则都已逐条核对。

## 验证

- 红：替身 go（输出 no tests to run）+ 替身 bash（拦下 heal / 生成工程脚本），临时根持锁，修前全部 go test 格 PASS、矩阵 exit 0（[脚本](../review/evidence/noncore-review-20261005-n15/matrix_red.sh) · [输出](../review/evidence/noncore-review-20261005-n15/nc207-red.txt)）。
- 绿：8 个 go test 格 `FAIL(no tests ran)`，矩阵 exit 1（[输出](evidence/noncore-bugfix-20261005-n15/nc207-green.txt)）。
- 控制：替身 go 输出真实执行的 `--- PASS:` 时全部 PASS、exit 0（[脚本](evidence/noncore-bugfix-20261005-n15/matrix_control.sh) · [输出](evidence/noncore-bugfix-20261005-n15/nc207-control.txt)）。
