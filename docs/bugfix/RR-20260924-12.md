# RR-20260924-12：Remote 确定冲突进入 fatal 投影路径

[问题](../bug/RR-20260924-12.md)。2026-09-24；已修复、未发布。

Remote MongoCommitter 仅在 **实体 meta 新建** 的 duplicate key 上附加 fmongo.ErrVersionConflict；保留原 duplicate key 与 entity/version 上下文。MongoStore 仅将明确的 fmongo/entity Remote version conflict 映射为 engine.ErrProjectionConflict，交给原有 Projector fatalOnce/OnFatal/准入拒绝路径。

不把所有 Mongo duplicate key 都粗暴归类；事务回执的并发/幂等处理仍保留。相同事务的已提交回执仍成功重放，瞬时网络故障仍重试。普通与 Remote DAO 写入仍在同一 Mongo 事务中，冲突时整体回滚，WAL 不 ack。

修前定向测试未识别为 fatal；修后验证两次重放只通知一次、后续 Commit 被拒、普通 DAO 没有漏写、原 WAL 仍有且仅有 1 条。直接 RemoteCommitter 的 CAS/幂等测试与真实 Mongo 重启回归纳入整体验收。

这不会自动修复历史二进制 WAL 中相互矛盾的业务内容；从错误数据恢复与修正程序逻辑是两个不同操作。
