# RR-20260929-07：chat 自定义频道键碰撞私聊

状态：已实施并通过本轮定向回归，未发版。源码基线 `f46db3e7d504bbd73581aa4119baa71171352519`。

根因：Kind 原样拼接冒号，shared 类型可产生 private pair 的同一存储键。

实现：仅对 Kind 的 % 和 : 做可逆转义，保留普通默认频道键；pair/shared 的字段边界不再被 Kind 伪造。

改动：kit/service/chat/chat.go。

回归：`TestReviewCustomSharedChannelCannotReadPrivatePair`。修前证据保留在 [第一轮](../bug/REPRO-2026-09-29-services.md) / [第二轮](../bug/REPRO-2026-09-29-services-02.md)；RR-09 修前是源码接线缺口，其他项有动态 FAIL。正式行为回归位于对应包，含 race；排行及 session ABA 使用隔离真实 Redis。统一命令、实际计数与未测边界见 [本轮总记录](SERVICE-BUGFIX-2026-09-29.md)。

兼容与边界：旧含冒号或百分号的自定义频道需要停写、按明确类型复制到新键；不读取歧义旧键，避免再次泄露私聊。已发生泄露不能靠新代码撤销。
