# RR-20260923-06 修复：Group.AddSubject 部分失败后残留成员状态且无法重试

[问题与修前证据](../bug/RR-20260923-06.md) · [收尾验收](../feature/SYNC-COMPLETION-2026-09-23.md)

状态：已修复并验证，未发布。

## 修复

所有本组成员订阅完成才写入 g.subjects；失败释放本组来源的订阅，允许重试。Manager 注册保留，不擅自退役可能已被其他政策使用的实体。

改动位于 `sync/entitysync/` 下的 policy/group.go。不改变实体帧线格式，不新增包。

## 验证

`go test ./sync/entitysync/policy -run 'TestGroupAddFailureCanBeRetriedWithoutPartialMembership' -count=1` 定向回归已通过。整块 race、调用方与构建结果统一记录在[收尾验收](../feature/SYNC-COMPLETION-2026-09-23.md#验收记录)，避免将定向通过等同全场景验证。
