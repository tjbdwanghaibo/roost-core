# RR-20261006-47 修复：Completed 的 saga 可被人工 Compensate 带回补偿

问题：[RR-20261006-47](../bug/RR-20261006-47.md)（F06-S5）。基线 `0b223b4c`（main，v1.23.0 之后；WIP `wip/sagafix` `bcdb4bd4` rebase 到此）。codebase-memory 共享 generation 停在 09-30（比基线旧），定位与结论按 worktree 当前源码读取。
同一批（sagafix2）修 RR-20261006-42～47，一笔提交 `63bc1d66`。

## 根因

`saga/engine.go` `Compensate`（基线 `:383-388`）没有对 `StatusCompleted` 的判断。

## 决策

- **拒绝**：`Compensate` 读到 `StatusCompleted` 时返回新哨兵 `saga.ErrSagaCompleted`，记录原样不动、不写、不计重开。`Completed` 是业务结论，按终态做业务的一方（发通知、写对账）已经据此行动；撤销已完成的业务走业务自己的冲正流程（例如另起一个反向 saga）。
- `Compensated` / `Compensating` 仍幂等返回原记录；`Failed`、`ManualRequired`、退避中的非终态照旧。
- **未采用**：B 允许（写进文档、计 `reopened_total`）——维护者选 A。
