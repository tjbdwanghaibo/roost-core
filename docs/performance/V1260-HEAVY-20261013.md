# v1.26.0 重档 15 分钟复测（2026-10-13）

结论：**通过**。v1.26.0 发布后的代码（运行时与 tag `v1.26.0` / `1e6f0e71` 相同；实际检出 `4554a493`，其后只多了发布文档）上，同参数 15 分钟重档完整跑完（902.87s，计时 900.004s），计数、最终 DAO 值、AOI 可见集合与 P99 门槛全部通过，零消息 / heartbeat 拒绝，200ms 慢 dispatch 为 0。

## 环境与参数

- Apple M5、macOS 26.5.2 / arm64、Go 1.27.0；`ROOST_PERF_CPU=0`，实际 GOMAXPROCS=10。宿主有常驻后台负载（启动时平均负载约 6.5，主要是 sysmond / WindowServer），与此前几轮相同，未关闭用户应用。
- 负载与 [REVIEW-20261012](REVIEW-20261012.md) 的 stackfix 复验相同：1000 玩家、10000 Entity、每玩家 10 条消息/s、全部 Entity 10Hz heartbeat、5% 修改率、on_change 即时处理（合批窗口 0）、AOI 上限 49 加自己；short worker 8 / 等待 65536，io worker 8 / 等待 64，long 8 / 4096（本负载未用）；Gate 与 Sync 开启；Gate / Game / 客户端同进程，经真实 loopback TCP 与本轮私有 NATS 2.14.5（JetStream，独立进程）通信。
- 变量名按三池改名后的 `ROOST_NEST_GAME_SHORT_WORKERS` / `SHORT_QUEUE` / `IO_WORKERS`；标签 `v1260-heavy-15m-20261013`。无 race、profile、索引重建并跑；NATS 日志无 slow consumer。

## 解读与边界

- 长尾明显收窄（各类 max 从数百 ms 降到 100ms 以内，>50ms 比例降一个数量级），P99 普遍下降。两次样本之间同时有热路径六项优化（[NEST-HOT-PATH-20261013](NEST-HOT-PATH-20261013.md)）、Sync 优化、可读性整理与长函数拆分、清理批等多项改动，且单次样本受宿主后台负载影响，**不能把差异归因到某一项**，也不能当吞吐上限；吞吐由负载发生器固定（10000 msg/s + 100000 HB/s），两次相同。
- 本场景不调用 Await、Remote、Saga，io 池 Started=0，不作为这些路径的容量验收；非零合批窗口、跨机、Linux 实机、独占服务器不在本次范围。
- 0.0098% 的已订阅 delta 仍超过 50ms（最大 86.341ms），长尾仍在，未唯一归因。
