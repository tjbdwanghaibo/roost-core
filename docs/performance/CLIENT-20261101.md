# 客户端 / Unity 当前验证（2026-11-01）

基线 cfb1aebd 加本轮客户端与构建脚本，macOS ARM64 / Apple M5，Unity 6000.3.12f1、Google.Protobuf 3.31.1，native C++ Release，Unity ARM64 Development Player（Mono / IL2CPP）。本机独立进程串行测量，测量期间没有并行编译、服务端压测或索引。不是低端设备、WAN 或生产完整游戏容量保证。

## 接入与弱网

- 实际 Editor 加载 native 插件并启动/关闭网络 worker；Mono、IL2CPP 均构建成功。
- 两种实际 Player 都通过正式 RoostNativeDriver 调度；真实回环 TCP 验证业务 PB 请求/推送、EntitySync 全量/零值与空集合增量/删除、64 位整数精度、native Lockstep 输入/快照恢复的反向 PInvoke、两代连接与重连回调。每代精确校验回调数量及最终数据。
- 两种 Player 和 C++ 各通过正常链路、每个下行协议包延迟 60ms + 每 7 字节分片再间隔 2ms 的链路。该延迟不是固定 RTT，分片不是 IP 丢包。会话恢复后不自动重发业务请求。
- native 故障五项通过：心跳无响应触发关闭；请求无响应返回 TIMEOUT_UNKNOWN；半帧关闭不交付不完整 PUSH；停止 Pump 300ms、事件容量 4、连续 30 个推送触发有界关闭；接收端停止读、16MiB 请求触发发送期限关闭。
- 真实账号/Gate/Nest/strict WAL/Mongo/C# 联合链路和批量能力修复另行 race 验证通过，见 [Robot/Gate](ROBOT-GATE-20261101.md)。Unity 场景使用协议夹具，不声称已经连接真实账号服务。

原始证据：`artifacts/perf/client/weak-{mono,il2cpp}-final-20261101`；summary 记录每个子进程退出码，日志保留故障类别和 Player 完整断言。当前新增测试所处 native 配置为 5 组 CTest，全部通过；之前的 Protobuf C ABI views / sanitizers 验证见 native 手册，未将旧检查称为本轮重跑。

## 可见集解码容量

每档 200 个模拟 tick、连续处理，重复 3 次；可见实体 50/500/2000/10000，每拍变化 1%/5%。50 × 1% 以跨拍累计实现，交替 0/1 个更新，不向上取整为 2%。每包最多 200 个实体，走真实生成 Hero PB、CRP1/RSSU 元数据和 EntityViews。先完整加载，再增量，最终逐实体核对值和实体总数。

表中 P99 单位 ms，范围为三次独立运行。只计数据已在内存后的解码/增量应用，不含读取输入文件、TCP 收包、场景渲染或物理。Unity 使用现有 C# codec，C++ 使用 native codec；实现和运行时不同，不能据此声称网络传输孰快。Cold 包含首次解析与视图创建，没有作为稳定帧耗时。

20Hz 只用于定义变化与每秒流量的换算，不是实测定时发送或 10 秒 wall-clock 循环。此 DAO 增量主要是 ID 和一个 level 字段，不能外推到大型背包或任意 blob。native 的 50/1% 与 10000/5% 档，同步编码分别约 1.31KB/s、1.00MB/s，仅统计增量阶段按 10 秒换算，不包含初始全量；不含 RS/TCP/IP 头和重传，更不是服务端总出口流量。

native 整个进程 RSS 高水位约 8–18.4MB，包含 Protobuf/runtime/夹具，不能全归于 SDK。Unity 10000/5% 负载结束托管已用堆约 Mono 9.41MB、IL2CPP 8.22MB（各三轮最大）；是时点采样，不是峰值/RSS。Unity 整进程已分配内存由 Profiler 单列。GC.CollectionCount(0) 是运行时原始计数，包含读取夹具引入的分配，不转换成每帧 GC 停顿；未做逐次 GC pause 归因。

本机 Mono 和 IL2CPP 的 GC.GetAllocatedBytesForCurrentThread 返回固定 0。新增分配探针后将不可用值记为 -1，不能解释为零分配。修正前 `unity-mono-capacity-20261101` 中的 allocated_bytes_per_tick=0 无效，保留原数据，以 `unity-mono-final-20261101` 为准。原始正确性和耗时未据此删除。

原始 JSON：`artifacts/perf/client/native-capacity-20261101.json`、`unity-{mono,il2cpp}-final-20261101/summary.json`，各 24 组，全部 verified=true。

## 复跑

先按 [Unity 接入](../../client/unity/README.md) 构建包及 Player，再执行。各输出使用新目录保留失败证据，不与其他性能任务并行。

```bash
cmake -S client/cpp -B /tmp/roost-client-check -DCMAKE_BUILD_TYPE=Release \
  -DROOST_BUILD_TESTS=ON -DROOST_PROTOBUF_TESTS=ON \
  -DCMAKE_PREFIX_PATH=/path/to/protobuf-install
cmake --build /tmp/roost-client-check --parallel 4
ctest --test-dir /tmp/roost-client-check --output-on-failure
python3 scripts/client/capacity.py --binary /tmp/roost-client-check/roost_native_capacity \
  --output artifacts/perf/client/native-new.json
python3 scripts/client/weak-network.py --native-build /tmp/roost-client-check \
  --unity-player /path/to/RoostNative-mono.app/Contents/MacOS/RoostNative \
  --output artifacts/perf/client/weak-new
python3 scripts/client/unity-capacity.py \
  --player /path/to/RoostNative-mono.app/Contents/MacOS/RoostNative \
  --output artifacts/perf/client/unity-new
# IL2CPP 使用对应 Player 和不同输出目录，仍串行运行。
```

缺 NDK/完整 Xcode、移动设备和 UE 环境，Android/iOS、UE、真实后台切换与网络制式切换未实跑；Linux/Windows 客户端本轮也未实跑。Driver 已实现禁用/后台断开及恢复通知，但不能由桌面回环测试宣称移动生命周期通过。TCP 原生适配不等于 TLS/WS/KCP 全传输已实现。
