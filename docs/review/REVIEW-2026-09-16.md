## 设计和进度

错误不等于没发生：History 与文件 generation 在正常成功路径上保持一致，但结果不确定时必须进入恢复流程。重试能否安全，取决于是否还能证明写入起点，不是只看 mutex 或返回 error。

PatchSyncer 是临时 patch 适配，不负责旧版本过滤或幂等；重复投递和更旧版本仍交给 Apply，是已声明契约。MessageID 区分发布调用，并不把同业务更新的重试自动合并。需要业务幂等/恢复时应另行设计，不能仅依赖 delivery ID。[机制文档](IMPLEMENTATION-SYNCBUS-PATCH-AND-DELIVERY.md)。

累计 41 份运行记录、24 篇机制文档、59 RR，仅为记录计数。下一轮优先真实 JetStream/NATS 发布确认、重连/重复投递及订阅关闭的交接，继续向业务 Apply 的恢复责任追踪。journal 多实例目录所有权、真实 Linux I/O 故障仍未验证；旧 room 和 statesync 外部消费缺口保留。[进度](PROGRESS.md)。
