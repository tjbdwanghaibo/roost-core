## 设计、性能与续跑

LOD 保留值避免了限频期间把组件误当删除，但绝对 tick 取模隐含发送必须经过采样点的要求，Replicator API 没有强制这个条件。低状态成本不能代替更新活性保证。

全局 SnapshotRing 与会话 sent 是两层历史：RingSize=2 不表示会话只保留两个发送 tick，本轮发送到 66 才验证默认 64 项 sent 的淘汰回退。ring.Add 满容量时平移切片并更新索引，工作量 O(capacity)；LOD 每组件在线性列表找旧值，单对象最坏 O(components²)，并复制数据。本轮只有源码成本分析，没有性能基准数字或性能 bug 结论。
