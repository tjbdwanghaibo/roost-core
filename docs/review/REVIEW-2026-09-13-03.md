## 真实 Redis 与实验

本机已有 Redis 8.8.0；临时目录 `C:/Users/tjbdw/AppData/Local/Temp/roost-review-0913c-ae07223a848b40e79994341a9d407d03`。实例只绑定 127.0.0.1:5997，save 关闭、appendonly no、工作目录独立。首次启动因 Windows 路径被 Cygwin 解释失败，改相对 redis.conf 与临时工作目录后成功 PONG。不是产品缺陷。

使用已声明依赖 go-redis/v9，薄适配转发真实 HGET/EVAL/DEL（仅映射 redis.Nil）。所有快照/marker Lua 使用源码常量原文，没有改脚本或生产依赖。测试通过 remoteentity Go overlay 注入。完整[源码与重建方式](../bug/REPRO-2026-09-13-03.md)。

| 场景 | 结果 |
| --- | --- |
| 2^53+1 后写 2^53，相同字节 | FAIL，版本回退；RR-10 |
| 2^53 后写 2^53+1，不同字节 | FAIL，误判冲突；同 RR |
| 同版本 schema 改变 | FAIL，旧 RR-07 真实补证 |

共十个场景，六个失败、四个通过。其中两个失败是旧问题升级证据；大版本两个失败合为一个新根因。
