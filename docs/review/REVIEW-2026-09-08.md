## 学习点

### 原子原语不等于业务事务

Session 每个 Create 都是原子 insert-only，但三个键不在同一事务内。owner claim 保护
一个 owner，ledger 保护一个 RequestID，维度不同。`err=nil` 只说明操作被处理，created
才说明取得所有权。测试屏障放在真实 Get 完成后、真实 Create 前，不用永远成功的
替身，能确定性暴露竞争窗口。未来修复还要处理落败者的 run/claim，不能只加报错。

### 限流计数必须对应资源生命周期

Coalesced 是累计统计，waiters 用于准入。加入、完成、取消、超时应有完整增减账。
只测满额拒绝不足以证明容量可复用；不存在数据 race 也会有这种状态错误，因此 race
检测不能替代不变量测试。此缺陷随当前 load 完成恢复，不应夸大为永久失效。

### AST 定位仍不能免除语法上下文检查

迁移器用 AST 找符号，最终仍按字节插入。ImportSpec 的位置不说明外层 GenDecl 是否
带括号。从括号块推导的策略不适用于单行 import。生成器应组合验证“语义分支 × 合法
语法形态”，并做格式化/解析/消费者编译，不只检查字符串。
