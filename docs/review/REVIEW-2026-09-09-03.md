## 机制阅读与学习

**停机错误不是完成状态。** Runtime.Shutdown 返回的是组件错误集合；Assembly 却无条件丢弃拥有的 Runtime。首次错误与二次 nil 之间，没有任何证据表明 worker 已退出。重试本应继续追踪同一对象，而非通过“对象已不可见”得到幂等成功。对超时后的资源管理，应该同时回答是否已停止、是否还有可重试的清理工作，而不是仅约定重复调用不报错。

**单文件生成成功不是包级产物成功。** Entity 工具对每个实体单独 format 后写文件，因此无法发现不同输出之间的包级同名声明。单实体对照通过、双实体编译失败，说明应把包级消费者作为验收单位。新增 guard test 的方向有价值，但 generator 自身的字符串测试没有运行生成消费者，就仍可能错过全局注册、有效 Kind/Category 及多个输出之间的关系。

**没有确认缺陷的阅读项也有边界。** Saga Assembly 用 lifecycleMu 串行化 Start/Stop，正常 Stop 先 drain 等消费者关闭，再取消/等待 Engine；超时路径有 hard Stop。本轮阅读并运行其现有 race 测试，未确认额外 Saga 问题；没有执行真实 JetStream 的 Start 部分失败或慢 drain 实验。Entity guard 的恢复/清理及 Nest/Protocol 常量抽取只做相关 diff 和包测试，不据此宣称完整生成体系无缺陷。
