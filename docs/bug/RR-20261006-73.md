# RR-20261006-73：轻量传输的 RPC 每次尝试固定截到 5s，call_timeout 超过 5s 不生效；超时 / 取消不带 ctx 语义

2026-10-07，基线 `c78d0c34`（main）。P2（处理时间 5s 以上的同步 RPC 一律 5s 超时；`errors.Is(err, context.DeadlineExceeded)` 判断不到）。来源：F09-R2（真实 nats-server 已证实），[impl/09 §3.1](../framework/impl/09-kit-services.md)。
状态：已复现（真实 NATS）；已修复（`a9bb8923`，[修复](../bugfix/RR-20261006-73.md)），未发版。

## 机制

`nats/driver/rpc.go` `RPCClient.Call` 每次尝试 `context.WithTimeout(ctx, 5*time.Second)`（基线 :164），缺省 `MaxAttempts = 1`：调用方 8s 的期限只用到 5s。`client.requestWithContext` 把期限到达映射成 `fnats.ErrTimeout`、取消映射成 `fnats.ErrCancelled`，丢了 ctx 的错误链；调用方期限已到时重试循环还会把它报成“取消”。
