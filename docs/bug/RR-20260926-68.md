# RR-20260926-68：调用方 ctx 临近到期、0 字节写出的推送被当作连接写失败，关闭健康连接

日期：2026-09-27。基线：本地 main `7706419`（RR-48～63 合并后，未推送）。来源：第二轮修复后独立审计。等级 P3（RR-52 引入的回退）。状态：已复现（20/20），未修复。

`codegen/internal/roost/render_player_tcp.go:995-1012` writeFrame：锁内 `ctx.Err()` 通过后写截止取 `min(write_timeout, ctx 截止)`（`:1000`），ctx 在检查后、写系统调用前到期时 `WriteTo` 立即 i/o timeout、0 字节写出，仍标 `errConnectionBroken`（`:1009`）→ `dropBrokenSession` 关闭正常读数据的连接（`:898`）。
复现：[REPRO-2026-09-26-06](REPRO-2026-09-26-06.md) §4：`healthy reading connection a was closed by a push that expired before writing`；基线 2000 次推送报错但连接保留。触发点：带截止的调用方（聊天 deliver 用请求 ctx、停机最后 Flush）。

修复约束：超时且写出字节数为 0 时按“写前拒绝”处理（不关连接）；或连接判定只用 write_timeout；部分写出仍视为连接损坏。
