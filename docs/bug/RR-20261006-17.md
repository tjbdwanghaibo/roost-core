# RR-20261006-17：协调器读了活动组文件，OpenActivity 却不核对 expected 集合属于 Key 的组

2026-10-06，基线 `ac913a60`。P3（配置不一致时窗口等不该等的服、或把结果发给不在活动里的服；单一部署按生成配置运行时 game 与协调器读同一份文件，不会自发出现）。
来源：[C4 方案](../feature/C4-ACTIVITY-GROUPS-FILE-2026-10-06.md) §6 的“未做”与 v1.23.0 发版文档 OWN-5，维护者第十三轮“不留 WANTED”。状态：已复现；已修复、声明场景验证，未发版。
[修复](../bugfix/RR-20261006-17.md)。

## 机制

- C4 之后活动组由 `configs/activity_groups.yaml` 定义，game 进程与协调器经同一个 `ParseGroups` 读它。协调器 Mod 只把文件用于启动校验和 sweep 组
  （`kit/service/global/activity/activity_mod.go` `Init`，修前），`Service.OpenActivity`（`service.go`）只检查 expected 集合的形状（非空、≤ 64、正数、不重复）。
- 所以协调器明明知道“哪些服是一组”，却接受：Key 的组不在文件里、expected 里有别的组的 sid、有不在任何组里的 sid、甚至整组都是另一个组的成员。
  一个读了旧版文件或配错 `groups_file` 的 game 进程开出的窗口会等一个永远不看这个组的服（只能等宽限窗口过期），或把结算发给不在活动里的服。

## 复现

`kit/service/global/activity/open_expected_group_promises_test.go`：按 Mod 的 `Provide` 同一份装配（`Mod.newService`，内存存储）、`activity.groups_file`
定义 `alliance-a: [1000, 1001, 1002]`、`alliance-b: [2000, 2001]`，四种不一致的开窗全部被接受：

```text
--- FAIL: TestTheCoordinatorRefusesAnExpectedSetTheGroupsFileDoesNotAllow/a-sid-of-another-group (0.00s)
    open_expected_group_promises_test.go:68: OpenActivity(alliance-a, [1000 2000]) opened [1000 2000]; the groups file does not allow that expected set
--- FAIL: TestTheCoordinatorRefusesAnExpectedSetTheGroupsFileDoesNotAllow/a-sid-in-no-group (0.00s)
    open_expected_group_promises_test.go:68: OpenActivity(alliance-a, [1000 1001 3000]) opened [1000 1001 3000]; the groups file does not allow that expected set
--- FAIL: TestTheCoordinatorRefusesAnExpectedSetTheGroupsFileDoesNotAllow/a-group-not-in-the-file (0.00s)
    open_expected_group_promises_test.go:68: OpenActivity(alliance-c, [1000]) opened [1000]; the groups file does not allow that expected set
--- FAIL: TestTheCoordinatorRefusesAnExpectedSetTheGroupsFileDoesNotAllow/the-whole-other-group-under-this-key (0.00s)
    open_expected_group_promises_test.go:68: OpenActivity(alliance-a, [2000 2001]) opened [2000 2001]; the groups file does not allow that expected set
```

## 修复

[修复记录](../bugfix/RR-20261006-17.md)：设置了 `activity.groups_file` 的协调器在 `OpenActivity` 写入任何东西之前按文件核对，不一致返回 `ErrInvalid` 并点名文件、组与 sid。
