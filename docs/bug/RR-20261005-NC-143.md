# NC-143：BlockRect 在 int64 上界附近溢出，返回倒置矩形

2026-10-05，基线 `23f82dbccfd5171373470ab942f33177ed4f4eed`。P3（需要 bounds 贴近 int64 上界且块尺寸大于剩余跨度的一半；AOI 只用 BlockRects 的键，不读矩形值）。状态：已复现、已修复、声明场景验证，未发版。[修复](../bugfix/RR-20261005-NC-143.md)。[本轮](../review/REVIEW-2026-10-05-n11.md)。

## 触发与差异

`spatial/block_index.go:78` 用 `bounds.Min + (x+1)*blockSize` 算块的右 / 下边界，再截到 `bounds.Max`。`NewBlockIndex` 用 `SafeSpan` 保证跨度不溢出，却没有约束 `(x+1)*blockSize`：最后一块的乘积可以超过剩余跨度，加上 Min 后在 int64 上溢出成负数，截断判断 `rect.Max > bounds.Max` 不成立，于是返回 `Max < Min` 的倒置矩形（经 `BlockRects` 交给调用方）。`BlockIndex(point)` 说点在该块，`BlockRect` 却不包含它。包注释承诺“overflow-safe arithmetic”。

## 复现

`spatial/block_index_promises_test.go`（基线代码上）：

```
block_index_promises_test.go:45: block 1 rect {Min:{X:4611686018427387904 Y:0} Max:{X:-9223372036854775808 Y:1}} is empty or inverted
block_index_promises_test.go:45: block 1 rect {Min:{X:4611686018427387905 Y:1} Max:{X:-9223372036854775807 Y:4611686018427387905}} is empty or inverted
```

下界（负坐标）对照通过。

## 约束

右 / 下边界改为 `Min + x*blockSize`（不溢出：小于跨度）再饱和加 `blockSize`，然后截到 bounds；不改块划分与 BlockIndex 编号。
