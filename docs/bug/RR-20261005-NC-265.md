# NC-265：robot Coalescer.Close 不等最后一次 flush 就返回

2026-10-06，基线 `dc877c04`，分支 `revleft`（N11～N13 留项与小防护）。**P3**。来源：N12 观察 O10。状态：已复现，已修复（见文末）。[本轮](../review/REVIEW-2026-10-06-revleft.md) · [证据](../bugfix/evidence/noncore-bugfix-20261006-revleft/README.md)。

## 触发与差异

`robot/robot.go` `Coalescer.Close`（基线 :334-352）：worker 运行时只 `close(done)` 就返回，worker 异步 drain。注释承诺 “Close flushes any pending batch”。

- 预期：Close 返回时最后一批已交给 flush 并处理完，调用方随后可以关闭 flush 写入的会话。
- 实际：Close 立即返回；最后一批确认发在已关闭的会话上，或根本没发。仓内无使用方（公开 API）。

## 复现

`robot/coalescer_close_promises_test.go（flush 卡住直到放行，间隔 1h 只由 Close 触发）`。修前（[原文](../bugfix/evidence/noncore-bugfix-20261006-revleft/nc265-red.txt)）：
