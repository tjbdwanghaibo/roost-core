# RR-20261001-09：activity 无 Intent 的 legacy Opening 永久占名额；单条坏 Intent 让该 group 的 `AdvanceExpired` 每 tick 整体失败

日期：2026-10-01。基线：main `32f69b2d`。来源：[W-2026-10-01-04](WANTED.md)（B 线修复独立复审分流，维护者 2026-10-01 拍板“做”）。等级 **P3**。状态：已确认，未修复。

## 位置、现象与修复约束

- 位置：`kit/service/global/activity`（RR-20260914-02 残余与 RR-20260929-02 之后的 `OpeningEntry.Intent`）。
- 现象：没有 `Intent` 的旧 Opening 条目不会被回收；一条 Intent 解析失败让整组推进失败并每 tick 重试。
- 修复约束：legacy 条目按旧规则（期限）回收；坏 Intent 记日志（状态变化时一次）并跳过，不阻塞同组其他条目；回归：种一条无 Intent 的 Opening + 一条坏 Intent → `AdvanceExpired` 跳过坏条目、回收 legacy 条目。
