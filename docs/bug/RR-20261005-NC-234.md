## 触发与差异

`kit/remoteentity/remote_entity_mod.go` `StopWithContext`（基线 :307-317）不论 `asm.Stop(ctx)` 的结果都记 Info `remote_entity mod: stopped`。ctx 到期、finalizer 或复制 handler 没排空时，Assembly 按 NC-174 保留、之后的 Stop 再等，但日志说已经停了，紧接着 App 又记 `mod stop failed … context deadline exceeded`。

- 预期：停完才记 stopped；失败记 Warn 并带错误。
- 实际：失败也记 stopped。
