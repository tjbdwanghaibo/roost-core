# RR-20260924-25：Remote Cluster 锁缺少同槽配置校验

日期：2026-09-24；基线 967bc69 加当前工作树。P2，Redis Cluster 部署首次写入不可用。已确认、修复配置准入并验证，未发布；[修复记录](../bugfix/RR-20260924-25.md)。

Remote 锁通过同一个 Lua 更新 `lock:<prefix>:<id>` 和其 `:fence` key。默认 `LockKey=e` 在真实 Redis Cluster 返回 CROSSSLOT；Kit 原先接受此配置，直到业务加锁才失败。空 `{}`、只有开括号或首个 tag 为空而后续 tag 有效也不能让 Redis 把两 key 放到同槽。

`TestClusterRequiresNonEmptyLockHashTag` 修前五个无效配置均被 Init 接受。真实六节点集成测试也直接验证默认前缀返回 CROSSSLOT；显式 `{remote-cluster-it}` 下运行后续故障场景。
