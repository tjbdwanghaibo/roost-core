# RR-20260928-11：pipelined 记录回退到 strict 路径进入 `WAL.Append` 时不等 fsync，等同 async

日期：2026-09-28。基线：本地 main `87ddbf0`。来源：批次 19a 修复方范围外发现。等级 **P2**：违反 pipelined “成功只在持久后对外可见”的契约。引入：修前即有。状态：已复现（探针），未修复。

`nestwal/wal.go:331` `Append` 的 `requireSync: record.Durability == corenest.DurabilityStrict` 不含 pipelined（3）。pipelined 在带 Remote 批次、broadcast（`nest/nest_dispatch.go:542`，`releaseLocks == nil`）时回退到 strict 路径，
经 `Projector.Commit` / `nestwal.Committer.Commit`（kit：`kit/dataengine/mod.go:355`）进入 `WAL.Append`，在 fsync 之前就返回；`NEST_PIPELINED_COMMIT.md:90` 写明这些路径“表现等同 Strict（锁内等待 durable）”。
后果：broadcast pipelined 的锁释放、Sync Confirm、AfterCommit、effect 可能先于 fsync 对外可见；带 Remote 批次时第 4 行回复“本地已提交”时本地部分可能尚未 fsync。

探针（`nestwal`，`-tags probe`）：

```text
PROBE durability=async fsyncBeforeAppendReturned=0 unsyncedAfterAppend=true
PROBE durability=strict fsyncBeforeAppendReturned=1 unsyncedAfterAppend=false
PROBE durability=pipelined fsyncBeforeAppendReturned=0 unsyncedAfterAppend=true
```

修复约束：`Append` 对 pipelined（回退到 strict 路径的记录）同样等待 fsync（例如 `record.Durability >= DurabilityStrict`，修复方核对 Durability 枚举与全部 `Append` 调用方后论证）；
pipelined 快路径（`Enqueue` 两阶段）不受影响；加回归覆盖 broadcast pipelined 与带 Remote 批次的 pipelined 两条回退路径（在持久前不对外可见）；同机前后对照 broadcast pipelined 的吞吐 / 延迟（`scripts/perf` 或现有 benchmark），代价如实写入记录；
RR-10 / 16 / 33 / 41 与 RR-20260928-09 回归不回退。

红探针：

```go
//go:build probe

package nestwal

import (
	"context"
	"testing"
	"time"

	corenest "github.com/tjbdwanghaibo/roost-core/nest"
)

// 探针：strict 提交路径（Committer.Commit / Projector.Commit → WAL.Append）上的 Durability 3 记录（pipelined handler 带 Remote 批次或 broadcast）
// 在 Append 返回前是否 fsync。
func TestZZProbePipelinedAppendSync(t *testing.T) {
	for _, d := range []corenest.DurabilityPolicy{corenest.DurabilityAsync, corenest.DurabilityStrict, corenest.DurabilityPipelined} {
		opts := testOptions(t.TempDir())
		opts.GroupCommitInterval = time.Hour
		script := &fsyncScript{}
		opts.syncFile = script.sync
		w, err := Open(opts)
		if err != nil {
			t.Fatal(err)
		}
		before := script.calls.Load()
		if _, err := w.Append(context.Background(), testRecord(1, d)); err != nil {
			t.Fatal(err)
		}
		w.stateMu.RLock()
		unsynced := w.unsynced
		w.stateMu.RUnlock()
		t.Logf("PROBE durability=%s fsyncBeforeAppendReturned=%d unsyncedAfterAppend=%v", d, script.calls.Load()-before, unsynced)
		_ = w.Close(context.Background())
	}
}
```
