RR-46 只在 Remote 批次确认后置 `remoteConfirmed`（`nest/nest_dispatch.go:83`）。复现：[REPRO-2026-09-26-05](REPRO-2026-09-26-05.md) §2b：`committed=true value=11 reply=release hook failed afterCommit=false`。release hook 只能经公开 API `RegisterOnEntityRelease` 由业务注册。

修复约束：本地持久提交成功后发生的释放 / 回调错误同样包 `ErrAfterCommitFailed`（保留原因链）；未提交路径不带；与 RR-49 一起保证已提交事务不被重排。

## 修复（2026-09-26）

状态：**已修复，未发布**（本地提交，未推送）。`Msg.txCommitted` 记录本条消息自己的事务已确定提交（strict / memory 持久提交成功、
