# RR-20260924-19：Remote 装配启停缺少生命周期所有权

日期：2026-09-24；基线 `967bc69` 加前轮优化工作树；等级 P1。已复现、修复、验证，未发布。[修复](../bugfix/RR-20260924-19.md)。

assemble.go 的 Start 每次 BindSync，但第一次启动已 SealDependencies，导致重复启动或初始化失败后的重试 panic。Stop 与 Start 无串行边界；先 Stop 后 Start 会在 finalizer 已终止的情况下返回成功；已取消的 Start 仍订阅并返回成功。Stop 超时也会提前拆掉未排空工作使用的复制依赖。

四个受控复现修前分别得到：重复启动/失败重试 `Start panic: remote_entity: dependencies are sealed`；先停后启 `Start succeeded with a stopped finalizer`；取消启动 `Start=<nil>`。日志 `/tmp/roost-remote-lifecycle-red.log`。

```sh
GOCACHE=/tmp/roost-nest-go-cache GOWORK=off go test ./remoteentity -run '^TestRemoteAssembly' -count=1
```

预期是重试不改封存依赖、启停有单一所有者、已停止实例拒绝重新运行，取消调用不报告启动成功。
