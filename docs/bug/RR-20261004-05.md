# RR-20261004-05：mongotest 忽略 `IndexModel.Sparse`，非 sparse 唯一索引把缺字段跳过，而真实 Mongo 当作 null（替身比真实宽松）

日期：2026-10-04。基线：v1.19.0（`74e1ba39`），main `2f111e9b`。来源：[B 线 NC 修复独立复审（第三组）§3](../review/REVIEW-2026-10-04-nc-audit-3.md)。等级 **P3**。状态：已确认，未修复。

## 现象、根因与修复约束

D4：NC-27 记录列为留项但未登记。根因 `mongo/mongotest/mongotest.go:960-971` `checkUniqueFieldsLocked` 缺字段时 `return nil`，全文件无 `Sparse`。真实 Mongo 探针：建索引与插入第二条缺字段文档都报 11000。修复约束：登记索引时保存 `Sparse`；非 sparse 缺字段按 BSON null 参与比较；sparse 时只在全部字段缺失才跳过（复合索引核对真实语义）；保留 NC-27 的“先验存量、失败不发布”。

复审报告里有修前 / v1.19.0 实测输出与会红的测试草稿（探针文件在审计 scratchpad，未入库）。
