# RR-20260926-56：syncbus JetStream 流名固定为 ROOST_SYNC，不随 prefix 隔离，多部署共用 NATS 时撞名

日期：2026-09-26。基线：本地 main `2330d57`（RR-30、33～47 修复合并后，未推送）。来源：修复合并后独立审计。等级 P3（部署隔离）。状态：源码判定（审计与修复方实跑中需手动加 stream 配置才能隔离），未修复。

修复约束：流名默认由 prefix 派生（保持现有默认 prefix 时流名不变以兼容已部署游标），并提供显式配置项；生成配置与文档同步；启动日志输出实际流名。

## 修复（2026-09-26）

已修复，按上方修复约束实现，见[修复记录](../bugfix/RR-20260926-56.md)。JetStream 流名缺省由 prefix 派生（`driver.JetStreamSyncStream`：默认 `roost.sync` 与
kit 缺省 `roost.room` 仍为 `ROOST_SYNC`，`zz3640.sync` → `ZZ3640_SYNC`，易撞的 prefix 追加摘要），`syncbus.stream` 显式配置优先；生成配置写入说明注释；
启动日志 `syncbus mod: started` 输出 `prefix` 与实际 `stream`。已部署默认配置的流名与 durable 游标不变；非默认 prefix 且未写 stream 的部署会换流（旧流仍占
subjects 时启动失败，配 `stream: ROOST_SYNC` 可沿用）。回归修前红、修后 `-race -count=10` 绿；集成机器人 3 轮在派生流 `ZZ5256_SYNC` 上通过。已本地提交，未推送/发布。
