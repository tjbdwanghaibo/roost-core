# NC-281：持久状态默认值按施法作用域检查，在进程回调里读 / 写该状态时求不出（ErrProgramInvariant）

2026-10-06，基线 `0aeb5ab6`。P2（编译通过；状态在 spawn 进程回调或进程字段里被读写时施法失败，area 进程启动那一步就跑回调，所以 Activate 直接失败）。状态：已复现；已修复、声明场景验证，未发版。[修复](../bugfix/RR-20261005-NC-281.md)。[本轮](../review/REVIEW-2026-10-06-n09-batch6.md)。

## 机制

- Runtime：`runtime_state.go` `evalStateRead` / `executeStateMutation` 用**读写处的 cast** 求 `state.defaultValue`。在进程回调与进程每一步里，那个 cast 是 `detachedProcessCast`：没有施法输入与 memory，`evalReference` 对 `referenceInput` / `referenceMemory` 越界返回 `ErrProgramInvariant`。
- 编译期：`runTypeCheckPass` 用 `checker.baseScope()`（施法作用域）检查状态默认值，`$input.*` 可见。

## 触发与差异

| 定义 | 修前编译 | 修前执行 |
| --- | --- | --- |
| entity 状态默认 `$input.target`，spawn 的 tick 回调里 `read_state` | 通过 | Activate `skill: immutable program invariant failed` |
| entity 状态默认 `$memory.m` | lower 报 `LOWER_UNRESOLVED`（定位在 `$.persistent_state.who`，lower 早于 memory 槽位分配） | — |
| 默认 `$caster` / `$primary_target` | 通过 | 能执行；`$primary_target` 在回调里是 lifecycle 实体（值漂移，表里标 ~） |

## 复现

`TestCompileRejectsStateDefaultsThatCannotBeEvaluatedEverywhere`。修前：`cast input: state default "$input.target" compiled; casting it: skill: immutable program invariant failed`；`cast memory: missing error INPUT_UNAVAILABLE … LOWER_UNRESOLVED`。

## 验收覆盖点

`$input.*` / `$memory.*`（以及 `$local.*`、进程专属引用）在状态默认值里报 `INPUT_UNAVAILABLE` 于 `$.persistent_state.<name>.default`，消息点名 `state_default`。控制：默认值是 `{"op":"eq","args":["$caster","$caster"]}` 的状态在施法流程与进程回调里都能读。
