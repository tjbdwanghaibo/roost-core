# RR-20260927-18：game-demo 场景自建的 entitysync Manager 没接卸载后重载，玩家被仅内存卸载后观察者停在旧内容上

日期：2026-09-27。基线：main `d4234c9`。来源：[OPEN-ITEMS-2026-09-27 B25](../review/OPEN-ITEMS-2026-09-27.md)（原始疑点：[REVIEW-2026-09-27-audit2 §疑点](../review/REVIEW-2026-09-27-audit2.md)
“demo scene Manager 未接 RR-59 重载链路”）。等级 **P3**：只影响 game-demo 模板生成的工程，触发需要原生步骤投影时被 lease fence 跳过。
状态：已复现，已修复（见[修复记录](../bugfix/RR-20260927-18.md)）。

图谱说明：codebase-memory 图谱已过期（09-26），以下行号与结论全部来自 `d4234c9` 源码与生成工程实跑。

## 触发、预期与实际

- 触发：场景内在线玩家的实例被仅内存卸载（`entity.ManagerAccess.Unload`，`DestroyReasonMemoryUnload`）。game-demo 里可达的是 RR-30 路径：
  礼物 saga 的扣除步骤 `handlerGiftDebit`（`demo/game/handler/gift_debit.go.tmpl`）走原生 `SubscribeDataEngineStep`，投影时租约已失效就被跳过，
  `dataengine/engine/fenced_step.go:218` `evictStaleEntities` 经 `ManagerAccess.Unload`（`:229`）驱逐发起人的 Player。RR-39（Remote 持久拒绝）
  共用同一入口，但 demo 的 Player 不是 Remote 实体，此路径在 demo 中不可达。
- 预期（RR-20260926-59 契约）：卸载时仍有订阅者，框架在快池外从权威重载并 `Rebind`，订阅者收到权威全量；重载不了退回 remove。
- 实际：
  1. 卸载关闭了实例的 `SubjectSyncState`（`entity/manager_access.go:598`），场景 Manager 上的 subject 停在关闭状态，不捕获、不发送；
  2. `ManagerAccess.Unload` 只通知经 `ConfigureUnloadResync` 接上的 Sync 目标（`manager_access.go:599-601`）。框架只在 kit 的 Nest Mod 给它**自己**的
     Manager 接线（`kit/nest/nest_mod.go:175`），game-demo 不用 `NewModWithEntitySync`，场景的 Manager 是 `scene.go.tmpl:212` 自建的，没有人接；
  3. 之后业务访问把玩家重新加载成新实例，场景也没有 `OnEntityLoaded → Rebind`，subject 仍绑在旧的关闭状态上。

  结果：同场景的其他玩家（以及玩家自己的会话）一直停在卸载前最后收到的内容上——可能正是被跳过、从未成为权威的效果——之后这个玩家的任何变化
  都不再送达，直到它离场。USER_GUIDE `:274-275` 要求自建装配自己接线，模板没有做。

## 复现（生成工程单测层，无外部依赖）

`roost project new r7demo -template game-demo`（replace 指向本 worktree），在 `internal/service/game` 加入修复后的回归

## 修复约束（清单推荐）

在 `demo/internal/service/game/scene.go.tmpl` 自建的 Manager 上接 `ManagerAccess.ConfigureUnloadResync`，照 `kit/nest/nest_mod.go:175` 的做法；
停机时先停重载（取消在途、不发 remove），再关 Manager，且在 Nest 停止之前。不改框架行为。

状态：**已修复，未发布**（本地提交，未推送）。`NewScene` 取进程的 `ManagerAccess`，`Scene.Start` 在启动复制循环前接线，`Scene.Close` 先停重载
再关 Manager（服务 Shutdown 先于 Mod 停止，所以也先于 Nest）。修后上面两段红都转绿。详见[修复记录](../bugfix/RR-20260927-18.md)。
