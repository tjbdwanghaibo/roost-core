# RR-20261008-43：失败 outbox 页遮住后续事务

P2，已修复、未发版。唯一发布入口重构时复核历史 RR-20261006-69：旧恢复循环只读最早 256 条，一条失败就停止翻页；256 条持续失败时，第 257 条正常记录永远不被扫描。过去其他发布入口可能帮助新提交，重启恢复没有这份保证。

`TestOutboxFailedFirstPageDoesNotStarveLaterTransaction` 写入真实 MongoCommitter 格式的 256 条坏记录及 1 条完整记录（同一 created_at、不同 ID）。以 Go overlay 恢复无游标入口，得到 `later transaction starved: state=2`；修后后三次通过，256 条失败记录仍保留为 Applied。overlay 是对旧扫描机制的反例，不冒称整份旧提交运行结果。见 `artifacts/perf/outbox-closure-20261008/outbox-pagination-{red,green}.log`。
