# RR-20260924-10：Outbox 启停分离导致关闭后启动与重复关闭通道

日期：2026-09-24；基线 `967bc69` 加工作树；模块 `dataengine/engine`；等级 P1（生命周期竞争导致进程 panic）；状态：已修复、未发布。[修复](../bugfix/RR-20260924-10.md)。

`OutboxWorker.Start` 与 `Close` 分别用两个 sync.Once，不能互斥保护 cancel/done。Close 在 Start 前看到 cancel=nil，关闭 done；之后 Start 仍创建 worker，run 退出时再次关闭 done，触发 `panic: close of closed channel`。并发 Start/Close 还会无同步地读写 cancel，并可能在关闭成功后继续领取工作。

预期：Close 是终态；未启动的 worker 可关闭，之后 Start 不再启动。已启动时只取消并等待唯一 run，超时后可继续 Close 等待。

复现：`go test -race ./dataengine/engine -run '^TestOutboxCloseBeforeStartIsTerminal$' -count=1`。修前真实输出 `panic: close of closed channel`，栈指向 `OutboxWorker.run`。修复测试另覆盖 100 轮同时 Start/Close。
