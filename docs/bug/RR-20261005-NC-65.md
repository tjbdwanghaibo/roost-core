# NC-65：game-demo 玩家加载后不按身上装备重建 Gear 层，attr_final 为空

2026-10-05，基线 `3d4fe9f3`。P2（客户端看到的合成属性错误：穿着装备的玩家重启 / 冷卸载后重新加载，Final 掉回 Base，复制出去的 `attr_final` 为空；不污染持久数据——`attr_base` 不含 Gear、`attr_final` 是 nopersist——下一次换装或升级即恢复）。属于生成的 game-demo 模板业务层。状态：已复现、已修复、声明场景验证，未发版。[修复](../bugfix/RR-20261005-NC-65.md) · [本轮](../review/REVIEW-2026-10-05-noncore-n07b.md)。

## 触发与差异

`demo/db/def/player.go.tmpl:41-46` 对 `attr_final`（`nopersist,sync`）的承诺：“It is recomputed when the entity loads, and replicated because it is what a client draws.”

实际 `demo/game/entities/player/attribute_component.go.tmpl:67-84` 的 `OnInitFinish`：

```go
component.container.Install(coreattr.Base, base)
component.container.Install(Gear, &gameattr.Combat{})   // :81 空的 Gear 层
component.recompose()
return nil                                                // 不写 attr_final
```

- Gear 层只在 `RefreshGear`（`:118`，唯一调用方是 equip handler）里按 `EquipmentComp().RangeWorn` 重建；加载时装上的是空层，Final = Base。
- 重组结果只经 `persist()`（`:219`）写回 DAO；`OnInitFinish` 不调用它，`attr_final` 在加载（以及新建）之后一直是空的，直到第一次换装 / 升级。

触发：任何非创建构建——进程重启后玩家重新登录、冷卸载后再次访问、远端重载——只要玩家穿着有属性的装备；`attr_final` 为空对所有玩家（含新建）都成立。

## 复现

生成 game-demo（replace 到基线源码），跑新增 `TestFinalIsRecomputedFromWornGearWhenThePlayerLoads`：新建玩家 → 事务内穿上铁剑（attack 15）→ 生成 DAO `Marshal` → `RestorePersisted` → `IsCreate=false` 构建：

```
attribute_component_test.go:276: a new player's attr_final is empty: the composed view was never handed to replication
attribute_component_test.go:320: after load final = attack 10 HP 100 power 30, want what the worn set gives: attack 25 HP 105 power 60
```

原文见[证据](../bugfix/evidence/noncore-bugfix-20261005-n07b/nc65-red.txt)。

## 本轮没做

没有用真实客户端在三进程链路上看复制帧（生成工程单测走生成 DAO 的持久化往返与正式构建器）；配置热更改了物品属性后，已加载玩家的 Gear 层不会自动重算（要等换装或重新加载），这是是否需要“reload 广播到在线实体”的设计选择，记为观察 C-O8，不在本条修。
