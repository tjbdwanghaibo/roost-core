## RR-20260918-03：map 撤销后的通知

文件 `dao/review_rollback_test.go`；4 叶子，2通过2失败。恢复字段指针身份通过后，再验证通知，避免把“值没恢复”和“hook没恢复”混淆。
```go
package testdata

import (
	"context"
	"errors"
	"github.com/tjbdwanghaibo/roost-core/nest"
	"testing"
)

type reviewCommitter struct{}

func (reviewCommitter) Commit(context.Context, nest.CommitRecord) error { return nil }
func TestReviewNotifyRollback(t *testing.T) {
	for _, mode := range []string{"normal_old", "normal_new", "rollback_old", "rollback_new"} {
		t.Run(mode, func(t *testing.T) {
			p := &EquipInfo{}
			old := &GemInfo{}
			replacement := &GemInfo{}
			p.SetGems(map[int32]*GemInfo{1: old})
			calls := 0
			p.SetNotify(func() { calls++ })
			if mode == "rollback_old" || mode == "rollback_new" {
				sentinel := errors.New("abort")
				_, err := nest.RunIsolatedTransaction(context.Background(), reviewCommitter{}, "review", func() (any, error) { p.SetGems(map[int32]*GemInfo{1: replacement}); return nil, sentinel })
				if !errors.Is(err, sentinel) {
					t.Fatal(err)
				}
				got, _ := p.GetGems(1)
				if got != old {
					t.Fatal("value not restored")
				}
			} else {
				p.SetGems(map[int32]*GemInfo{1: replacement})
			}
			calls = 0
			want := 0
			if mode == "normal_old" || mode == "rollback_old" {
				old.SetLevel(9)
			} else {
				replacement.SetLevel(9)
			}
			if mode == "normal_new" || mode == "rollback_old" {
				want = 1
			}
			if calls != want {
				t.Fatalf("notifications=%d want=%d", calls, want)
			}
		})
	}
}
```

- [09-18 原复现](REPRO-2026-09-18.md)的三个实体 fixture 用当前 CLI 重生成，均能消费编译。composition 导入换为临时模块；harness 新增 `atomic.Uint64`，建 RoomManager 前 Store(9)，配置 `DurableWatermark: h.watermark.Load`。原三 gate 路径先验证 LSN10 不发送，再 Store(10) 重试同一操作，验证发送1帧。cleanup 先推进水位，避免在测试仍故意阻挡时把 Close 的 deferred 当故障。原8消费+3gate+3coordinator合计14叶子通过，race 无报告。
