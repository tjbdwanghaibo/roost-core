# RR-20260923-04：在途交付覆盖新的会话或订阅意图

- 日期：2026-09-23；等级：P1；模块：Sync。
- 基线：`967bc69` + 前一轮 R1～R3 与 RR-01～03 工作树。
- 状态：已复现、修复并通过定向回归与模块 race 验证，未发布。[修复记录](../bugfix/RR-20260923-04.md)。

## 触发、预期与实际

Push 尚未返回时执行 Hold、Close/Open 同 ID、换 profile、退订或退役。预期旧交付不能覆盖 Hold、新会话或新 profile；若 create 已准入，退订和退役仍须补发 remove。

旧实现仅按会话 ID 采纳副本，结算不校验捕获时的订阅；首次 create 在途时按“尚无已交付对象”直接删订阅。结果包括 held 丢失、新会话被旧错误关闭、新 profile 快照被吞，以及已准入 create 永远不再 remove。

## 证据

`go test ./sync/entitysync -run 'TestInFlightDeliveryCannotOverwriteNewIntent' -count=1`。六个确定性交错子场景在修前全部失败。测试位于 `sync/entitysync/inflight_promises_test.go`，用 Push 回调或通道固定交错。

相关实现：`sync/entitysync/` 下的 session.go、subscriptions.go、subject.go、flush.go。影响边界及行为迁移见修复记录。
