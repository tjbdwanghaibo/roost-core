# RR-20260927-29：RR-27 引入：持锁的非 Nest 领头方完成加载后，loader 另起 goroutine 迟到调用 `RunLocal` 永久阻塞

日期：2026-09-27。基线：本地 main `001b03b`。来源：第六轮独立审计（审计记录随第二路合并后写入 `docs/review/REVIEW-2026-09-27-audit6.md`）。等级 **P4**：契约外用法，仓内 loader 在 `LoadEntity` 内同步调用 `RunLocal`（`dataengine/engine/entity_repository.go:266`）。引入：RR-20260927-27。状态：已复现，未修复。

`entity/manager_access.go` `runOnLeader` / `loadEntityShared`：领头方从 `flight.done` 分支正常返回时不关闭 `leaderAway`；loader 的 `LoadEntity` 返回后另起的 goroutine 用加载 ctx 调 `entity.RunLocal`，
`runOnLeader` 向已无人接收的 `leaderSteps` 发送、`leaderAway` 永不关闭，调用方永久阻塞（goroutine 泄漏）。HEAD：`PROBE P27late late RunLocal (after the flight finished) still blocked after 2s`；`bd15427`（RR-27 前）：`late RunLocal returned <nil>`。

修复约束：领头方无论以哪种方式离开 `loadEntityShared`（ctx 离开、正常完成、panic）都关闭 `leaderAway`（`sync.Once`），迟到步骤走原路径（绑定执行器或就地）；RR-27 / RR-54 / B20 回归不回退。
