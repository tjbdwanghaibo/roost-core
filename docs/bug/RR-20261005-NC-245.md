# NC-245：hotcode 插件 Apply 中途失败不回滚已替换的补丁点（N10 O-H1）

2026-10-06，基线 `81d7cb16`，分支 `revn10b`（N10 第二批）。P2（ai / actionflow 仓内无生产使用方；hotcode 由 Nest 全局 handler 与 game-demo 使用）。状态：已复现、已修复、声明场景验证，未发版。[修复](../bugfix/RR-20261005-NC-245.md) · [本轮](../review/REVIEW-2026-10-06-noncore-n10b.md)。

## 触发与差异

`hotcode/plugin.go:49-51`（基线）`bundle.Apply(Default)` 返回错误时 LoadPlugin 只返回错误、丢掉 Bundle；Apply 里已成功的 Replace 不撤销。Apply panic 直接穿出。

预期：加载失败 = 什么都没变：已替换的点回到加载前的那一代（加载前已生效的补丁保留，不是回到原函数）。

实际：运维看到“加载失败”，`hotcode.list` 里却有点是插件版本；Bundle 被丢，无法调它的 Revert；`hotcode.revert` 只能回到原函数，会把加载前已生效的那一代补丁一起撤掉。真实 .so：first 在失败后返回 101（插件版本），应为 11（加载前的 v0）。

## 复现

`hotcode/plugintest/plugin_load_test.go`（修前，[原文](../bugfix/evidence/noncore-bugfix-20261006-n10b/red-plugin-245.txt)）：

```
plugin_load_test.go:164: after the failed load first(1) = 101, want 11: the partially applied patch was left in place (101) or rolled back past the previous generation (2)
```
