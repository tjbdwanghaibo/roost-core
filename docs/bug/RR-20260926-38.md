# RR-20260926-38：Durability 1/2 下 finalizer 与投影器并发发布同一 Remote 事务——快照双发、所有权转换竞态、每笔写额外 Mongo 读

日期：2026-09-26。基线：v1.17.0（`8811c02`）。等级 P2（可用性 / 性能，不写坏数据）。状态：受控并发复现，未修复。引入：RR-19 修复（Admitted 回源）。

## 根因

`remoteentity/transaction_tracking.go:174-194` 对 Admitted 也回源；Durability 1 下 finalizer（`transaction_manager.go:235-262`）在投影器 Mongo 事务提交后、发布完成前读到 Applied，
调 `publishAppliedRemoteTransaction` 与投影器 `ApplyRemoteCommits` 并发 `afterRemoteCommit`；`acknowledgeRemoteCommit`（`:1012-1023`）先读后转，未串行。

复现：[REPRO-2026-09-26-04](REPRO-2026-09-26-04.md) §6：投影器落后时 `invalid ownership transition: local_owned -> recovering`、投影失败计数+1；finalizer 落后时实体重新隔离、gate 多占；
一笔 async 写（投影 300ms）finalizer 回源 CommitStatus 3 次（修前 0）。

## 修复约束

Durability 1/2 由投影器负责完成；finalizer 只在投影器报告 skip / unknown 或超过较长期限后回源；`acknowledgeRemoteCommit` 幂等（向量相等且已 Owned/Shared 视为成功）或按 txID single-flight 发布。
不能回退 RR-19“拒绝可回源得到结论”与 RR-28 行为。
