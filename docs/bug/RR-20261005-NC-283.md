# NC-283：投射引用（`$primary_target.position`、`$event.target.position`、`$input.target.position` 等）类型检查通过，lower / Runtime 不认

2026-10-06，基线 `0aeb5ab6`。P2（编译通过的定义每次求值 `ErrProgramInvariant`；输入槽位的投射从 B3 起编译失败且定位在 `$`）。状态：已复现；已修复、声明场景验证，未发版。[修复](../bugfix/RR-20261005-NC-283.md)。[本轮](../review/REVIEW-2026-10-06-n09-batch6.md)。

## 机制

- 类型检查 `projectedReferenceType` 对作用域里任何实体根投射 `.position`（以及 hit 的 `.entity` / `.target` / `.position`）。
- lower `lowerReference`：memory / 局部变量按根 + field 拆分；输入只按全名查 `c.input`，查不到时（B3 之后）报 `LOWER_UNRESOLVED`；其余引用整串当 builtin 名字。
- Runtime `evalReference` 的 builtin 分支只认精确名字（`$caster.position`、`$owner.position` 是单列的 builtin），`$primary_target.position` 等落到 default：`ErrProgramInvariant: builtin "…"`。

## 触发与差异

| 引用 | 修前 |
| --- | --- |
| `$input.target.position` | 编译失败 `LOWER_UNRESOLVED`（定位在 `$.phases[0].on.enter.steps[0]`） |
| `$primary_target.position`（exists 守卫内） | 编译通过；Activate `immutable program invariant failed: builtin "$primary_target.position"` |
| 回调里的 `$lifecycle_entity.position`、`$event.target.position`、`$event.source.position`、`$event.owner.position` | 编译通过；Activate（area 启动那一步跑回调）同上 |

## 复现

`TestProjectedReferencesCompileAndRun` 六个子用例修前全部失败（文本如上）。

## 验收覆盖点

六种投射编译无诊断、执行无错误；`teleport $caster` 到 `$input.target.position` / `$primary_target.position` 之后施法者位置等于目标位置。

## 修复

[修复记录](../bugfix/RR-20261005-NC-283.md)：lower 按求值上下文表的行把 builtin 投射拆成根 + field，输入槽位按根 + field 解析；`evalReference` 既有的 field 分支取位置。
