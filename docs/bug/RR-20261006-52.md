# RR-20261006-52：运动衍生物启动步 Frame 之后被 Host 拒绝，Host 侧已登记的衍生物无人停止

2026-10-07，基线 `47abe511`。P2（Host 侧残留一个一直运行的衍生物，Runtime 不记得、`Shutdown` 也停不到）。来源：F08-R，[08-skill 实现](../framework/impl/08-skill.md) §11 R2。
状态：已复现；已修复（`50a0fe88`，[修复](../bugfix/RR-20261006-52.md)），未发版。

## 机制

1. `startEntitySpawn` 先跑启动步 `stepSpawnMotion`，成功之后才把记录放进表（基线 `skill/spawn_owned.go:43-53`）。
2. 启动步里 Frame 之后的任一步（steering / trajectory / offsets / collision / carry / completion / signals）被 Host 拒绝时，只解除 carry 就返回（`:46-48`），`executeOwnedSummon` 回滚召唤事务。
3. Host 已经因 Frame 等前几步登记了这个衍生物（`MemoryHost.StepSpawn` 每一步都写 `host.spawns`），Runtime 没有记录，谁都不会请求停止。
