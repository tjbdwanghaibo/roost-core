## 4. RR-20260916-04：Recover 的位置比较不能识别删除 ABA 与同位置替换

**P2，Core，未修复。** 关联原 RR-20260915-09，但原追加/epoch 触发已通过，不撤销其有效修复。

位置：Core [syncstream/syncstream.go](../../syncstream/syncstream.go)，streamObservation 第 172 行、appendIfUnchanged 第 191 行、Recover 第 346 行、Import 第 578 行。基线见第 2 节。

当前 Recover 在 provider 前记录 epoch/existence/latest，provider 锁外执行，再在写锁内比较这三个值。它们描述“当前位置”，不证明期间没有发生替换：

- 流原本不存在；provider 捕获旧内容期间，另一操作 Append 新状态后 DeleteStream；提交时仍为“不存在、同 epoch”，检查通过，旧捕获被重新追加为 Full seq=2。
- 流原本 epoch=7/latest=1；provider 捕获期间 Import 同 epoch/latest=1、但 payload 不同的新快照；检查通过，旧捕获作为 seq=2 覆盖新内容。

两种交错都通过 provider 内顺序操作即可确定复现，无需依赖调度概率。独立测试四叶子：no_change、append_control 通过；append_delete_absent、same_position_import 失败，实际返回 nil error 和 payload=stale 的新 Full。期望均返回 ErrRecoverStale 且不提交该旧 Full。影响是恢复响应内容回退，且旧内容获得更新序号。

**实施建议：**

1. 为 History 引入与协议 Sequence/Epoch 分离的进程内 mutation revision；先采用全局单调代数也可以，明确它会保守拒绝其他流并发修改下的捕获。需要减少误拒绝再做每流代数与删除墓碑，避免墓碑无限增长。
2. provider 前捕获 revision；appendIfUnchanged 写锁内比较，再执行追加。Import/Restore、删除、追加、Rotate 等成功改变捕获依据的路径均更新代数；失败不应假装成功提交。Import 不得从传入快照覆盖本进程 revision，删除不得将其重置。
3. 不仅把 sequenceFloor 加入比较：相同 floor 的 Import 仍可换内容。也不要持 History 锁运行 provider；业务回调可能重入 History。
4. 原五个 Recover 测试保留，再加本节两种交错、DeleteObserver/SweepIdle 等删除入口、Import 失败不改变状态、正常无变化恢复对照。定义 ErrRecoverStale 的宿主重试/重新读取策略，避免无限重捕获。

这仍只约束 History 观察到的变更；宿主业务状态变化却不通知 History 的一致性，需要 SnapshotProvider 自己的捕获协议。

### RR-04 的四场景复现

放入 syncstream 包；snapshotProviderFunc 复用现有包内测试适配器。provider 内的操作模拟“捕获后、提交前”的交错。

```go
func TestReviewRecoverReplacementBoundary(t *testing.T) {
    for _, mode := range []string{"no_change", "append_delete_absent", "same_position_import", "append_control"} {
        t.Run(mode, func(t *testing.T) {
            h := NewHistory(HistoryOptions{Epoch: 7})
            s := Stream{Topic: "state"}
            appendFull := func(x *History, payload string) {
                t.Helper()
                if _, err := x.Append(Packet{Stream: s, Full: true, Payload: []byte(payload)}); err != nil { t.Fatal(err) }
            }
            if mode == "same_position_import" { appendFull(h, "before") }
            result, err := h.Recover(ResyncRequest{Stream: s, Epoch: 999},
                snapshotProviderFunc(func(ResyncRequest) (Packet, error) {
                    switch mode {
                    case "append_delete_absent":
                        appendFull(h, "new")
                        if e := h.DeleteStream(Observer{}, s); e != nil { t.Fatal(e) }
                    case "same_position_import":
                        fresh := NewHistory(HistoryOptions{Epoch: 7})
                        appendFull(fresh, "replacement")
                        if e := h.Import(fresh.Export()); e != nil { t.Fatal(e) }
                    case "append_control":
                        appendFull(h, "new")
                    }
                    return Packet{Payload: []byte("stale")}, nil
                }))
            if mode == "no_change" {
                if err != nil || len(result.Packets) != 1 { t.Fatal(result, err) }
            } else if !errors.Is(err, ErrRecoverStale) {
                t.Fatalf("stale capture accepted after %s: %+v err=%v", mode, result, err)
            }
        })
    }
}
```

需要 imports errors、testing。上面为实际复现的等价整理版（给成功的准备 Append 补显式错误检查）；实际观测结果记录在第 4 节。

### RR-05 的无效注入复现

放入 Kit service/match 包，复用现有 newStore/ranked/player/enqueue 测试 helper；imports context、errors、testing。

```go
type reviewRejectGrouping struct{ calls int }
func (g *reviewRejectGrouping) Group(Queue, []Ticket) ([]Ticket, bool, error) {
    g.calls++
    return nil, false, errors.New("policy refuses all matches")
}
func TestReviewGroupingInjection(t *testing.T) {
    g := &reviewRejectGrouping{}
    s, _ := newStore(t, func(c *Config) { c.Grouping = g })
    q := ranked()
    a := enqueue(t, s, q, player(1, 10), "a")
    b := enqueue(t, s, q, player(2, 10), "b")
    ctx := context.Background()
    if _, err := s.Sweep(ctx, q, 10); err != nil { t.Fatal(err) }
    if _, err := s.Candidates(ctx, q, 10); err != nil { t.Fatal(err) }
    m, err := s.Commit(ctx, q, []string{a.ID, b.ID})
    if g.calls == 0 && err == nil {
        t.Fatalf("configured rejecting policy ignored: calls=%d committed=%s", g.calls, m.ID)
    }
}
```
