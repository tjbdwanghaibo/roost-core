# NC-267：ObjectPool 同一对象 Put 两次，之后两次 Get 交出同一个对象

2026-10-06，基线 `dc877c04`，分支 `revleft`（N11～N13 留项与小防护）。**P3**。来源：N13 观察 O5。状态：已复现，已修复（见文末）。[本轮](../review/REVIEW-2026-10-06-revleft.md) · [证据](../bugfix/evidence/noncore-bugfix-20261006-revleft/README.md)。

## 触发与差异

`container/object_pool.go` `Put`（基线 :57-66）：对象不在 workList（第二次归还）时照样追加到 freeList，freeList 里有两份，之后两次 Get 交出同一个对象，两个使用者共享一份可变状态。

- 预期：重复归还是空操作。
- 实际：见上。仓内零调用方（公开 API，C3 / C8 决定保留）；包注释已声明非并发，但这是单 goroutine 内的误用后果。
