# RR-20261006-64：2 人 lockstep 房间的 desync 永远裁不出来

2026-10-07，基线 `a7285da6`。P1（demo 两个匹配队列都是 2 人房；任何哈希分歧都没有回调、没有指标，`GAME_DEMO_TEMPLATE.md` 的“无 desync”是空真）。来源：框架文档审查 F04-8。维护者 2026-10-07 选 A。
状态：已复现；已修复（`99a3e99f`，[修复](../bugfix/RR-20261006-64.md)），未发版。

## 机制

1. `HashQuorum <= 0` 时取 `players/2+1`（基线 `sync/lockstep/room.go:167-170`），2 人房为 2。
2. `DesyncDetector.Report` 只有某个哈希有 quorum 份一致上报才出裁决（基线 `desync.go:70-72`）。2 人报不同哈希时每个哈希只有 1 份，永远不到 2。
3. 同理 4 人 2:2、3 人全不同也裁不出。检测器不知道座位数，无法判断“已经不会再有上报”。
