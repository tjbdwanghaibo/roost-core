# RR-20261004-04：`ReadThroughStore` 的 loader 回填被 L1 以 stale 拒绝时，`Get` 返回 `ErrStaleWrite`（读取因写被拒而失败）

日期：2026-10-04。基线：v1.19.0（`74e1ba39`），main `2f111e9b`。来源：[B 线 NC 修复独立复审（第三组）§3](../review/REVIEW-2026-10-04-nc-audit-3.md)。等级 **P3**。状态：已确认，未修复。

## 现象、根因与修复约束

D2：旧缺陷，NC-15 扩大到 LocalStore。根因 `cache/read_through.go:191-193` 不区分 `ErrStaleWrite` / `ErrConflictingWrite`；`:186-188` remote.Set 的 stale 同样让读取失败。唯一生产用法 `entity/remote_snapshot.go` 无 loader，不受影响。修复约束：loader 分支复用 remote 回填分支的 switch——stale / conflict 读回 L1 已准入值，L1 无值则 miss（stale）或拒绝（conflict）；remote.Set 的 stale 不让读取失败。

复审报告里有修前 / v1.19.0 实测输出与会红的测试草稿（探针文件在审计 scratchpad，未入库）。
