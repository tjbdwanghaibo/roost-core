# RR-20260925-03：慢请求全堆栈诊断放大 Remote 压力

- 日期/基线：2026-09-25，Remote authority 工作树；P2，必要调用链 nest/trace.go。
- 触发：Mongo 等依赖变慢，一批 Nest 业务请求超过 200ms。
- 原行为：每个请求各自启动一次进程所有 goroutine 堆栈抓取，分配 256 KiB 缓冲；单请求 `traced` 标记只能去掉自身重复抓取，不能限制同时变慢的请求总量。`stop` 等待本次诊断回调结束，业务资源释放也可能被诊断拖延。
- 实际证据：上一轮 `authority-bulkmeta-strict-20-20260925/run.log.gz` 含 5381 条 slow dispatch trace，解压日志 1,449,710,553 字节，压缩 51,191,706 字节。该日志包含初始化/5000 笔预热及 60 秒正式负载，不是单独 60 秒的日志量。
- 预期：保持逐请求延迟指标和慢日志，昂贵的全进程堆栈采样频率有界。
- 根因：诊断范围是全进程，限流范围却只是单请求。
- 证据摘要：`artifacts/perf/remote/unified-verification-20260925/previous-log-volume.json`。
- 状态：已修复，128 并发采样/时间边界与 race 回归通过。[修复](../bugfix/RR-20260925-03.md)。
