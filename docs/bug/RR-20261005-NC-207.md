# RR-20261005-NC-207：故障矩阵把 “no tests to run” 的格记为 PASS

日期 2026-10-05。基线 main `8597046c`。等级 **P3**。状态：已复现（替身驱动），未修复；已修复、声明场景验证，未发版（见文末）。来源：N15。

## 触发与实际

`scripts/test-remote-matrix.sh:2` 承诺“不把缺失 / 跳过计为通过”，`:30` 的判定只看退出码 0 且日志里没有 `--- SKIP:`。`go test -run` 一个都没匹配到时输出 `testing: warning: no tests to run` 且退出 0，被记 PASS。用替身 go（输出 no tests to run）与替身 bash（拦下 heal / 生成工程脚本）在临时根上跑整张矩阵：全部 go test 格 PASS，矩阵 exit 0（[脚本](../review/evidence/noncore-review-20261005-n15/matrix_red.sh) · [输出](../review/evidence/noncore-review-20261005-n15/nc207-red.txt)）。

当前 21 个 `-run` 正则都能匹配到现有用例（逐条核对），所以这是潜伏缺陷：用例改名 / 搬包后对应格会静默变成空绿。根包门禁 `TestFaultMatrixScriptNamesEveryFullEnvironmentSuite` 只看 `dataengine-env.sh`，不看本脚本。

## 影响与定级

发版前矩阵（交接 §5 “21/21”）可能报告没跑过的格。定级低是因为当前没有触发路径，不是因为后果轻。P3。

## 验收

日志含 `no tests to run` / `[no test files]` 的格记 FAIL；有用例执行的格不变。
