## 1. `TestRemoteProjectionFatalSuffixIsNotHiddenByEarlierTransientFailure` 竞态（跨平台）

- CI：a22c5a5 的 `ci / linux-test (1)`（run 36207964729）失败；Windows 上同样出现过。
- 本机 macOS 实跑：non-race 500 次失败 7 次；`-cpu=1,2,4` 600 次失败 8 次；`-race` 200 次失败 48 次（24%）。
- 机制：`dataengine/engine/projector_remote.go:92-100` 3 个 worker，记录 1 瞬时成功；若它在记录 2、3 的失败返回之前完成，`!failed` 成立会 `launch()` 记录 4，
  记录 4 成功后 `completeProjection(id, nil)`（`projector.go:468` 幂等），之后 fatal 结果写不进去。这符合“首次**观察到**失败后停止补位”的设计；
  测试 `projector_remote_test.go:270-281` 却假设记录 4 一定未开始（断言 `n == 1` 且 ticket 得到 fatal）。测试由 646ce63 引入。
