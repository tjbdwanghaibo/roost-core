# RR-20260927-23：demo 场景没有接 `OnEntityLoaded → Rebind`，卸载时无订阅者的玩家被业务重新加载后，场景仍绑在已关闭的状态上

日期：2026-09-27。基线：`d4234c9`。来源：批次 6 修复方在 RR-20260927-18 中报告的剩余边界。等级 **P4**。引入：修前即有（RR-18 只接了 `ConfigureUnloadResync`）。状态：已确认（源码推断），未复现，未修复。

`demo/internal/service/game/scene.go.tmpl` 自建的 entitysync Manager 在 RR-20260927-18 之后接了卸载后重载，但没有像 `kit/nest/nest_mod.go:163-170` 那样接 `OnEntityLoaded → Rebind`。
卸载时没有非 leaving 的订阅者（例如玩家自己的会话已丢、重开也已放弃）时不会触发主动重载；之后业务重新加载这个玩家，场景的 subject 仍停在关闭的旧状态上，稍后进入视野的观察者看不到它。

修复约束：场景从 DataEngine 能力取 `OnEntityLoaded`（与 kit/nest 相同的可选接口），在 `Scene.Start` 接上、`Scene.Close` 解除，处理停机顺序；先写红回归（生成工程测试层，替身 loader），RR-20260927-18 回归不回退。
