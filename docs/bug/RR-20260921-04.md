# RR-20260921-04：game-demo 一次闲置归还批次能把刷新循环占住超过租约本身

日期：2026-09-21（登记）、2026-10-04（核实）。等级 **P2**。状态：已修复（本地提交，未推送、未发版）。
来源：[REVIEW-2026-09-21-02](REVIEW-2026-09-21-02.md) §RR-20260921-04 与 [REPRO-2026-09-21-02](REPRO-2026-09-21-02.md)（09-21 第二轮审查，当时只登记在 [README](README.md) 表行与聚合报告里，没有单独主记录）；
现状核实：[REVIEW-2026-10-04-open-triage](../review/REVIEW-2026-10-04-open-triage.md) §1.1 / §2.2（v1.19.1 上更差：40s → 45s）。本文件是 10-04 修复时补建的主记录。

## 位置、现象与根因（v1.19.1 = `d3e69336`）

- `demo/internal/service/game/playerowner.go.tmpl`：`renew:487-567` 跑在 `refreshLoop:469-483` 唯一的 goroutine 上，续租之后同步调用 `handBackIdle:566`；
  `handBackIdle` 串行最多 `handBackBudget`（8，`:327`）人，每人 `dropResident` 自带一个 `evictWait`（= `evictBudget` 5s，`:154`）计时器，
  撤离成功的再共享一份 `projectionWait`（5s，`:617`）。最坏 8×5s + 5s = **45s**。
- `demo/game/playerroute/playerroute.go.tmpl:46-47`：`Lease` 30s、`RefreshInterval` 10s。续租在批次**之前**刚发过一次，批次期间不再续，本进程其余所有租约在批次结束前过期、准入先行耗尽；
  下一轮对每一把走 “lease lost” 分支（重取带一次撤离，进一步拖长），抢不回的被 `fence`、玩家批量断线。
- U-0272 / RR-20260920-12 只界住了单次等待（个数界），没人检查这个界在批次上相乘之后还成不成立；RR-20260926-31 又在批次上加了一份投影等待。

红文本（10-04 核实）：`worst-case hand-back pass = handBackBudget(8) x evictBudget(5s) + projectionWait(5s) = 45s, not below Lease(30s) - RefreshInterval(10s) = 20s`；
缩放实跑 `one renew pass took 409ms with per-eviction wait 50ms; multiple = 8.2 -> … 40.9s`。

## 修复约束

- 界用时间表示：整个归还回合一个预算，明显小于 `Lease − RefreshInterval`，撤离与投影等待都在预算内；或把归还移出刷新 goroutine——写明选择与理由。
- 被预算截断、没归还成的玩家保留租约且 `handingBack` 复位（不丢、不放行 stale 副本）。
- 断言写成常量之间的关系，不写死数值。

## 修复（2026-10-04）

状态：**已修复**（本地提交，未推送、未发版）。记录：[docs/bugfix/RR-20260921-04.md](../bugfix/RR-20260921-04.md)。

- 新常量 `handBackPassBudget = Lease − RefreshInterval − AdmissionGuard`（15s）；`handBackIdle` 用它派生回合 ctx，撤离等待与投影等待都受它约束，
  每轮开始下一个玩家前按表自己的时钟与 ctx 检查预算，用完就停：其余已选中的玩家 `finishHandBack(…, false)`——租约留在服务、下一轮再考虑。归还仍在刷新 goroutine 上。
- 回归：`TestAHandBackPassHoldsTheRefreshLoopLessThanTheLeaseAllows`（可控时钟：每次撤离把表的时钟拨过一整份 `evictBudget` 再失败）修前红
  `one hand-back pass held the refresh loop for 40s (8 evictions at evictBudget 5s each), not below Lease(30s) - RefreshInterval(10s) = 20s`，修后 15s、3 次撤离、其余 5 人留在服务；
  另有常量关系 `TestTheHandBackPassBudgetFitsInsideTheLease` 与缩放实跑 `TestAHandBackPassStopsWaitingWhenItsBudgetRunsOut`。
