# RR-20260928-02：Guard 跨 EntityManager 同 ID 时 RR-21 的“本 handler 自己撤销”误判

日期：2026-09-28。基线：本地 main `149eaac`。来源：OPEN-ITEMS B43（批次 13 证实）。等级 **P4**。引入：RR-20260927-21。状态：已复现，未修复。

同一 handler 的 Guard 在 Manager A 上撤销新建 X，随后在 Manager B 上新建同 ID 的 X，而 B 上 X 正处在别的持有者的 Destroy 收尾窗口：预期 RR-81 的 `ErrCreatedEntityLockConflict`，实际 `ErrEntityRemoved`（“本 handler 内已撤销”）。
`entity/manager_factory.go:94` `guard.revokedInThisGuard(id)` 只按 ID 查 `revokedCreated`（`entity/entity_guard.go:90`、`:521`），不区分 Manager。红探针：`/private/tmp/claude-502/-Users-whb-roost/4f139f43-13e1-4529-b481-b39566685060/scratchpad/probes-r15/zz_b43_probe_test.go`（`//go:build probe`）。

修复约束：`revokedCreated` 以（EntityManager, ID）为键，RR-21 分支只在撤销发生在同一个 Manager 时命中；Guard `eMap` 按 ID 记的既有模糊地带不扩大、在记录里写明；RR-21 / RR-81 / RR-11 回归不回退。
