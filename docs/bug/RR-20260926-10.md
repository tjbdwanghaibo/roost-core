日期：2026-09-26。基线：main `aaada47`（v1.16.1 同一结构，不是本批引入）。等级 **P1**（进程被 fence、重启起不来，需人工处理 WAL；已回复成功的事务无法落库）。

## 触发条件

事务 A 已写入 WAL 并对调用方完成（async / strict / pipelined 均可），投影尚未把 A 写进 Mongo；此时实体被卸载——
正式生成的 lifecycle `Destroy(..., deletePersisted=false)`（登出、踢下线、淘汰等“保留存档”路径）——紧接着经 DataEngine 仓库重新加载同一实体。
本地删档（`deletePersisted=true`）只把 tombstone 写进 WAL，在其投影前重新加载会把实体“复活”，根因相同。

正常负载下投影滞后为毫秒级；Mongo 变慢、主从切换后投影退避重试（RetryMax 5s）或有积压时，“登出后立即重登”即可命中。

## 预期 vs 实际

预期：重新加载能看到 A 的结果，或等该实体的投影追上后再加载。

实际：加载直接读 Mongo，得到 A 之前的状态与版本；在旧状态上执行的事务 B 被接受并回复成功；投影 B 时期望版本不符，
报 `ErrProjectionConflict`，Projector fatal，Nest 被 fence。B 留在 WAL 里，下次启动 `Runtime.Start` 的恢复 Flush 再次冲突，进程起不来。

## 根因（代码）

- `entity/entity_manager.go:189-285`：`Destroy` 在 `deleteFromDB=false` 时没有任何“等本实体投影完成”的屏障。
- `dataengine/engine/entity_repository.go:52-109`、`:204-275`：`LoadEntity` 只检查 `gate.Ready()`（`:56`），随即 `store.ReadConsistent`（`:207`）读 Mongo，
  不看 WAL 中该实体尚未投影的事务。
- `dataengine/engine/mongo_store.go:254-265`：投影时版本 CAS 失败判为 fatal 冲突（设计正确，不能跳过冲突 WAL）。

## 复现

用正式生成的 DAO/Entity + 真实隔离 Mongo（本地 `roost-it` 副本集），复用 `codegen/internal/entity/testdata/dataengine` 的 trade fixture 与投影暂停门：
提交 A → 暂停投影 → lifecycle 卸载（保留存档）→ 重新加载 → 提交 B → 恢复投影。探针源码见 [REPRO-2026-09-26-02](REPRO-2026-09-26-02.md) §1。
2026-09-26 复审方二次实跑（Go 1.27.0，darwin/arm64，库名 `roost_generated_it_probe_*`，跑后已删除）三种策略一致：

```text
memory after A: coins=9997 version=2
memory after unload+reload: coins=10000 version=1 (A's effect visible? false)
transaction B on reloaded entity: err=<nil>
projector fatal after resume: conflict=true err=... fatal projection version conflict: .../trade_inventories/31765252 expected=1 next=2 stored=2
--- FAIL: TestZZProbeUnloadReloadBeforeProjection/{async,strict,pipelined}
```

## 影响

已回复成功的事务 B 无法落库；进程 fence 后，重启恢复阶段再次冲突，必须人工处理 WAL。与 RR-20260924-12（永久版本冲突触发 fencing）的 fail-closed 设计一致，
但触发源是框架自己的“卸载→重载”路径，不是外部写入。

## 实施方向（约束）

- 重载同一实体前必须看到该实体已写入 WAL 的全部事务（等待其投影完成，或从 WAL 未投影部分补齐），不能以读 Mongo 旧版本继续接受事务。
- 不能跳过冲突 WAL、不能放宽版本比较来“恢复”。删档 tombstone 路径同样适用。
- 等待应在慢阶段完成（快池不得阻塞，见 roost-coding）。

## 验收覆盖点

- 三种持久级别：A 未投影时卸载并重载，重载后看到 A；B 正常投影，无 fatal。
- 删档 tombstone 未投影时重载不复活实体。
- 投影积压 / Mongo 慢时登出重登不 fence；重启恢复通过。
