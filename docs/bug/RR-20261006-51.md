# RR-20261006-51：施放中的衍生物在移交之前不推进，移交前的 tick 永久丢失

2026-10-07，基线 `47abe511`（main，v1.23.0 之后）。P2（法术场、光束、飞行物等在施法 `wait` / `repeat` / policy 等待期间不结算，寿命照常流逝）。来源：框架文档审查 [FRAMEWORK-DOCS-FINDINGS-2026-10-07](../review/FRAMEWORK-DOCS-FINDINGS-2026-10-07.md) 的 F08-R，详见 [08-skill 实现](../framework/impl/08-skill.md) §11 R1。
状态：已复现；已修复（`50a0fe88`，[修复](../bugfix/RR-20261006-51.md)），未发版。

## 机制

1. `advanceOwnedSpawns` 与 `nextOwnedSpawnTick` 只看已移交分区（基线 `skill/spawn_owned.go:294`、`skill/scheduler.go:313-322`）。
2. 施放中分区的衍生物唯一的推进路径是 `spawnStepTask`，它在生产路径上没有创建点，只能从 checkpoint 解出来（基线 `skill/runtime_checkpoint.go:1157-1158`）。
3. 召唤后施法没有立刻 `finish` 时，衍生物停在启动那一步；`EndTick` 照样从启动算起，移交后只补走一步，中间的 tick 永久丢失；施法等得比衍生物寿命还长时，衍生物在移交那一刻才补一步再到期。
4. 维护者 2026-10-07：先补“施放 → 移交 → 停止”端到端用例，再在这套用例上修。
