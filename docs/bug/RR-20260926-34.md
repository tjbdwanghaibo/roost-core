# RR-20260926-34：DataEngine 投影在 Mongo 事务内撞唯一键后继续读——真实 Mongo 已中止事务，“相同即成功 / 漂移即 fatal”失效，投影卡死

日期：2026-09-26。基线：v1.17.0（`8811c02`）。等级 P2（WAL 头部卡住，全部实体投影停止；身份冲突被降级为非 fatal 无限重试）。状态：已在真实 Mongo 复现，未修复。

## 根因

`dataengine/engine/mongo_store.go:358-383`（stageReceipt）、`:399-419`（stageEffect）、`:285-297`（insertTransactionMarker）都在 `session.WithTransaction` 回调内
（调用点 `mongo_projection.go:98,119,124,128`）InsertOne 撞键后在同一事务 FindOne；真实 Mongo 事务内写错误即中止，FindOne 返回 `NoSuchTransaction`（带 TransientTransactionError 标签，
`errors.Join` 后仍被识别），驱动重跑回调直到 transaction_timeout（生成配置 30s）。`mongo/driver/collection.go:359` 把驱动错误换成裸 `fmongo.ErrDuplicateKey` 丢了标签。
单测未发现：`mongo/mongotest/mongotest.go:770,917,979` 撞键后不中止事务。

## 复现（真实 Mongo 8.0.28，[REPRO-2026-09-26-04](REPRO-2026-09-26-04.md) §2，TransactionTimeout=5s）

```text
A 同一 receipt 另一事务: design=nil → elapsed=5.29s err=context deadline exceeded fatal=false docWritten=0
B receipt payload 漂移: design=ErrReceiptIdentity(fatal) → 5.01s 同上 isReceiptIdentity=false fatal=false
C effect id 被另一事务复用: design=ErrTransactionIdentity(fatal) → 5.19s 同上 fatal=false
D 同一记录 8 路并发投影: 40ms errs=all nil markers=1（marker 撞键走 WriteConflict，正常）
原始驱动: callback invocations=25 firstInsert=duplicate key firstFind=(NoSuchTransaction) Transaction … has been aborted
```

触发：另一事务的多文档投影复用同一 receipt 或 effect ID（saga-start effect 为内容哈希 `saga/nest.go:49-51`、`saga-completion:<cmd>`、业务自定义稳定 Effect ID）。

## 修复约束

事务内先快照读再插入（并发插入以 WriteConflict 触发驱动重试），或撞键立即返回哨兵、在事务外重读裁决；保持“相同即成功、漂移即 fatal 身份冲突”；不吞 Transient 标签；
**必须补真实 Mongo 集成回归**（伪 Mongo 需同步改为忠实地在事务内写错误后中止）。附带语义：同一 saga start 在两个事务各发一次按现有设计为 fatal——修复时保持并在记录中写明。
