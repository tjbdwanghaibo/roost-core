# RR-20261006-49：排队模式下永远不会被接受的 retry pair 让 Drain 永不结束

2026-10-07，基线 `47abe511`（main，v1.23.0 之后）。P2（卡住：停机在 Drain 处超时返回，走不到 Close；无日志）。来源：[FRAMEWORK-DOCS-FINDINGS-2026-10-07](../review/FRAMEWORK-DOCS-FINDINGS-2026-10-07.md) 的 F04-2，[04-sync 实现 §10.2](../framework/impl/04-sync.md#102-本篇写作时发现的源码疑点待闭环)。
状态：已复现；已修复（`04378f7c`），未发版。[修复](../bugfix/RR-20261006-49.md)。

## 机制

1. 被 Manager 拒绝的订阅进入 `Interest.retry`，每次 `Apply` 重说，直到被接受或 pair 被释放（RR-20260920-06：拒绝不是对 pair 的裁决）。
2. 排队模式的 `queuedPending` 把整个 retry 计入（基线 `policy/interest_queue.go:112-116`），`Drain` 的退出条件要求它为假（`sync/entitysync/drain.go:22`）。
3. 一个永远不会被接受的 pair（观察者会话已关闭且不再重开、subject 已注销而政策没 Hide、resubmit 被拒）让 `queuedPending` 恒真，`Drain` 只能等 ctx 超时；kit 停机在 Drain 处返回（`kit/nest/nest_mod.go:331-333`）。排队模式还丢掉 `Apply` 返回的 Refusal（`interest_queue.go:108`），没有任何日志。
