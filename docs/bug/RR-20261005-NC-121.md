# NC-121：actionflow 丢弃排队动作（ClearQueue / EndAll / ClearMission）不发 OnEnded

2026-10-05，基线 `197f7bb9`。P2（被丢弃的排队动作已发过 OnQueued、ID 已交给 Enqueue 的调用方，此后再也没有结束事件：用 `EnqueueAction` 发起的 `ai.TaskflowAction` 叶子永久 Running，Hook 侧维护的排队视图——例如同步给客户端的动作队列——永久残留；目前无生产使用方）。状态：已复现、已修复、声明场景验证，未发版。[修复](../bugfix/RR-20261005-NC-121.md) · [本轮](../review/REVIEW-2026-10-05-noncore-n10.md)。

## 触发与差异

`actionflow/action_runner.go`（基线）：`Enqueue`（`:106`）建条目后发 `OnQueued`（`:120`）并把 ID 返回调用方；排队项启动失败时 `start` 会发 `OnEnded`（`:314`），已有用例 `TestActionRunnerQueuedStartFailureContinuesQueue` 把“排队项失败也要被观察到结束”钉住。但三处丢弃路径只清切片：

- `EndAll`：`:218` `unit.next = nil`
- `ClearQueue`：`:225` `unit.next = nil`
- `ClearMission`：`:240-249` 过滤掉本任务的排队项

触发：组内有正在跑的动作，再 `Enqueue` 一个 → 调用上面任一方法。预期：被丢弃的排队项发一次 OnEnded（取消状态），不调 Start / Cancel、不发激活切换。实际：没有任何结束事件。
