# 2026-09-12 第二轮：Mirror 集成观察

基线与验证见[运行记录](../review/REVIEW-2026-09-12-02.md)。本轮没有新增确认 RR，也没有关闭旧问题。

| 观察 | 证据 | 判断 |
| --- | --- | --- |
| `remote=mirror` 未接只读运行时 | entity/policy.go、entity_factory.go:341、Nest shouldPrepareRemoteID、codegen gen.go:34；M-04 已明示 | 已知功能缺口，不冒充新回归；不能向业务承诺标记自动只读 |
| 通用缓存删除不保留版本水位 | entity/remote_snapshot.go:389；临时 race 探针：v2 → Delete → 迟到 v1，结果 v1 | 作为失效原语可解释；接成只读复制协议前必须补防复活机制 |
| Remote 接收删除直接失效缓存 | remoteentity/syncer.go:103–104 不比较 env.Version；cache/mirror.go:98–102 同样直接 Delete | 源码风险；真实 broker 顺序、旧删除投递与权威回填交错尚未端到端复现，后续单独验收，不扩大成已确认数据丢失 |
| 完整 Remote Assembly 含写侧依赖 | remoteentity/assemble.go:49–95 要求 Redis 和原子 backend | 不适合作为轻量 Mirror 默认装配；建议提取读组件 |

完整复用清单、只读封口、版本墓碑、重连恢复与验收计划见[实现学习与方案](../review/IMPLEMENTATION-REMOTE-POLICY-MIRROR.md)。
