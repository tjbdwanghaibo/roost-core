# RR-20261006-74：nats.rpc.transport=jetstream 的部署里，生成的 ClientMod 总走轻量传输，每次调用都被请求流截获

2026-10-07，基线 `c78d0c34`（main）。P1（按文档“两端 transport 一致”配置的跨进程服务调用全部失败）。来源：F09-R3（推断），[impl/09 §3.1](../framework/impl/09-kit-services.md)。
状态：已复现（真实 NATS）；已修复（`a9bb8923`，[修复](../bugfix/RR-20261006-74.md)），未发版。

## 机制

服务端开 JetStream RPC 后 `bus.HandleRpc` 只订阅 JetStream（`bus/bus.go` :659-666）。生成的 ClientMod 的 `Init` 只读 `<svc>.service_type` / `call_timeout`，不读 `nats.rpc.transport`（`servicerpc.OptionsFromConfig` / `WithTransport` 在生成代码里零调用），客户端总走 request-reply，请求被请求流存下，调用方得 `bus.ErrRPCCapturedByJetStream`（RR-20261005-NC-92 的拒绝）。
