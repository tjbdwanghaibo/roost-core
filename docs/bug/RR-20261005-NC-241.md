# NC-241：ai 策略回调里 SetStrategy / Shutdown 立即切换，旧树接着跑、发起的动作成孤儿

2026-10-06，基线 `81d7cb16`，分支 `revn10b`（N10 第二批）。P2（ai / actionflow 仓内无生产使用方；hotcode 由 Nest 全局 handler 与 game-demo 使用）。状态：已复现、已修复、声明场景验证，未发版。[修复](../bugfix/RR-20261005-NC-241.md) · [本轮](../review/REVIEW-2026-10-06-noncore-n10b.md)。

## 触发与差异

`ai/controller.go:43-81`（基线）SetStrategy 只在 `switching` 期间拒绝重入；`Tick` / `OnActionEnd` / `OnMissionEnd` 调策略时不设任何标记。行为树节点（FuncNode、Condition、TaskflowAction.Launch）里调用 `SetStrategy(next)` 或 `Shutdown`：EndActions 结束现有动作、Stop 旧策略（BehaviorStrategy 在这里 Reset 整棵树），然后控制权回到仍在执行的旧 `root.Tick`。

预期：被替换的策略在 Stop 之后不再发起动作；切换的 EndActions 覆盖旧策略发起的全部动作。

实际：旧树从被 Reset 的状态接着跑：Sequence 的下一个叶子发起新动作，这个动作在 EndActions 之后才出现，没有被切换结束；它的结束通知送给了新策略，旧叶子永远收不到。事件顺序 `[end_actions stop launch]`；Shutdown 同理 `[stop launch]`。
