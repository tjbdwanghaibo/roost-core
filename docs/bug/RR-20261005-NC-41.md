`saga/mongo_store.go` 的 ClaimOutbox：Find 筛选 `next_attempt_at <= Now`，但随后的 FindOneAndUpdate 只检查 ID 和 lease_until。两个发布者扫描同一消息，A 先领取、失败并 Nack，将 next_attempt_at 延至未来且释放租约；B 持有旧候选，在未来期限前再次领取。违反 outbox 到期领取契约，绕过配置的退避，失败依赖可能受到额外发布压力。不是证明消息重复执行业务；业务幂等仍由收件箱承担。

当前源码入口 `saga/mongo_store.go:314`，原子条件补修位置`:326`；基线用 `git show 12726715:saga/mongo_store.go`核对，不把新增注释后的行号当旧行号。
