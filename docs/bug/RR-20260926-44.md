# RR-20260926-44：PrepareRemoteWriteBatch 失败时 Abort 无条件经 RunLocal，多占一次快池续行

日期：2026-09-26。基线：v1.17.0（`8811c02`）。等级 P3（性能：Remote 争用时给快池加压）。状态：已复现，未修复。

`remoteentity/batch.go:475` Abort 无条件 `entity.RunLocal`；`PrepareRemoteWriteBatch` 在 `:85-97` 失败时调用，ctx 带慢阶段执行器 → `dispatchFastContinuation`（`nest/remote_dispatch.go:68-85`）。
复现：[REPRO-2026-09-26-04](REPRO-2026-09-26-04.md) §10 `prepare err=…not found, local-executor hops=1`，此时无已定稿本地状态需回滚。
修复约束：未 finalized（无本地状态需回滚）时就地只置 aborted 标记，不走 RunLocal；已 finalized 的回滚仍在快池持锁执行。
