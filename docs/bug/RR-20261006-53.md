# RR-20261006-53：衍生物回调不继承施法的事件链，每个 tick、每个目标同一个 EventID

2026-10-07，基线 `47abe511`。P2（proc 深度在衍生物处清零，`max_depth` 管不住“被动 → 召唤衍生物 → 回调伤害 → 被动”；按事件 ID 掷骰的 Host 每 tick 结果相同）。来源：F08-R，[08-skill 实现](../framework/impl/08-skill.md) §11 R3。
状态：已复现；已修复（`50a0fe88`，[修复](../bugfix/RR-20261006-53.md)），未发版。

## 机制

1. 衍生物的 `eventContext` 只填 tick / source / owner / target / skill / cast / spawn（基线 `skill/spawn_owned.go:38`），`EventID` / `RootEventID` / `ProcDepth` 都是 0。
2. 回调里的效果经 `effectEventContext` 取 `castID<<32 | (effect+1)`（基线 `skill/runtime_cast.go:231-236`）：回调跑在脱离施法的 cast 上，`cast.id` 是所属施法，同一个回调效果每个 tick、每个目标都是同一个 ID；`deriveEvent` 得到 root=0，`dispatchEvent` 再把根改成事件自己。
3. 结果：衍生物自成一个根、深度 0；施法自己的伤害与衍生物的伤害分属两个根，`once_per_root` 触发两次；同一目标每 tick 的事件 ID 相同。
