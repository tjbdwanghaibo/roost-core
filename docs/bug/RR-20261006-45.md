# RR-20261006-45：MongoStore.ClaimDue 遇到一条坏记录整批丢弃、List 整次失败

2026-10-07，基线 `0b223b4c`（main，v1.23.0 之后；WIP `wip/sagafix` `bcdb4bd4` rebase 到此）。P3（同批正常记录等一个租约才被处理；运维面读不出其他记录）。来源：框架文档审查 [FRAMEWORK-DOCS-FINDINGS-2026-10-07](../review/FRAMEWORK-DOCS-FINDINGS-2026-10-07.md) 的 F06-S3，详细证据见 [06-saga 实现](../framework/impl/06-saga.md) §11 S3。
状态：已复现；已修复（`63bc1d66`），未发版。[修复](../bugfix/RR-20261006-45.md)。

## 机制

1. `MongoStore.ClaimDue` 逐条领取后才 `validatedRecord`，失败时返回 `out, err`（基线 `saga/mongo_store.go:236`）；`coordinatorLoop` 在 `err != nil` 时整批丢弃（`saga/engine.go:759-767`），已领取的正常记录要等 `LeaseDuration`（15s）才被重新领取；坏记录排在前面时每一轮都如此。
2. `List` 遇到一条坏记录整次失败（基线 `saga/mongo_store.go:144-151`），运维面也读不出别的记录。
3. 触发：手工改坏文档，或不兼容的写者整体 Replace 丢了字段。
