# RR-20261007-05：事务标记 TTL 未覆盖 WAL 告警窗口

- 日期：2026-10-07；基线：`6f0c1bd8`；来源：F03-12；P2。
- 状态：已复现、已修复，未提交、未发布；组合验证进行中。

Kit 与直接 Assembly 装配未比较事务标记 TTL 与 WAL MaxUnackedAge。Mongo TTL 按整秒存储，原值略大于窗口也可能被截成相等。去重标记过早删除后，积压事务失去持久身份凭据。

修前命令：`GOWORK=off go test ./kit/dataengine -run TestTransactionReceiptRetentionExceedsWALWindow -count=1`，实际失败：

```text
receipt_retention_promises_test.go:18: transaction_receipt_ttl=1h accepted: <nil>
receipt_retention_promises_test.go:18: transaction_receipt_ttl=24h accepted: <nil>
receipt_retention_promises_test.go:18: transaction_receipt_ttl=24h500ms accepted: <nil>
```

MaxUnackedAge 只是健康阈值，不会令日志过期。因此启动校验仅排除明显冲突，不证明任意长停机恢复安全。CBM 旧代际按当前源码补证。[修复记录](../bugfix/RR-20261007-05.md)。
