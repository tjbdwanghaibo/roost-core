# RR-20261006-07：`app.run` 启动阶段失败的退出原因不进文件日志

2026-10-06，基线 `8a292a5a`。P3（排障信息缺失；只看日志文件的运维看不到进程为什么退出）。来源：收尾盘点 A13。状态：已复现；已修复、声明场景验证，未发版。[修复](../bugfix/RR-20261006-07.md)。

## 机制

`app/app.go` `run` 初始化文件日志后 `defer flog.Close()`，生成的 main 在 `run` 返回之后才 `slog.Error("server exit", "err", err)`——那时文件日志已关，这一行只到 stderr（RR-20261005-NC-165 的回退）。Serve / Shutdown 的错误 `run` 自己记过；启动阶段（Mod Init / Provide / Start、单实例锁、业务时间检查）失败是直接 `return`，文件里没有任何错误行。

## 触发与差异

文件日志开、stdout 关，一个 Mod 的 Init 返回错误：预期日志文件里有这条错误；实际只有 `starting server` 与 `mod init` 两行。

## 复现

`TestRunWritesTheExitReasonToTheFileLog`（`app/exit_reason_log_promises_test.go`）修前：

```
--- FAIL: TestRunWritesTheExitReasonToTheFileLog (0.00s)
    exit_reason_log_promises_test.go:48: the exit reason "mod init failed: exit reason 7c1e" is not in the file log:
        ... msg="starting server" ...
        ... msg="mod init" mod=exit_reason
```

## 修复

[修复记录](../bugfix/RR-20261006-07.md)：关闭文件日志之前写一行 Error，带最终错误。
