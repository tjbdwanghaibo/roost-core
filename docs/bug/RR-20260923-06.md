# RR-20260923-06：Group.AddSubject 部分失败后残留成员状态且无法重试

- 日期：2026-09-23；等级：P2；模块：Sync。
- 基线：`967bc69` + 前一轮 R1～R3 与 RR-01～03 工作树。
- 状态：已复现、修复并通过定向回归与模块 race 验证，未发布。[修复记录](../bugfix/RR-20260923-06.md)。

## 触发、预期与实际

Group 中同时存在有效会话和尚未开通的会话，随后 AddSubject。预期添加失败后没有残留的组内实体或本组订阅；补齐会话后能重试成功，同时保留其他来源的订阅。

先把实体加入 g.subjects，再逐成员订阅，返回错误时没有回滚。有效成员可能已订阅，下一次 AddSubject 被 ErrGroupSubjectPresent 拒绝。

## 证据

`go test ./sync/entitysync/policy -run 'TestGroupAddFailureCanBeRetriedWithoutPartialMembership' -count=1`。修前残留组内实体/订阅断言失败。测试位于 `sync/entitysync/policy/group_ownership_promises_test.go`，按明确的成员添加、失败重试或来源释放顺序验证状态。

相关实现：`sync/entitysync/` 下的 policy/group.go。影响边界及行为迁移见修复记录。
