`remoteentity` 包里其余 Redis 访问只有上述三处（`Assemble` 只把 `deps.Redis` 交给 L2 与锁工厂；`interest.go` / `syncer.go` 的 `remote_entity_*` 是 sync bus topic，不是 Redis 键）。

## 触发条件、预期与实际

- 触发：两个非 authority 兼容装配（各自 `NewManager` + `SetOwnershipStore(NewRedisMarker(redis, ""))`）连同一个 Redis db，同一实体 ID。
- 预期：每个部署只看到自己的所有权租约。
- 实际：两边都写 `remote_entity:marks` 这把 hash 的同一个 field；A `ClaimOwnership` 之后 B `GetOwnership` 读到 A 的租约（owner=A 的 sid），B 自己的 Claim 会被当成“别人已是 owner”而拒绝。
- 锁键：缺省 `lock:e:<id>` 同样跨部署共享（同 ID 时互相争锁、共用 fence 计数器），但 `lock_key` 已可配置——这是缺省值 + 文档问题，不是缺少配置面。
