# RR-20261004-02：`LayeredStore` 的 L1 过期后（或 ttl≤0 时）仍永久否决权威值；远端写已生效却报 `ErrStaleWrite`

日期：2026-10-04。基线：v1.19.0（`74e1ba39`），main `2f111e9b`。来源：[B 线 NC 修复独立复审（第三组）§3](../review/REVIEW-2026-10-04-nc-audit-3.md)。等级 **P2**。状态：已确认，未修复。

## 现象、根因与修复约束

D1：NC-14 与 NC-15 叠加引入的回退。根因 `cache/layered.go:58-73`（回填遇 `ErrStaleWrite` 一律读回 L1，不看 `localValid`）与 `:115-118`（远端写成功后 L1 拒绝即把错误返回给调用方）；`local.go:75` 让 LocalStore 真正返回该错误。可达：codegen 生成的带版本字段的 `NewCached*RedisDAO`。修前 `42804572` ttl=0 正确、ttl>0 只错一个窗口；v1.19.0 永久错。修复约束：回填遇 stale 时只有 `localValid` 为真才交付 L1；否则删 L1 再用 L2 值回填（ttl≤0 不回填）；`Set` 远端成功后 L1 拒绝不报错（删 L1）。保留 NC-14 的三条红用例。

复审报告里有修前 / v1.19.0 实测输出与会红的测试草稿（探针文件在审计 scratchpad，未入库）。
