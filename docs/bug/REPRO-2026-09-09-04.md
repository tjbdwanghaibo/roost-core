## RR-20260909-05

以下测试复用 match 同包现有 newStore/ranked/player 助手，使用真实 MemoryStore。

```go
package match

import (
    "context"
    "errors"
    "testing"
)

func TestReviewEnqueueReplayKeepsSubjectOwnership(t *testing.T) {
    store, _ := newStore(t)
    ctx := context.Background()
    first, err := store.Enqueue(ctx, ranked(), player(1, 100), "shared-request")
    if err != nil { t.Fatal(err) }
    replay, err := store.Enqueue(ctx, ranked(), player(1, 100), "shared-request")
    if err != nil || replay.ID != first.ID {
        t.Fatalf("valid owner replay failed: %v", err)
    }
    foreign, err := store.Enqueue(ctx, ranked(), player(2, 900), "shared-request")
    _, _, readErr := store.Ticket(ctx, ranked(), first.ID, player(2, 900))
    if !errors.Is(readErr, ErrNotPermitted) {
        t.Fatalf("control Ticket read should refuse: %v", readErr)
    }
    if err == nil {
        candidates, e := store.Candidates(ctx, ranked(), 10)
        if e != nil { t.Fatal(e) }
        t.Fatalf("cross-subject replay succeeded: owner=%s score=%d; candidates=%d; direct Ticket read=%v",
            foreign.Subject.Key(), foreign.Subject.Score, len(candidates), readErr)
    }
}
```

保存为临时 match_review_test.go。临时 go.work use 三仓绝对路径；GOWORK 指向它。overlay JSON 的 Replace 将不存在的 D:/whb_s/cube-kit/service/match/review_external_test.go 映射到该临时测试绝对路径。Kit 中执行：

```powershell
go test -race -overlay <match-overlay.json> ./service/match -run '^TestReviewEnqueueReplayKeepsSubjectOwnership$' -count=1 -timeout=30s
```

实际 FAIL：cross-subject replay succeeded: owner=player:1 score=100; candidates=1; direct Ticket read=match: caller does not own this ticket。随机票据 ID 省略。正常重试和 Ticket 拒绝均先作为对照验证。
