# RR-20260925-02：直接构造 MongoCommitter 可绕过持久许可

- 日期/基线：2026-09-25，Remote authority 工作树；P1，remoteentity。
- 触发：直接调用 `NewMongoCommitter`，未调用原 `EnableWriteAuthority`，以 base=0 提交一个没有 ownership/grant 的实体。
- 预期：所有 Mongo Remote 写均须匹配持久权限；不因装配方式不同降级。
- 原行为：`requireAuthority` 零值 false，`applyCommitMetadata` 进入旧 `applyCommit`，CAS 不匹配后插入 legacy metadata 并继续落 DAO；正式 Assembly 会打开开关，因此正式装配不受此旁路影响。
- 根因：构造时的隐式弱模式及有副作用的能力 getter，遗留兼容路径与新持久权限契约并存。
- 回归：`go test ./remoteentity -run '^TestMongoCommitterRejectsWriteWithoutGrantByDefault$' -count=1`。新测试验证默认构造必须拒绝；原实现证据来自源码，本轮保留修后回归结果。
- 状态：已修复，相关 race/vet 已通过。[修复](../bugfix/RR-20260925-02.md)。
