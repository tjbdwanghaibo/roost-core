# RR-20261008-42：Layered 冷键准入元数据无界增长

P2，已修复、未发版。来源：CARRYOVER N04 Layered 容量历史候选；基线 88fc852c。

L1/L2 各只保留 1 个值时，连续 Set 70000 个不同键，Layered.expiry 仍保存 70000 个截止时间。只有再次读取同一个过期键或显式 Delete 才会删除元数据，故内存随累计访问键数增长，与实际缓存容量无关。

修前 `TestLayeredColdKeysHaveBoundedMetadata` 实跑失败：`expiry entries=70000, want <=65536 while each backing cache holds 1`，原始证据 `artifacts/perf/outbox-closure-20261008/layered-red.log`。65536 是本次明确的缺省容量，不是宣称旧实现已有此配置。

根因在 `cache/layered.go` 的无容量 expiry map。修复与行为边界见[修复记录](../bugfix/RR-20261008-42.md)。
