# RR-20260924-06：Ticker 并发 Start/Stop 可能残留运行

- 日期 / 基线：2026-09-24，`967bc69` 加 Nest N1/N2a 工作树；等级 P2。
- 状态：已复现、已修复，未提交、未发布；见 [修复记录](../bugfix/RR-20260924-06.md)。

## 触发与根因

两个 goroutine 同时调用 Ticker.Start 和 Stop。原实现用独立的 started/stopped atomic：Start 先读到 stopped=false，Stop 随后设置 stopped=true 并看到 started=false，直接返回；Start 最后才 CAS started 并启动循环。Stop 已返回，ticker 却继续执行，stopChan 没有关闭。

预期是 Stop 返回后，已启动的 run 已退出，或 Start 已被阻止。问题属于生命周期状态转换缺少共同临界区，不是 atomic 单字段存在 data race；仅靠 race detector 不能发现这个顺序缺陷。

## 最小复现

[completion_unlock_test.go](../../nest/completion_unlock_test.go) 用通道同时放行 Start/Stop，WaitGroup 等待二者返回，20,000 次检查已启动实例的 done 必须关闭；测试遇到旧代码泄漏时主动清理。修前实际失败：

```text
iteration 7127: stopped ticker retained a live run
```

```sh
GOCACHE=/tmp/roost-nest-go-cache GOWORK=off go test ./nest \
  -run '^TestTickerConcurrentStartStopAlwaysClosesStartedRun$' -count=1
```
