## 修复（2026-09-26）

已修复，按上方修复约束实现，见[修复记录](../bugfix/RR-20260926-52.md)。生成 TCP 传输在某条连接推送 / 写失败时立即注销并关闭这一条连接
（连接槽、按 IP 计数与关闭事件仍由读循环的 defer 各释放一次），其余连接收到则推送成功；没有任何连接收到时推送失败、全部连接已关闭，scene 按会话丢失
使玩家离场。写之前就被拒绝的推送（ctx 结束、payload 超限）不关闭连接。失败连接被注销后不会再收到推送，重同步对同一失败连接至多一次。
