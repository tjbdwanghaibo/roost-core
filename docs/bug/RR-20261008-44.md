# RR-20261008-44：兴趣广播故障耗尽快照读取预算

P1，已修复、未发版。Mirror S2 真实三节点 NATS 在 SIGSTOP 下，owner 已确认 v7，但只读方 30s 后仍 `TIMEOUT 7 last=6`。日志保留于 `artifacts/perf/outbox-closure-20261008/mirror-local.log`；后续场景还被未恢复的暂停节点连带影响。

根因：`SnapshotClient.ReadSnapshot` 在 `cache.Read` 之前同步 `RenewInterest(ctx)`，虽然忽略续租 error，却共用并耗尽 caller ctx。设计宣称“兴趣失败不影响这次读”，实际读 L2/权威时预算已结束。

直接回归用等待 ctx 的兴趣 publisher 与健康权威 loader。旧同步路径 overlay 复现读取预算耗尽；新路径 3 次通过。额外检查队列容量、旧代际、释放与停止重试；真实 S2 修后收敛 2967ms（配置陈旧上限 3s），读取 errors=0。不是通过扩大超时或跳过静默断线验收修复。
