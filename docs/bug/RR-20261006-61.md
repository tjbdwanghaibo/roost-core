# RR-20261006-61：lockstep 指标名在合仓时丢了 `lockstep.` 前缀，desync 告警永不触发

1. 合仓提交 `c8249526`（staging/lockstep → lockstep）把 `room.go` 里 7 处 `metrics.IncCounter("lockstep.xxx")` 改成了裸名 `frame.total`、`input.late.total`、`input.rejected.total`、`catchup.frames.total`、`desync.total`。
