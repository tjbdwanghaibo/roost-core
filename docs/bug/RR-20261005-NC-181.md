# NC-181：RangeAll 的 false 只停当前桶，EntityManager.Range 的提前停止不成立

2026-10-05，基线 `f6245613441d16aafec33870166a4ec14f1ca15b`。P3（仓内正式调用方 `kit/statslog` 总是返回 true；公开的 `ManagerAccess.Range` / `RangeByCategory` 写明可以提前停止）。状态：已复现，未修复。[本轮](../review/REVIEW-2026-10-05-n13.md)。

## 触发与差异

`container/bucket.go:54-58`：

```go
func (h *BucketHolder[K, T]) RangeAll(f func(K, T) bool) {
	for _, bucket := range h.Buckets {
		bucket.Range(f)
	}
}
```

`Bucket.Range` 在回调返回 false 时 break，但 `RangeAll` 不知道，接着遍历下一个桶。`EntityManager.Range`（“Return false from fn to stop early”）与 `RangeByCategory` 包装的就是它：找到第一个目标就返回 false 的回调，还会在其余每个非空桶里各被调用一次——“找第一个”会被后来者覆盖，“最多处理 N 个”会多处理 bucketCnt-1 个。

预期：回调第一次返回 false 后不再被调用。

## 复现

`TestRangeAllStopsAtTheFirstFalse`（8 桶 64 键）与 `entity` 组合叶 `false stops Range and RangeByCategory`（4 桶 32 实体）：

```
bucket_range_promises_test.go:63: callback ran 8 times after returning false on the first entry, want 1

```

## 约束

`RangeWithCursorCnt` 的 false 同样只停当前桶，零调用方；修复时一并按“立即停止”处理，游标只记已开始遍历的桶。
