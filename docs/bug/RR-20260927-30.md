# RR-20260927-30：RR-25 修得不完整：自定义 Mutex 结构体含装着 func 的接口字段时 `sameMutex` 仍 panic

日期：2026-09-27。基线：本地 main `001b03b`。来源：第六轮独立审计（审计记录随第二路合并后写入 `docs/review/REVIEW-2026-09-27-audit6.md`）。等级 **P4**。引入：修前即有（RR-20260927-25 未覆盖）。状态：已修复（[修复记录](../bugfix/RR-20260927-30.md)，分支 `fix-r8-b13`，基线 `a136c98`），本地提交，未推送。

`entity/entity_guard.go` `sameMutex` 用 `reflect.Type.Comparable()`；结构体含接口字段时 Type 层面返回 true，接口里装着 func 等不可比较值时 `a == b` 运行期仍 panic（reflect 文档明确写明）。
探针 `TestAud8InterfaceFieldMutexValue`：`PROBE P25: RequireEntity(fresh) panicked: runtime error: comparing uncomparable type func()`。`ReleaseEntityInstance` 比较 superseded 时也用 `sameMutex`，同样适用。

修复约束：改用 `reflect.ValueOf(a).Comparable()`（Go 1.20+，按值判定），或在比较外 recover；框架锁仍走指针快路径、不加反射开销；RR-25 / RR-26 回归不回退。探针原文见 [RR-20260927-29](RR-20260927-29.md)。
