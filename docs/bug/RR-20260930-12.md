# RR-20260930-12：引擎 fence 之后，带 Remote 批次、没有 effect 的 memory handler 仍以 Durability 0 直写权威

日期：2026-09-30。基线：`4784ef82`。来源：REMAINING §3 N21（RR-20260927-32 §未验证项、audit7 §疑点），维护者 2026-09-30 拍板“收紧”。等级 **P2**：引擎 fence（本进程已有事务结果未知）之后仍有一条路径向 Remote 权威写入，破坏“fence 之后本实例不再写”的恢复前提；不丢数据、不重复提交。状态：已复现；2026-09-30 已修复，未发版，见文末“修复”。

## 触发

1. 一条带 Remote 批次（声明了 remote-managed 目标）的 memory handler（`Rollback: RollbackNone, Durability: DurabilityMemory`），handler 里不 `Emit` effect。
2. handler 执行期间（或之前）别的消息把引擎 fence（例如嵌套独立事务结果未知，RR-20260926-76）。
3. handler 正常返回。

## 预期

与 RR-20260927-06 对交给 committer 的记录相同：fence 之后消息自己的提交被明确拒绝——回复满足 `errors.Is(err, nest.ErrNestFenced)` 与 `nest.ErrCommitRejected`（判别表第 12 行），Remote 批次 Abort、不 Commit，committer 不被调用；RollbackNone 的内存修改不撤销。

## 实际

回复成功，Remote 批次 `Commit` 一次（Durability 0 直写权威），没有 Abort。回归 `nest/fenced_memory_remote_no_effect_promises_test.go` 在基线上：

```text
--- FAIL: TestFencedMemoryRemoteWithoutEffectIsRefused (0.00s)
    fenced_memory_remote_no_effect_promises_test.go:46: reply=ok committer=0 remote commits=1 aborts=0 value=77
    fenced_memory_remote_no_effect_promises_test.go:48: Remote batch was committed 1 time(s) after the engine was fenced: a Durability 0 write reached the authority behind the fence
```

## 根因

`nest/rollback.go:585` `durableCommit`：`tx.durability == DurabilityMemory && len(tx.effects) == 0` 时直接 `return nil`，在 `refuseCommitAfterFence()`（`:601`）之前返回。`commitDurable`（`nest/execution.go:310-320`）把 nil 当作提交成功，置 `msg.remoteCommitted = true`；`finishRemoteWriteBatch`（`nest/msg.go:90`）据此 `batch.Commit`。RR-20260927-06 的 fence 检查只覆盖“记录要交给 committer”的路径（memory handler 只有 emit 了 effect 才走到），带 Remote 批次而无 effect 的 memory handler 从没经过它。

## 修复约束

1. 在 `durableCommit` 的 memory 早返回分支里，消息带 Remote 批次（`tx.dispatch.RemoteWriteBatch != nil`）时先做同一个 `refuseCommitAfterFence` 检查；拒绝走 `commitDurable` 既有的明确拒绝分支（Abort 批次、`rejectCommit` 加 `ErrCommitRejected`）。
2. 不改 memory + RollbackState 无 Remote 批次的路径（它没有任何持久或 Remote 写，不在本条范围）；不改嵌套独立事务（`dispatch == nil`）的规则。
3. 快池内只读一次 `FenceError`，不新增等待。
4. 回归：fence 后带 Remote 批次、无 effect 的 memory 消息——`ErrNestFenced` + `ErrCommitRejected`、批次无 Commit 有 Abort、committer 0 次、值不撤销；RR-20260927-32 的四个子用例不变。
