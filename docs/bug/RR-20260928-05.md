# RR-20260928-05：生成的 shell / systemd 安装不提供 `configs/data`（推断）

日期：2026-09-28。基线：本地 main `149eaac`。来源：批次 14 源码核对。等级 **P2（推断，待实证）**：与 RR-20260927-34 同形。引入：修前即有。状态：已确认（源码），未实跑。

`renderShellInstall` 只安装二进制与 `config.yaml`，systemd 单元 `WorkingDirectory=$APP_ROOT`，而 `config_data.dir` 为相对的 `configs/data`，启用 configdata 的服务启动会 `stat dir configs/data: no such file or directory`。

修复约束：先在临时目录按生成的 `install.sh` 实际安装一次（不写系统目录：用可配置的前缀 / DESTDIR，或在临时根下演练；不调用 systemctl），证实后让安装脚本把 `configs/data` 装到 `WorkingDirectory` 下对应位置，与 RR-34 的镜像布局一致；加生成器回归。

## 实证与修复（2026-09-28）

实证：按生成的 install.sh 在临时根下实际安装（替身代替 root / systemctl，不写系统目录），game 启动即 `mod config_data start: configdata: stat dir configs/data: stat configs/data: no such file or directory`，readiness 失败后停服，release 里只有二进制、`config.yaml` 与 `SHA256SUMS`——推断成立。

状态：**已修复**（本地提交，未推送 / 发布）。用 configdata 的服务安装时把 `configs/data` 拷进 release，unit `WorkingDirectory` 改为 `$APP_ROOT/current`（与 RR-20260927-34 的镜像布局一致），缺数据时在创建 release 之前拒绝；演练 install / 升级 / rollback 均通过。见[修复记录](../bugfix/RR-20260928-05.md)。
