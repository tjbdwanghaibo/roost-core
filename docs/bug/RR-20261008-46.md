# RR-20261008-46：Destroy等Entity锁时不响应取消

P2；基线42eb95e8，历史A8。进入Destroy时检查ctx后直接调用Mutex.Lock，另一业务持锁时取消无法结束等待；内存销毁与持久删除均受影响。

修前：`GOMAXPROCS=2 GOWORK=off go test -p 1 ./entity -run '^TestEntityManagerDestroyCancelsWhileEntityLockIsHeld$' -count=1 -timeout=30s`。测试先等GetMutex屏障，确认已越过初次ctx检查，再取消，持有者保持锁；两种路径均失败：

```text
--- FAIL: TestEntityManagerDestroyCancelsWhileEntityLockIsHeld (2.00s)
    --- FAIL: TestEntityManagerDestroyCancelsWhileEntityLockIsHeld/memory (1.00s)
        destroy_cancel_promises_test.go:79: Destroy ignored cancellation while the entity mutex remained held
    --- FAIL: TestEntityManagerDestroyCancelsWhileEntityLockIsHeld/durable (1.00s)
        destroy_cancel_promises_test.go:79: Destroy ignored cancellation while the entity mutex remained held
```

原始证据：`artifacts/perf/outbox-closure-20261008/destroy-cancel-red.log`。不是“取消了尚未开始的调用”或包级超时。[修复](../bugfix/RR-20261008-46.md)。
