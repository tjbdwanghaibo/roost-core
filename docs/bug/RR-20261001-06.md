# RR-20261001-06：account 建角的 pending slot 没有 owner-only 释放入口，名字租约过期被他人提交后该账号在该区服永久建不了角色

日期：2026-10-01。基线：main `32f69b2d`。来源：[W-2026-10-01-01](WANTED.md)（B 线修复独立复审分流，维护者 2026-10-01 拍板“做”）。等级 **P2**。状态：已确认，未修复。

## 位置、现象与修复约束

- 位置：`kit/service/account`（RR-20260929-19 的持久建角计划：`create_role.go` / `service.go` 的 `Slots` 与 `RoleCreation`）。
- 现象：两个账号抢同一名字，A 的名字租约过期、B 提交成功后，A 的 slot 永远停在 pending，没有任何入口释放；platform 同类场景有 `ResolvePendingAttempts`，account 没有对等入口。
- 修复约束：加 owner-only `ResolvePendingCreation(ctx, accountID, sid, note)`（与 platform 同形，不上 bus），或在租约过期且名字已被占时自动把 pending 置为失败并释放 slot（写明选择理由）；补 Memory + 真实 Redis 回归；`errcode_test.go` 的 `segmentAllocated` 若加码要同步。

## 修复（2026-10-01）

状态改为 **已修复，未发版**。修复记录：[docs/bugfix/RR-20261001-06.md](../bugfix/RR-20261001-06.md)；运维行 T-181。

- 根因：`create_role.go` 的 `releaseCreationSlot` 在 Admitted 之后只放行 foreign allocator ID；名字租约过期、被他人**确认提交**后 `resumeRoleCreation` 的 `ErrKeyTaken` 分支仍以 `!Admitted` 为条件，slot 永远不释放；`createRole:68-70` 对任何别的名字答 `ErrRoleLimit`；包里没有 Admin 面。
- 修法（推荐方案 a + b 的可判定子情形）：
  1. 同名重试发现名字 **committed 给别的 owner** 时自动释放 slot（这个计划再也不可能 Commit 它的名字——Commit 要 token 匹配当前条目，committed 条目只有 owner 能 Release——于是也不可能发布角色）；仍答 `ErrNameTaken`，之后换名建角成功。名字只是被他人 **reserved** 时不动（会过期、计划仍可能完成）。
  2. 新增 owner-only `account.Admin.ResolvePendingCreation(ctx, accountID, serverID, note)`（不上 bus，与 platform / activity 同形）：备注必填并写到 `Account.admin_note / admin_action_at_unix`，版本 + 身份围栏的 `DeleteIf` 释放 slot，返回被放弃的 `RoleCreation`（其 `PlayerID` 指向可能留下的未发布角色记录，保留作审计、永不可玩）。拒绝（`ErrNotResolvable` 560115）：无 slot、已发布、legacy 空 slot、名字仍被本计划自己 reserved（可能有在途尝试）或 committed（同名 `CreateRole` 即可完成）。
- 修前红（Memory 与真实 Redis 同文）：`account store:rr06-loser cannot create any role on server 1 after its name was committed elsewhere: account: role limit reached for this server: another name is pending on server 1`。修后 Memory `-race` 与真实 Redis（`-tags integration`，account + integration 两包）全绿。
- 契约更正：RR-20260929-19 的"名字被新 owner 占用后保留证明"收窄为"被 **reserved** 时保留；被 **committed** 时释放 slot、保留未发布角色记录"；原回归 `TestPendingRoleNameConflictRetainsRecoveryProof` 改名为 `TestPendingRoleNameConflictReleasesSlotButNotTheOrphanRole`。
