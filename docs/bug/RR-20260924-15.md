# RR-20260924-15：同批重复事务 ID 覆盖 digest 校验

日期：2026-09-24；基线：`967bc69` 加 DataEngine 工作树。等级：P1。状态：已复现、修复、验证，未发布；[修复记录](../bugfix/RR-20260924-15.md)。

ProjectBatch 把每笔记录的 digest 按 TransactionID 写入 map，相同 ID 的后一个 digest 会覆盖前一个。若持久 marker 已匹配后一个 digest，applied map 会让两个输入都跳过，导致前一个不同内容没有被识别为 ErrTransactionIdentity。

最小复现：两个合法记录使用同一个 ID、不同 Handler，预置匹配第二条的持久 marker。旧代码 ProjectBatch 返回 nil，预期拒绝身份冲突；不是合法的幂等重试。

```sh
GOCACHE=/tmp/roost-nest-go-cache GOWORK=off go test ./dataengine/engine \
  -run '^TestMongoBatchRejectsConflictingDuplicateIDBeforeMarkerLookup$' -count=1
```

修前 `conflicting batch identity=<nil>`；日志 `/tmp/dataengine-batch-identity-red.log`。正常 Nest 使用不同 ID 不触发，但损坏/历史重复身份记录或直接调用 ProjectBatch 会破坏身份检查，不能静默视为完成。
