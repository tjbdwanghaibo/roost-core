# RR-20260924-18：RemoteChecksum 不能写入真实 Redis

日期：2026-09-24；基线 `967bc69` 加 DataEngine 优化工作树。等级 P1。状态：真实依赖复现、修复并验证，未发布；[修复记录](../bugfix/RR-20260924-18.md)。关联 [RR-20260920-01](../bugfix/RR-20260920-01.md) 的 BSON 校验和存储类型变更。

remoteSnapshotL2Store.Set 将 entity.RemoteChecksum 命名类型直接作为 Redis Eval 参数。真实驱动返回 `redis: can't marshal entity.RemoteChecksum (implement encoding.BinaryMarshaler)`。本机缓存的 IgnoreRemoteError 降级策略允许 Publish 继续，导致本机 L1 有数据、Redis L2 无数据，未参与发布的节点无法从共享缓存获取快照。

已有 fake 通过 fmt.Sprint 接受任意参数，掩盖了驱动编码约束。问题对任意 checksum 数值均成立，并非只在 uint64 高位触发；不能通过回退 BSON 修复解决。

`TestRealDataEngineRemotePublicationAndWALRecovery` 在真实 Mongo 副本集、Redis 和文件 WAL 下复现：Mongo 文档版本正确，L1 读取成功，Eval 连续返回上述错误，L2 found=false。修前日志 `/tmp/roost-remote-l2-red.log`。
