# RR-20260924-21：Redis 锁版本和 fence 的 Lua 返回丢精度

日期：2026-09-24；基线 `967bc69` 加前轮优化工作树；等级 P2。已复现、修复、验证，未发布。[修复](../bugfix/RR-20260924-21.md)。

versionedTryLockLua 通过 tonumber 返回版本，直接返回 INCR 的 Lua number 作为 fence。Lua 浮点数不能表示全部 int64，合法版本可能回退，相邻 fence 可能不可区分。

真实 Redis 预置 version=9007199254740993、counter=9007199254740992，修前 TryLock 返回 version=9007199254740992、fence=9007199254740992。TestRealVersionedLockExactCounters 的 2^53+1 子用例失败；MaxInt64 对照修前已通过，不计为失败证据。日志 `/tmp/roost-remote-lock-redis-red.log`。

```sh
source /tmp/roost-dataengine-it/env.sh
GOCACHE=/tmp/roost-nest-go-cache GOWORK=off go test -tags=integration ./remoteentity -run '^TestRealVersionedLockExactCounters$' -count=1 -v
```

根因位于 remoteentity/versioned_lock_lua.go。测试只写专属 key，不涉及生产计数。
