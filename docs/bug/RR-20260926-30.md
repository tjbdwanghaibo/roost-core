# RR-20260926-30：saga 原生步骤（本地实体 + lease fence）投影时租约已过期，记录被跳过而 Nest 内存保留扣减，后续事务投影冲突 fatal、重启无法恢复

日期：2026-09-26。基线：main `985d5ba`（v1.16 起已有，不是回归）。等级 P2（触发需投影积压超过租约期；后果与 RR-10 同级：fence 且起不来）。
状态：已复现（单元探针），未修复。RR-19 只禁止了 Remote 写 + lease fence 的组合，本地组合未处理。

## 触发条件

原生步骤（本地 DAO + `inbox.Bind` 的 lease fence）已在 Nest 内存提交，但投影晚于 `lease_until`。租约只在 Reserve 时设置（`saga/dataengine_step_inbox.go:186`），
不续期；demo 为 2 分钟（`demo/internal/service/game/gift_saga.go.tmpl:117`）。Mongo 中断/变慢积压超过 2 分钟；或重投时租约已过期再次 Reserve 拿到新 token
（`:210-221`），handler 在内存再扣一次。

## 预期 vs 实际

预期：记录被跳过 = 该事务整体未发生，内存亦不得保留其效果（或不得继续在其上接受事务）。
实际：`dataengine/engine/mongo_projection.go:93-101` 只写 skipped 标记并 ack，Nest 内存扣减保留；同实体下一笔事务按内存版本投影，
`mongo_store.go:254-265` 判 fatal 冲突，Projector fence；重启回放同一冲突，起不来。SAGA.md:77-82、kit/README.md:499 只说旧 worker 晚到“不产生副作用”。

## 实施方向与验收

- 跳过带本地变更的记录时，受影响的本地实体不能继续以含该效果的内存状态接受并投影新事务：例如跳过时让这些实体失效/重载，并使 WAL 中其后基于旧内存的同实体记录
  得到确定处理（不能跳过冲突 WAL、不能放宽版本比较）；或在准入时以持久时间约束保证投影前租约有效。需要在修复记录中说明选择。
- 回归：租约过期跳过后，同实体下一笔事务不 fatal；重启恢复通过；Mongo 与内存一致。

## 修复评估（2026-09-26）：未修复，需维护者拍板

状态不变：已复现，**未修复**。在评估基线（main `87d9499` + 本轮 RR-29/10/07/17 本地提交）上探针仍复现。按任务约束没有硬修：
(a) 跳过时失效实体需要“驱逐重载 + Sync 回滚”的正式契约（roost-coding 要求先设计），且被跳过记录之后已完成的同实体记录无法在不跳过冲突 WAL、不放宽版本的前提下处理，
除非再加“未投影 fence 记录期间同实体只读”的准入屏障；(b) 同进程不重 Reserve 单独不够，租约心跳在 Mongo 中断时同样失效，改成“token 未变即有效”是 lease 语义变化且依赖跨进程所有权契约；
(c) 准入时间余量无法覆盖无上界的投影延迟。需要拍板的五个契约点、推荐组合与各方案反例见[修复评估](../bugfix/RR-20260926-30.md)。
另记一个相关疑点：投影事务只读 claim，与到期附近的并发 Reserve 存在写偏斜（未登记、未修改）。
