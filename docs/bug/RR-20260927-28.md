# RR-20260927-28：`RetractSyncSubject` 锁外比对状态后按 ID 注销，其间同 ID 换成另一个状态登记时注销的是新登记

日期：2026-09-27。基线：`7b56060` + cherry-pick `ed32ba3`（RR-20260927-22），分支 `fix-r7-b12`。来源：[OPEN-ITEMS-2026-09-27](../review/OPEN-ITEMS-2026-09-27.md) B41
（批次 10 报告，[bf-RR-20260927-22 §未验证项](../bugfix/RR-20260927-22.md)）。等级 **P4**：调用方是 Nest 撤销事务内新建的实体（仍持有该实体锁），
实际触发要同 ID 恰在此刻被 Rebind 到新状态、或旧登记恰好退役完成并重新登记。引入：修前即有（RR-20260926-35 起），RR-22 没有扩大它。
状态：已修复（[修复记录](../bugfix/RR-20260927-28.md)），本地提交，未推送。

## 现象与根因

`sync/entitysync/manager.go:582` `RetractSyncSubject(state)`：`:587` 在**不持 `subj.mu`** 时比对 `subj.state != state`，通过后 `:590` 按 ID 调 `Unregister(id)`。
两步之间同 ID 换成另一个状态登记，`Unregister` 按 ID 注销的就是新登记：

- **形状一（同一 subject 换状态）**：旧状态关闭，`Rebind(新状态)` 在 `subj.mu` 下把 `subj.state` 换成新状态（`:369`）；随后的 `Unregister(id)` 退役这个 subject——新状态的登记被撤回。
- **形状二（旧登记忘掉后重新登记）**：旧登记被注销并退役完成、从表里忘掉，新状态登记为新 subject；RR-22 之后 `Unregister` 取锁后确认表项、不一致就重查并注销**当前**登记
  （`:456` 起），于是新 subject 被退役。

另外，锁外读 `subj.state` 与 `rebind` 在 `subj.mu` 下的写本身是数据竞争。

## 复现

测试缝 `retractLookedUp`（`RetractSyncSubject` 取到 subject 之后、比对并注销之前调用）确定性进入窗口；用例
`sync/entitysync/retract_subject_promises_test.go` `TestRetractSyncSubjectDoesNotRetireALaterRegistration` 两个子用例对应两种形状，
窗口内会话 1 在新登记上订阅，断言 `RetractSyncSubject(旧状态)` 之后新登记仍在、状态是新状态、未退役、会话 1 的订阅保留。

```text
$ GOWORK=off go test ./sync/entitysync -run TestRetractSyncSubjectDoesNotRetireALaterRegistration -count=1 -v
    retract_subject_promises_test.go:98: RetractSyncSubject(first) retired the registration of the second state: subject 1211 is gone
    retract_subject_promises_test.go:98: RetractSyncSubject(first) retired the registration of the second state: subject 1211 is gone
--- FAIL: TestRetractSyncSubjectDoesNotRetireALaterRegistration (0.00s)
    --- FAIL: TestRetractSyncSubjectDoesNotRetireALaterRegistration/rebound_to_new_state (0.00s)
    --- FAIL: TestRetractSyncSubjectDoesNotRetireALaterRegistration/forgotten_then_registered_again (0.00s)
```

（会话 1 尚未持有对象，退役直接移除订阅、subject 随即被忘掉，所以表现为 subject 不在了。）

修复约束（清单推荐）：在 `subj.mu` 内比对，按实例撤销；不改 `Unregister(id)` 按 ID 注销当前登记的语义（RR-22）；不在快 worker 上等待。
