# RR-20260925-01：重复故障测试遗留 JetStream 流，耗尽预留容量

2026-09-25，基线 967bc69 + 当前工作树。影响测试验收，非生产 Remote 数据错误。已修复清理路径，真实复跑结果见 [修复记录](../bugfix/RR-20260925-01.md)。

Remote 完整故障矩阵最后的 broker-network 三项在业务开始前失败：`no suitable peers for placement, insufficient storage`。隔离磁盘仍有约 626 GiB 可用；NATS 每节点配置 4 GiB JetStream 上限。检查发现至少 56 个已结束测试的 `ROOST_IT_EFFECTS_<pid>_<seq>` 流仍存在，夹具通常为每个流预留 64 MiB，持续占用 placement 预算。

`kit/dataengine/real_fixture_integration_test.go` 为每次测试创建唯一流，但 `realFixture.close` 只停止服务、删除 Mongo 测试库，没有删除 JetStream 流。重复运行矩阵最终导致新夹具无法启动。

证据：`artifacts/perf/remote/authority-matrix-20260925/broker-network.log`；清理前清单 `/tmp/roost-finished-streams-before.txt`。没有通过增大容量或跳过网络场景隐藏问题。

修后真实网络三项通过，未产生新残留。历史 56 个流经分项有界清理与独立列表核对，最终残留为 0；中间超时记录保留，详情见修复记录。
