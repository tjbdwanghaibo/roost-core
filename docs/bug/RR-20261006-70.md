# RR-20261006-70：JetStream RPC 的 handler 超过 AckWait 时被重投、在实例间并发重复执行

2026-10-07，基线 `c78d0c34`（main）。P1（非幂等 RPC 的副作用执行多次）。来源：F05-3（推断），[impl/05 §10.2 第 3 条](../framework/impl/05-remote-mirror.md)。
状态：已复现（真实 nats-server）；已修复（`a9bb8923`，[修复](../bugfix/RR-20261006-70.md)），未发版。

## 机制

1. 被调方 handler 的期限取调用方截止（`bus/jetstream_rpc.go` `jetStreamRPCProcessContext`），可以远长于 `nats.rpc.ack_wait`（缺省 10s）。
2. 消费回调执行期间不发 in-progress ack（`nats/driver/jetstream.go` `Subscribe` 的 Consume 回调），AckWait 一到 broker 把未确认的请求重投。
3. 服务级 durable 在实例之间共享（`rpc_<svc>_<method>`），重投落到另一个实例（或本实例排队），服务端没有按 MsgID 去重 → 同一请求并发执行多次。kit 也没有像 saga 那样校验“处理期限 < AckWait”。
