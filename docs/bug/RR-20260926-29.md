# RR-20260926-29：RR-17 后 kit/dataengine 6 个真实 Mongo 集成测试的夹具失效（先 Close 再 ReplayPass），多批顺序 / 丢 checkpoint / ack 失败重启等覆盖丢失

日期：2026-09-26。基线：main `985d5ba`。等级 P2（测试缺陷；产品行为符合 RR-17；nightly 与故障矩阵 `mongo-wal-recovery` 格变红，覆盖丢失）。
状态：已复现（985d5ba 失败 / aaada47 通过；2026-09-26 故障矩阵 20/21 PASS，唯一 FAIL 即此），未修复。

## 现象

`dataengine runtime: shutdown has started`：TestRealLocalMultiBatchOrderIdentityAndLostCheckpoint、TestRealLocalMultiBatchLateConflictRollsBackThenAcknowledgesPrefix、
TestRealMixedProjectionSegmentsPreserveOrder、TestRealProjectionOnlyMongoAckFailureRestartPreservesSameEntityOrder、
TestRealMongoMixedRatioWALReplayAckThroughput（4 子测试）、TestRealDataEngineRemotePublicationAndWALRecovery。

## 根因

RR-17 在 `dataengine/engine/projector_replay.go:17` 加 `operations.Begin()`，Close 后 `ReplayPass` 返回 `ErrRuntimeStopped`；
`kit/dataengine/multi_batch_integration_test.go:34-44` 的 `manualRealProjector` 先 `p.Close()` 停后台循环再手动 `ReplayPass`。engine 包单测用内部
`projector.cancel()` 不受影响，外部包调不到。另：“Close 后 ReplayPass/Flush 返回 ErrRuntimeStopped”是导出 API 行为变化，CHANGELOG 未写。

## 实施方向与验收

- 给外部测试一个正式的“不启动后台循环的手动 Projector”入口（或改用 Runtime），不回退 RR-17 语义。
- 回归：上述 6 个测试在真实 Mongo 通过；故障矩阵 `mongo-wal-recovery` PASS；CHANGELOG 记录行为变化。

## 修复（2026-09-26）

状态：已修复（基线 `87d9499`），已本地提交，未推送/发布。新增 `ProjectorOptions.ManualReplay`（不启动后台回放循环，回放只由显式 Flush / ReplayPass 驱动，
Close 后仍拒绝），`manualRealProjector` 与 `real_integration_test.go` 三处改用它；RR-17 语义不变。修前 6 个测试以
`dataengine runtime: shutdown has started` 失败，修后在本地真实 Mongo 通过，`-skip 'Failover|Toxic'` 全包通过，矩阵 `mongo-wal-recovery` 格命令单独通过。
按本轮约束未改 CHANGELOG，行为变化写入 USER_GUIDE。见[修复记录](../bugfix/RR-20260926-29.md)。
