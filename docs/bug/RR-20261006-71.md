# RR-20261006-71：remoteentity.Assemble 不校验快照段配置，只读装配会拒绝的组合被 owner 装配静默接受

2026-10-07，基线 `c78d0c34`（main）。P3（直接调 `Assemble` 且只填了部分 `Config` 时；kit 从 `DefaultConfig` 起步不受影响）。来源：F05-4（源码核对），[impl/05 §10.2 第 4 条](../framework/impl/05-remote-mirror.md)。
状态：已复现；已修复（`a9bb8923`，[修复](../bugfix/RR-20261006-71.md)），未发版。

## 机制

`NewManager` 用不校验的 `newSnapshotClient`（`remoteentity/manager.go` :130、`snapshot_client.go` :134），`validateSnapshotClientConfig`（:114-132）只在只读方 `NewSnapshotClient` 路径执行。`SnapshotInterestTTL = 0` 时每次续租 `ExpiresAt = now`，兴趣表一律拒绝，owner 永不推送；`SnapshotL2TTL = 0` 时墓碑不落地、O5 过滤关闭。
