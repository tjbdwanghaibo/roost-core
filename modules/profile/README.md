# 玩家档案

`roost module add profile` 同时安装 enter。新角色完成 `EnterInit` 建档事务后是 **1 级、0 经验**；等级与 `Enter.Initialized` 在同一笔事务中提交。初始等级不是升级，不触发经验、任务或升级奖励邮件。

Entity 构造与角色建档是两步：`BuildEntity` 只分配 DAO 和组件，原始零值还没有完成业务初始化，不能直接作为已进入游戏的角色使用。正式客户端入口走 enter，它在开放自身视图前完成建档。构造函数不能绕过 Nest 调持久字段 setter。

建档失败时初始等级与标记一起回滚，下次重试；重进不重置等级。冷加载按存档恢复。若建档之前已经通过受控业务给角色设置了正等级，初始化保留它。安装 attribute 时，在同一事务内按初始等级建立基础和最终属性。

升级仍由 `ProfileComp().AddExp` 完成，每次最多执行一轮升级钩子，参数是起止等级；连升几级由差值表示。模块场景中的底层组件单测可以直接构造未建档的 DAO；`profile + enter` 的联动场景验证实际建档、升级、回滚、重进和冷加载路径。
