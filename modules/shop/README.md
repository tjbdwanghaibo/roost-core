# 商店

`roost module add shop` 安装 wallet、bag、rules（含 enter）。`ShopBuy` 在同一笔 Player Nest 事务中扣金币、发道具、记限购和回执；普通购买不需要 Saga。

商品在 `configs/schema/shop_goods.go` 与 `configs/table/shop_goods.csv`。默认三条商品：10 金币买一份道具 1001；30 金币买五个道具 1002、每日限 3 份；200 金币买道具 1003、终身限 1 份。正式上线前改成自己的商品，再运行 `roost generate`；运行期按 configdata 热更。

配置装载会校验正数价格/数量、限购类型和道具引用；购买仍保留运行时检查。规则导出与购买都用生成的配置访问器，读取本次请求固定的快照。新增商品不需要改组件，也没有生产可调用的测试目录替换函数。

限购类型 0 不限、1 每业务日、2 终身；数量是购买份数，发放总数为份数乘 ItemCount。临时停售用 Off，保留计数；删除商品或改变限购类型会在玩家下次成功购买时清理旧计数。因此商品号、商品含义与限购类型上线后不能复用或随意改变。

客户端在统一 [rules](../rules/README.md) 中取得未下架商品、价格与限购规则，已买数量仍由 Player.Shop 同步。展示目录更新和购买是两次请求，跨请求可能热更；没有期望价格校验，以服务端购买应答为准。

请求键只在最近 64 次成功购买中去重；更早的键重发可能再次购买。背包拒绝或提交失败时整笔回滚，调用方必须返回错误。没有多货币、全服库存、折扣或支付平台逻辑；付费到账使用 purchase。
